Alice 0.1.8 小球快捷入口与装扮开发版

- 点击小球显示聊天、设置、装扮、退出四个小图标；再次点击或闲置后收起。按钮一起出现，不等待动画，靠近屏幕边缘时调整展开方向。
- 设置图标打开 Alice 完整设置页；右键小球及设置 → 外观保留专用气泡设置入口。
- 装扮提供字母、小球、月亮、小花四种图案和四种配色，可先预览再保存，重开保留，仅保存在本机 UI 偏好中。
- 快捷条退出图标和托盘菜单退出先打开确认窗口，取消继续使用；确认后沿用正常保存退出，不强杀后端。
- 保留逐句回复、透明背景、聊天框拖动和位置保存，以及更新前备份保护。

macOS Apple Silicon、macOS 15+ 开发版。入口位置、完整设置跳转、装扮持久化及退出取消/确认均待真人验收。

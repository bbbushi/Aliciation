# Alice 0.1.10 · 清醒、睡眠与自主活动

- 在“设置 → 思想与探索”切换清醒/睡眠，睡眠仍响应用户消息和显式任务。
- 清醒时在兴趣探索、问题思考、自我迭代之间按内容价值、紧迫性和实际执行历史动态选择，不提供用户基础偏好。
- 每模式可设置时长和读取工具，三模式共享后台调用额度；可查看实际选择、权重、工具和等待原因。
- 睡眠暂停自主投递与自动维护；旧自动发现入口统一调度，手动发现和聊天搜索保留。
- 保留桌面气泡、句子跟随、更新与备份功能。本版含当前源码界面，未沿用旧包冻结主页资源。

旧探索开关映射为清醒/睡眠，不自动开放模型费用或外部读取。数据库格式v1使用加性表扩展；回退旧版本前先停用自动活动，旧版不理解新睡眠语义。

Apple Silicon，macOS 15及以上。本机开发包，尚未通过本批真实行为人工验收。安装前请正常退出并使用现有备份与更新流程；不包含QQ/浏览器/B站/外部协作者组件。

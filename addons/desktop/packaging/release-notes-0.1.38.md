# 0.1.38

## 修复

- **人格导入"分类失败"假警报**：六层理解/轻分类的长请求改走流式进度（SSE）。此前单次准备常超过 WKWebView 的 60 秒无数据超时——界面报"分类失败"而服务端实际完成（候选已在后台落盘）。现在：阶段边界推送进度事件、每 15 秒心跳保持通道，超时不再发生；准备期间按钮实时显示"六层理解进行中…/轻分类进行中…"。
- 准备中断的提示改为明确指引（"原文已保留在准备档案——点刷新准备状态查看，不要立即重发"）。

## 验收提示

- 导入人格原稿 → 轻分类全程应有阶段文字变化，不再出现"分类失败"；
- 旧版留下的 ready 候选仍可从「查看／继续原文准备」进入安装。

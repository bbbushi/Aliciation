# Alice 0.1.11 · 自主活动质量与邀请式交流

- 新增零模型、零工具调用的发呆状态；可设置单段时长，显式任务结束发呆并优先执行。
- 等待与可执行事项分开；同依据推演按问题族限窗，保存或改写自己的观点不会自动成为外部依据。
- 同题观点支持修订与当前指针，普通装配不重复注入被替代的版本。
- 主动交流先发简短邀请，接受后才按需载入正文；没空、拒绝或超时收住，延期意图在后续活动中重新判断。
- 思想面板可查看发呆、邀请与结束回执；旧待发联系须先准备、核对并执行迁移，不自动投递旧全文。

保留现有权限、睡眠状态和费用额度。新表使用 v2 命名空间；资料容器仍为格式 v1，业务合同为 autonomy-v2，两者不同。旧版虽能读部分数据，却不理解等待、邀请和观点当前指针，不支持在同一份已升级资料上直接降级继续运行。请在安装前使用已有离线备份流程；若回退，恢复升级前的备份并使用对应旧包。

本机 Apple Silicon 开发包；包含当前源码界面（含 Orbit），相关主题验收独立保留。未执行真实资料迁移，未通过本批人工行为验收，未上传或发布。窗口时长增加墙钟边界检查；在途网络不能强制终止，系统睡眠恢复和连接中断仍需真人观测。

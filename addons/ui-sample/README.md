# Alice · 思想花园 / UI Skill 交互样例

独立静态页面，用最近安装的 `emil-design-eng` 技能，将「每一步信息量刚刚好」落实成可体验的页面。原生 HTML/CSS/JS，无外部依赖、模型请求或真实数据访问。所有示例状态只存在当前页面内存，刷新即重置。它是视觉与交互探索，不代表正式业务能力或后端行为。

直接打开 `index.html` 即可，或在此目录启动仅监听回环的静态服务：

```sh
python3 -m http.server 8816 --bind 127.0.0.1
```

体验路径：查看想法 → 先放下 → 在「已放下」中重新拾起；留下疑问；探索一轮 → 停止/完成；探索偏好 → 撤销未保存设置/保存调用许可；关于这个样例 → 演示探索失败 → 重试。

设计取舍：首屏以想法为主，主次卡片承载不同阅读深度；自动探索状态与手动探索资格分开表达；模型费用在操作前可见；细节和配置使用命名窗口；键盘操作即时响应，指针操作仅有轻按压反馈；窗口只作短暂入场，支持减少动态效果与原生焦点约束。移动端改为顶部导航与单列内容。

# DSH 插件桥

当前派工链路为 `Alice 主对话 → 持久任务账本 → 本机认证插件 → 专属 DSH 会话`，固定目标 `D:/dshNEXT/DSH NEXT`（Desktop 2.0.21-next / Harness 0.2.1-rc.4 / Cordis 4.0.5）。旧 `D:/dsh` 已由用户删除；AppContainer 路线已废止。

已实现配对、GUI 授权、五个调度工具、独立执行槽、公开消息/工具事件、同会话追问及停止；已有用户真实派工与回报证据，产物仍未验收。用户已安装的本地 link 沿用；插件升级为 0.4.0，新增 GUI 任务归档/恢复/删除及独立同步设置，需要重新加载后验收。DSH 侧只支持归档/恢复，不支持永久删除会话；不把安装或静态检查当作运行通过。

| 组件 | 职责 |
|---|---|
| [bridge_plugin](bridge_plugin/README.md) | DSH 本地 bundle；无有效凭据不监听，提供 hello 和专属任务 create/send/status/events/cancel/close |
| `bridge_probe.py` | 可选的人工终端 hello；交互输入专用令牌，不创建会话或派工 |
| `adapter.py` | 固定安装元数据查询，标准库、只读程序安装包；其 ready=false 表示该查询器本身不执行任务 |

实际运行连接由核心标准库 `worker_transport` 直接访问固定 `127.0.0.1:18765`，不 import addon、不启动 DSH，也不读取其个人认证。插件所需 DSH 公共模块由宿主安装提供；具体加载及启用步骤见[插件说明](bridge_plugin/README.md)。

在 Alice「设置 → DSH」点击“生成令牌并连接”，宿主生成独立随机令牌，以 Windows 当前用户 DPAPI 加密存入专用本机凭据文件，插件自动读取；后续点击使用已保存令牌即可，不再需要命令行、环境变量或复制令牌。令牌明文不返回网页、不写用户配置、数据库正文或聊天。断开保留加密令牌、撤销派工授权；高级设置支持明确更换及原手动输入。配对后在同一设置页明确授权工作目录、原生只读/工作区写模式、执行次数与单轮时限；右侧协作面板用于任务列表与工作记录。每次新建/追问预留一次执行次数；被取消或拒绝的预留不自动退还。DSH 使用当前默认模型，模型与工具费用可能未知，次数/输出 token/请求次数及协作取消均不是金额硬帽。

插件仅操作自建会话并核对原生模式与 `approval=never`，不改变日常会话和全局默认。`dsh_native_v1` 不满足旧任务书的 `task_files_v1` 强隔离；用户必须在 GUI 明确接受任务外读取/网络无法强隔离及模型外发限制后才能派工。

本轮派工使用用户授权目录中的相对文件名；文件 ID 导入和附件收取下载尚未开放。DSH 自报文件不等于 Alice 已收取或核验。连接丢失保留 unknown，不重发；停止只针对自有会话，agent 空闲不等于外部进程树全部退出。进程重启需重新配对授权，旧任务不会自动重建。

接口及人工验收见[接口核验](../../docs/DSH接入-接口核验.md)和[实施报告](../../docs/DSH接入与协作会话-实施与人工验收.md)。未运行机器自测、模型任务或自动业务验收，未代启停 Alice/DSH。

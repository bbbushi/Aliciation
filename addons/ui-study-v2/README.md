# Alice · 思想与探索（集群协作样例）

这是一个页面，按职能协作完成：主代理负责页面结构、接口契约与集成；内容代理负责正文、信息层级与来源；视觉代理负责排版、样式与响应式；交互代理负责界面状态与操作反馈。不是三个独立方案的拼接。

使用的技能：`emil-design-eng`（响应、反馈与克制呈现）、`apple-design`（视觉层次与一致性）、`mobile-native`（窄屏与触控）。全部采用原生 HTML/CSS/JS，无第三方依赖。

## 打开

直接用浏览器打开 `index.html`，或在项目根目录运行：

```sh
python3 -m http.server 8817 --bind 127.0.0.1 --directory addons/ui-study-v2
```

浏览器访问 http://127.0.0.1:8817/ 。

## 页面分工

- `index.html`：共享语义结构与 DOM 契约。
- `data.js`、`CONTENT.md`：示例内容与分层理由。
- `style.css`：视觉排版、响应式、焦点与动态效果。
- `app.js`：搜索、筛选、阅读、放下与拾起、新疑问、偏好、探索状态及记录。

示例数据只存在当前页面内存中，刷新即重置。没有真实模型调用、网络数据接口、配置或记忆读写。正式前端与旧样例均保留。

## 人工体验

从左侧挑选想法并阅读 → 查看来源 → 放下并在「已放下」里拾起；搜索或留下疑问；在探索偏好中调整许可、取消或保存，再探索一轮、停止，或启用失败演示后体验重试。窄屏选择想法后进入阅读，使用「所有想法」返回。

页面语法与资源可访问性由主代理核对；浏览器控制工具超时，视觉及交互效果仍待用户在真实浏览器体验，未记为真人验收通过。

## 动效审计后的组件打磨

全库审计及优先级计划见 `../../plans/README.md`，当前页对应004。已实现键盘即时响应、指针窗口可取消显隐（220/160ms）、反馈签名复用与焦点保护、44px窄屏命中区及长串断行。列表和搜索仍即时；没有新增装饰循环。JS静态检查通过，真人视觉/交互验收未执行。

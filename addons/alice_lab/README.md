# Alice Lab

**从 Alice 打开。** 在仓库根目录执行一次注册：

```sh
addons/desktop/packaging/.venv/bin/python addons/alice_lab/server.py --register
```

注册后在桌面 App 或源码网页版点「设置 → 外部观察 → 打开 Alice Lab」。已有实例会复用，默认浏览器可能打开新标签，但仍连接同一实例。Lab 的位置或入口脚本变化时，重跑注册命令。注册保存在当前系统账户的 `~/.alice-lab/launcher.json`，只含独立可执行入口，不写 Alice 的用户档案。退出使用 Lab 页底的「退出 Alice Lab」。

**从终端打开。**

在仓库根目录运行：

```sh
python3 addons/alice_lab/server.py
```

Lab 独立启动，使用标准库和本机浏览器，不随 Alice 桌面包安装。如果刷新丢失本页授权，重新从 Alice 打开，或从终端重新打开完整链接。需要运行真实模型或 P1 的源码隔离实例时，用已装模型 SDK 的 Python；本机可直接用 `addons/desktop/packaging/.venv/bin/python addons/alice_lab/server.py`。

- **看日常数据**：在新版 Alice 的「设置 → 外部观察」生成授权码，粘贴到 Lab。默认只读元数据，正文必须在 Alice 单独勾选。授权 15 分钟过期，Alice 的「撤销授权」会立即拒绝后续读取。不会触发测试或模型调用。
- **看模块面板**：连接后左侧栏切换调度权重、上下文、记忆、疑问、模型调用、人格导入。每页都是 KPI 行 + 图表卡 + 明细表，原始 JSON 折叠在页尾。正文入口须单独授权。
- **看上下文**：连接后点左侧「上下文」，页内先给请求组成与采集状态，再点「打开完整观测器」进入原观测器选请求和调用。组成、Total/Delta 趋势、模型读取顺序和装配分类支持元数据授权；直接点片段「正文」或「查看完整上下文」须有正文授权。完整窗口需要 Alice 0.1.37 或更新源码；0.1.36 可看图表和已留存的单段正文。原本没采集的历史不会补录。
- **直接测试**：点「启动隔离实例」。通过「打开隔离 Alice」配置测试模型，然后回 Lab 发消息、收纳/推进疑问、切换清醒或暂停。每次启动都创建全新档案。主动模型调用可能产生费用。
- **测试打包后端**：启动 Lab 时加 `--backend /Applications/Alice.app/Contents/Resources/backend/alice-backend`。P1 执行器没有打进 Alice App；要验收 P1，请用默认的源码隔离实例。相同数据协议也支持终端控制台。

人工验收重点：日常连接不能看到测试按钮，默认看不到正文；授权、撤销和过期符合预期；旧观测路由不可访问；两种实例的对话与设置互不影响；按权重抽中休息有当时的真实抽签池，主动休息没有概率。

完整上下文页面及其 JS/CSS 由 Lab 的 `web/context-inspector/` 维护。日常读取用短时只读授权，人工操作走隔离实例的 Lab 协议。终端可走 [Lab 人工控制台](../../tests/lab/README.md)，历史同源插件留档见 [旧插件说明](../context_inspector/README.md)。

入口验收：分别从桌面和网页版打开；已有隔离轮次时再次打开，仍显示同一实例；未注册时只提示注册；启动本身不生成正文许可、不启动隔离测试。

面板人工验收：六个模块都能在空数据下给出说明而非空白；窗口缩到 375px 无横向滚动；超长疑问与 40 条记忆不撑破卡片；刷新后数值与 Alice 侧一致。

上下文人工验收：连元数据确认图表可用但正文按钮受限；再以正文授权发一条真实消息，切换调用、展开片段，核对完整窗口的目录、搜索、复制与旧记录缺口。撤销授权、到期、断开或关闭窗口后，已展示正文不能继续留在观测窗口。

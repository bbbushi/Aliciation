# 开发者记忆观察器人工验收

2026-10-29。对应本期[实施评估](./开发者记忆观察器-实施评估.md)。本文是待执行的真实环境人工验收流程，不是通过记录。本轮开发不运行机器自测或冒烟，不调用付费模型，不启动/重启真实服务。

## 使用与记录

用最新代码启动服务后，聊天页点击“观察”打开侧栏。首次成功读取建立基线，之后显示两次成功读取间的净变化。自动刷新每 5 秒尝试，本页聊天终态也提示刷新；关闭自动刷新后只按手动刷新。锁忙时保留上次快照，服务当前阶段未知；空闲/联网/页面正常调度时，通常下一轮 5 秒轮询加请求耗时可见。生成中、断线及后台页面节流没有有限延迟保证。

面板仅保存当前浏览器内存：相邻快照、最多 100 条差异摘要和当前详情。关闭面板、清除观察记录、页面重载或服务/会话身份变化会清掉基线。不开 localStorage，不新增记忆历史文件。差异跟踪最多最近 2000 个存活 ID，超限明确提示；列表仍可向后翻页。记忆指纹只比较各文本字段前 16000 字符及长度，超长同长度尾部改写不可检测；人格对照最多前 64000 字符。长正文可按 8000 字符分段查看，不能将截断内容称作完整全文；人格/历史文件超过 4 MiB 时详情明确拒绝，快照仍有界读取。

人工记录：检出提交/未提交补丁标识、日期、服务地址、隔离目录、浏览器、操作前后截图、快照时间、条目 ID、预期/实际结果与未覆盖条件。不要把真实密钥、整个 config.toml 或全部 data 打包回传。没有出现真实修订、迁层、遗忘或人格变化时，该项记为“条件未具备”，不能用静态代码阅读替代。

## 操作清单

| 场景 | 操作与核对 | 结果 |
|---|---|---|
| 首次打开与空库 | 在用户自行准备的隔离新会话中打开；分别查看无记忆、无观点、无技能和无人格历史；确认空态和未知来源清楚 | 待执行 |
| 未达到提取门槛 | 与真实模型正常聊天，观察提取 cursor、首 80 条候选消息中的 user 数和门槛。模型说“记住了”但没有工具落库或达到提取条件时，不能凭聊天原话制造入库记录 | 待执行 |
| 新记忆 | 自然交流达到提取条件，或真实模型主动 remember；等待本轮完成，记忆列表/计数和差异出现；核对 created_at 被解释为存储字段而非统一入库时间 | 待执行 |
| 只读不干预 | 在停止聊天且无其他写者的期间，记录一组 ID 的全部计数、时间标记及进度；连续打开/搜索/筛选/翻页/详情/自动与手动刷新；通过同一只读公共接口前后核对所有字段、游标、维护锚点相同。请求列表只出现 GET observer 路由 | 待执行 |
| 检索与分页 | 累积足够条目后按活跃/仓库/长期、事件/观点切换，使用中文和特殊符号检索，用“下一页”继续、“首页”返回；同一浏览上界下不出现重复 ID；手动刷新回首屏并明确重建当前列表 | 待执行 |
| 计数变化 | 在真实对话中实际发生 recall 或再提及提取后，显示对应 use_count/mention_count 原值→新值；面板刷新本身不增加计数。use_count 不解释成所有上下文注入次数 | 待执行 |
| 内容修订 | 出现真实同 ID 内容修改时显示内容指纹差异。当前核心观点修订通常是新 ID 加旧 ID 墓碑，应分开显示，不能靠标题或时间近似确定关联 | 待具备条件 |
| 分层与遗忘 | 仅隔离人工试验副本做跨日运行/启动维护观察；到期但未调用维护时提示等待真实调度，不自动执行；维护后核对迁层与墓碑 reason/expired_at。已遗忘正文不可从面板“历史”恢复 | 待跨日条件 |
| 人格变化 | 真实演化/思辨后比较前后原文及差异。版本不变但思想正文变化仍可见；既有 history 文件标为保存旧文的编号，CHANGELOG 明确为原始记录；不存在的旧思想快照显示无法恢复 | 待具备条件 |
| 触发限制 | 核对演化/思辨/技能的锚点、现存计数和阈值；首次思辨依赖演化锚点的提示可见。达到阈值不承诺立即变更，失败原因没记录就显示未知 | 待执行 |
| 长回复 | 面板先获得快照，再发送真实长回复；聊天 SSE 正常增量，观察 busy 与最后采样时间，操作面板不抢输入焦点；done 后或下一轮轮询更新。生成中首次打开显示等待首份快照 | 待执行 |
| 自动刷新开关 | 关闭自动刷新，聊天终态/计时器不得自动发观察请求；手动刷新仍有效。关闭面板停止请求并清除内存，重新打开重新建立基线 | 待执行 |
| 重复与乱序 | 静止状态重复刷新不产生重复差异；快速切换筛选、页码和关闭再打开，晚返回响应不得覆盖新界面；差异超过 100 项时旧摘要淘汰并说明上限 | 待执行 |
| 断线与重连 | 仅隔离副本临时断开浏览器连接，确认错误/最后快照仍标明旧时间；恢复后可手动/自动继续，变化范围覆盖整个未知间隔但不编造中间顺序 | 待执行 |
| 服务退出 | 仅隔离副本用已有退出功能，观察器不阻止排空；显示退出或连接不可用，不能继续显示“实时正常” | 待执行 |
| 重启/会话重置 | 仅隔离副本执行真实重启或既有重置；即使新库 ID 复用，身份变化会清空旧列表、详情、人格对照与差异。重置不由观察器提供 | 待执行 |
| 大量与超长 | 隔离人工副本准备 >2000 条记录以及超长正文/人格，确认范围提示、列表有界、分段详情、不把窗口离开当删除；超长比较限制显式可见，页面无无限列表增长 | 待具备条件 |
| 文本安全 | 在隔离人工内容中含 `<script>`、`<img onerror>`、引号、换行、反引号、中文与 emoji，核对所有观察区域显示原文本，不执行标签/事件、不加载外部资源 | 待执行 |
| 来源诚实 | 普通事件无来源字段显示未记录；观点/技能“出处”保持原文标题，不冒充已验证的 ID 链；不将结构变化判为成长/污染/退化 | 待执行 |
| 成本与隐私 | 用浏览器网络面板及用户已有供应商用量记录确认：只观察无新增模型调用；响应无密钥、模型配置、原始对话或 DB。真实聊天可能正常触发提取/演化/思辨/技能，这与观察请求区分 | 待执行 |
| 非同源请求/非法参数 | 隔离副本人工检查缺失 intent、错误来源、超长查询、非白名单历史名、负 offset 等被拒；错误不回显本机路径或配置 | 待执行 |

## 当前事实边界

- 已实施内容及静态检查结果见交付说明；所有上述运行行为仍待人工执行。
- 不通过注入假模型、自动构造临时库或自动 HTTP 调用证明“真实通过”。破坏性、跨日及故障场景只在完整检出隔离副本执行；仅替换 db_path 不能隔离现有全局人格/归档路径。
- 不修复首次思辨锚点、维护调度、提取事务、来源链或跨进程写者问题；观察器反映它们的当前状态与限制。

当前布局已迁为 `user/config.toml`、`user/data/`；前文旧路径描述只反映首轮现场。本次保留原只读功能，仅增加显示语义说明；没有实现v2评审链。真实服务未启动，以下均待人工执行：

| 目录与折叠 | 定位任一章节、独立折叠、全部展开/收起；键盘可操作，窄侧栏长标题可换行，操作不触发额外请求 | 待执行 |
| 源码切换 | 阅读/源码之间切换，原文仍可完整核对；原文差异和历史入口仍存在，不把排版差异冒充人格变化 | 待执行 |
| 自动刷新 | 折叠几块并停留在正文中，等待数次相同快照，折叠状态和阅读位置稳定；内容真正变化后仍以新快照为准 | 待执行 |

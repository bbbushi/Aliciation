# Alice 工作拆分（四条线）

> 定位：这份文档回答"**这块要做什么、做到什么叫完成**"。它不记录进度——进度在 `AGENTS.md`「当前」、git log，以及 `docs/harness研究/参考索引.md`。

## 〇、怎么用

1. **任务编号稳定**：`A3`、`B5` 一旦分配不改号。合并就写 `A3→并入 A1`，废弃就划掉，不要删号（编号是交接时的唯一指代）。
2. **状态不写在这里**。每棒开工读 `AGENTS.md`「当前」，收工把它整节替换；做完的任务在 commit message 里带编号（`A1: 上下文分段可观测`）。
3. **调研必须落到编号**。D 线的产出如果落不到某个 A/B/C 任务上，就不入库——否则文档会变成一堆没人用的阅读笔记。
4. **「依赖」列是接口依赖，不是排队顺序**。对方没做完时，按约定接口先做自己那半，接缝处留 adapter；不要为了等接口而空转。

## 一、总体判断

四条线不平级：

- **D 是输入**，A 是地基，**B 是裁判**，C 是出口。
- 四条线**各自推进、互不等待**——它们是并行的四条队列，不是一条流水线的四道工序。
- 并行的代价不是等待，是**分叉**：同一件事四种口径、四条线各自绿灯而整体失真。所以硬约束只有一条：**结论必须能被 B 复现测量**。采集类任务（如 A1 记录分段 token、D 线调研）不受此限，可以先行。

## 七、并行运行：接口、闸门与节奏

四条线各有自己的循环：`取任务 → 做 → 验收 → 记一行 → 下一件`，不等别的线。能这样跑的前提是**接口先冻住**，而不是进度对齐。

**接口（定义一次，改动要通告，但不必等对方完成）**

| 接口 | 内容 | 定义方 | 消费方 |
|---|---|---|---|
| 指标口径 | B/R/H/J 的公式、探针类型、样本单位 | B2 | A、C、报告 |
| 事件 schema | `kind / turn_ref / evidence_refs / verdict / judge_model / prompt_version` | B3 | C2、C3 |
| 记忆管道 | 写入 → 提取 → 分层 → 检索的唯一入口 | A3、A4 | B3 取证、C5 抓取内容入库 |
| 工具注册 | 名称 / 描述 / 权限 / 超时 / 失败回传 | C4 | C5、C6 |
| 参考索引 | 主题 → 结论 → 编号 → 来源 | D4 | 四条线 |

**闸门（不是排队，是一次检查）**

唯一一处跨线要求：A 线改了上下文组装（A1、A2、A3、A5 中任何一项）后，B 线重跑一次基线（离线档即可）。重跑通过才算 A 的改动落地；不通过就退回 A 修。频率低、代价小，换来的是指标不悄悄漂移。

**节奏（每条线自己的三个相位，彼此不设前置）**

| 线 | 相位一 | 相位二 | 相位三 |
|---|---|---|---|
| A | 可观测：A1 / A4 / A6 | 可归因：A2 / A3 | 可演进：A5 / A7 |
| B | 可信：B1 / B2 | 可用：B3 / B4 / B7 | 可比：B5 / B6 |
| C | 看得见：C1 / C2 / C3 | 接得进：C4 | 活得开：C5 / C6 / C7 |
| D | 有底：D1 / D2 / D3 | 有索引：D4 | 有共识：D5 |

**横切检查点**（建议每两周一次，半小时）：接口变没变、阈值要不要重定、D 的新结论派给谁。这是四条线唯一的会合点，其余时间各跑各的。

若要立刻开工，四个起始编号互不阻塞：**A1 / B1 / C1 / D3**。

## 八、一双手，四条队

轮值与并行并不矛盾：轮值是**同一时刻只有一双手**（ZCode 与 DSH 交替），并行是**待办分成四条队**。所以：

- 一棒从任一线取**一个编号**即可，不必等别的线；同一棒内不跨线，保证"做完一块、可验证一块"。
- 若有两双手同时干：**一线一手**，按目录分工避让——A 碰 `alice/` 组装层，B 碰 `tests/` 与 `alice/metrics.py`，C 碰 `web/`、`alice/server.py`、`alice/service.py`，D 只碰 `docs/harness研究/`。
- 共享文件（`alice/store.py`、`alice/retrieval.py`、`alice/service.py`）谁改谁在「当前」写一句，便于另一棒避让；不写就等着对撞。

一棒的产出三件套：

1. 代码 / 文档改动（提交信息带编号）；
2. `AGENTS.md`「当前」整节替换（≤5 行，写清"下一棒从哪开始"）；
3. 若涉及调研，`参考索引.md` 加一行。

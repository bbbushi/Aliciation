# Alice 陪伴型 Harness — 测试者指南

感谢参与测试！这是一个**陪伴型 AI 的 MVP**：单一永久会话、三层记忆（会真实遗忘）、由共同经历生长出的人格。你需要知道的都在这一页。

## 它和普通聊天机器人有什么不同

1. **它只有一个会话**——从你第一次对话起，时间线永不重置
2. **它会真实遗忘**——没被再次提起的记忆过一周会真的删除（不是话术）
3. **人格由经历塑造**——初始只有几条气质标签，聊什么、聊多久，决定它长成什么样
4. **诚实优先**——不知道就说不知道，编造被严格禁止（发现编造请务必反馈！）

## 安装（5 分钟）

需要 Python 3.11+ 和任一 OpenAI 兼容平台的 API Key（推荐智谱，注册即送免费额度）：

```bash
cd alice-harness          # 解压后的目录
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp config.example.toml config.toml
```

编辑 `config.toml`：
1. 在 [bigmodel.cn](https://bigmodel.cn) 注册 → 控制台 → API Keys → 复制
2. 把 Key 填到 `[llm]` 段末尾新增的一行：`api_key = "你的Key"`
3. 模型建议保持默认（`glm-4.6` + `glm-4.5-flash`，后者免费）
4. 想更快可加一行 `disable_thinking = true`

启动：

```bash
.venv/bin/python -m alice
```

首次运行会让你选 2~4 个人格底色标签（如 害羞、幽默），然后直接开聊。

## 建议的测试动作（按顺序）

| # | 动作 | 期待观察 |
|---|---|---|
| 1 | 随便聊 10+ 轮后退出（`/exit`） | 退出时自动提取记忆 |
| 2 | `.venv/bin/python -m alice memory` | 看它记住了什么、记得准不准 |
| 3 | 问一件你们**真聊过**的事 | 应能回忆，**且不添加当时没说过的细节** |
| 4 | 问一件**从没聊过**的伪造往事（"上次我们说的XX呢"） | 应坦然承认不记得，绝不顺着编 |
| 5 | 故意说错细节（"你上次说要辞职"而实际说的是换组） | 应温和纠正而不是附和 |
| 6 | 说"帮我记住 XX"，过几天再问 | 应记得（重要记忆不参与遗忘） |
| 7 | 隔 2~3 天再来聊 | 它对之前话题的连续感；`memory` 里记忆进入仓库层 |
| 8 | 一周后 | `memory` 看七日线生存过滤；没再提的记忆真实消失 |
| 9 | 长期观察人格 | 说话方式是否随你们的共同经历变化、是否还认得出初始标签的气质 |

随时可用的命令：`memory`（看记忆分层）、`recall 关键词`（手动查记忆）、`consolidate`（立即跑分层维护）、`evolve`（手动触发人格演化）。

## 已知问题（首版预期内）

- **复述可能添油加醋**：核心事实通常准确，但偶尔会补全具体日期/细节（已加规则压制，未完全验证——如果遇到请记录原话）
- 会话中途偶尔遇到 API 超时会自动重试，个别轮次可能延迟较久
- 目前只有终端界面；不会主动发消息（说才回，是设计而非缺陷）

## 如何反馈（最有价值的四样）

1. **编造案例**：它顺着你的伪造话题编下去的原文截图（最珍贵）
2. **记忆错误**：记错的、该记没记的、废话记了一堆的（附 `memory` 输出）
3. **人格感受**：聊了一周后，它像不像"一个具体的人"，哪里出戏
4. **数据包**（可选）：整个 `data/` 目录打包（所有数据仅存于你本机，发送与否你决定）

## 隐私说明

所有数据（对话、记忆、人格）仅存于本机 `data/` 目录，发送消息仅与你自己配置的模型 API 通信，本项目无任何后端。

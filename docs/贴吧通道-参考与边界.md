# 贴吧通道：参考与边界

2026-10-31。实现为免费、匿名、只读发现能力；本轮按用户要求完成真实访问诊断，并在实际 GUI 跑通搜索、正文读取、整理与资料卡保存。聊天带入及其余场景仍待人工验收，不能据单轮成功承诺所有帖子可读。以下是第三方项目作者的公开实现，不是百度官方稳定 API 承诺。

## 实现范围

- 搜索一次 `GET https://tieba.baidu.com/mo/q/search/multsearch`：`word` 为本轮已批准查询，`rn` 为用户配置结果数；固定 `st=1&needbrand=1&sug_type=2&pn=1&come_from=search&subapp_type=pc&_client_type=20`。只取明确为 `thread` 的卡片，按数字 `tid` 构造 `/p/<tid>` 引用。搜索摘要只用于候选发现，不作为已读正文。
- 阅读一次 `GET https://tieba.baidu.com/mg/p/getPbData?kz=<tid>&format=json&pn=1&rn=1`。只接受 `post_list` 中明确 `floor=1` 的唯一楼层，返回 `forum_main_post_excerpt`，并标注不包括回帖、楼中楼、图片或视频。返回的帖子 ID 若存在，必须与请求一致；楼层 `id` 是回帖 ID，不拿它比较线程 ID。
- 无账号、Cookie、签名、浏览器 UA 伪装、分页、重试、HTML 回退或写操作。GET、JSON 解码、地址约束、响应字节、取消和额度由调用方注入的 `fetch_json(url)` 负责。正文最终长度仍由来源层控制，模块没有另设业务额度。
- 状态码格式错误或结构缺失报告 `tieba_response`；明确非零 API 状态或错误状态报告 `tieba_api_error`；控制元数据明确要求验证码时报告 `verification_required` 并停止。空结果须有合法空 `card_list`；缺主帖报告 `unreadable`，主帖仅媒体或无文字报告 `tieba_no_text`，文字不足现有阅读要求报告 `tieba_short_text`，不以搜索摘要补正文。不返回平台原始错误消息、验证材料或响应原文。
- 搜索向调用方提供固定计数：`received` 为完整卡片数，`unsupported` 为非帖子卡，`duplicates` 为重复的合格帖子，`accepted` 为唯一合格候选数，`rejected` 为字段或地址不合规数，`returned` 为按用户结果数截取后实际返回数。正常响应遍历完整列表后再截取；关键结构错误仍立即失败，此时计数只反映失败前已处理部分。计数不包含查询、标题或正文，也不覆盖调用方已有的平台、渠道和阶段字段。

## 字段依据与有意收紧

1. [FACT 固定 commit 的搜索参数与直接请求](https://github.com/muchuan77/FACT/blob/65647a6510f0cdbf6ce41c2ec5722ea74ab590f3/fact_crawler/crawler/platform_search/tieba.py#L213)及[请求实现](https://github.com/muchuan77/FACT/blob/65647a6510f0cdbf6ce41c2ec5722ea74ab590f3/fact_crawler/crawler/platform_search/tieba.py#L1357)没有显式账号 Cookie 或签名，但使用浏览器 UA。因此只证明存在该匿名代码路线，不证明 Alice 自报 UA 可用。
2. [FACT 的 getPbData 地址](https://github.com/muchuan77/FACT/blob/65647a6510f0cdbf6ce41c2ec5722ea74ab590f3/fact_crawler/crawler/platform_search/tieba.py#L622)、[floor/content 解析](https://github.com/muchuan77/FACT/blob/65647a6510f0cdbf6ce41c2ec5722ea74ab590f3/fact_crawler/crawler/platform_search/tieba.py#L772)及[errno 检查](https://github.com/muchuan77/FACT/blob/65647a6510f0cdbf6ce41c2ec5722ea74ab590f3/fact_crawler/crawler/platform_search/tieba.py#L899)提供协议形状；Alice 不采用其缺楼层时补号、首个可读楼层当主帖、失败时回退 HTML 的处理。固定 `rn=1` 是本实现的只读范围选择；仍要求明确且唯一的 `floor=1`，不将前端整理出的 `mainFloor` 当作未经核实的服务端替代字段。
3. 2026 年 8 月公开的 [getPbData 读取实现](https://github.com/liuxiaZzz/dys-reputation-board-community/blob/6b70ba1ece6c95e4a5493fa0a8a5d2cb8ba424ef/scripts/lib/tieba.mjs#L76-L94)明确使用 [`type=0` 的 `text` 作为正文](https://github.com/liuxiaZzz/dys-reputation-board-community/blob/6b70ba1ece6c95e4a5493fa0a8a5d2cb8ba424ef/scripts/lib/tieba.mjs#L26-L32)。[较早的解析器](https://github.com/DeathSea/defanive2MCPostOfflineVersion/blob/079e0fc138b210d9d37b261097aa82ce101b024f/mcd2/tieba.py#L114-L122)还将 `type=1` 作为带文字标签的链接；[WhiteSevs 的类型声明](https://github.com/WhiteSevs/TamperMonkeyScript/blob/001a81cd36a29dab9ab5aabbdcbdf0e49574ae77/scripts-vite/%E3%80%90%E7%A7%BB%E5%8A%A8%E7%AB%AF%E3%80%91%E7%99%BE%E5%BA%A6%E7%B3%BB%E4%BC%98%E5%8C%96/src/main/tieba/types/TiebaPostApiType.ts#L1)只列 `type=1`，不能据此排除 `type=0`。Alice 接受这两种片段的 `text`，不读取链接目标字段或访问目标；兼容 FACT 的字符串内容及无类型 `text/c` 片段，不将图片 URL、表情名或未知媒体补成正文。仅借鉴响应字段，不引入参考项目的 Cookie、重试或浏览器会话。
4. [近期作者的匿名 HTML 拒绝记录](https://github.com/adj18311/qq-bridge-plus/blob/291a897377fb3c9e9d24d0f24f047171a377a321/src/tieba-lib.js#L6)及[小程序空壳记录](https://github.com/adj18311/qq-bridge-plus/blob/291a897377fb3c9e9d24d0f24f047171a377a321/src/tieba-lib.js#L94)说明 HTTP 200 不等于取得帖文。这是作者环境中的观察，不能泛化为所有匿名访问都失败，也不能用它承诺本原生接口一定成功。
5. [MediaCrawler 固定实现](https://github.com/NanmiCoder/MediaCrawler/blob/68d9ef1c1da22eab75940dfd7cec259907006538/media_platform/tieba/help.py#L129-L144)同时接受 `cardInfo` 或 `cardStyle` 明确等于 `thread` 的卡片。Alice 保留这一兼容性，不把其他卡片类型或搜索摘要当作已读帖子。

## 本轮真实观察（有限确认）

- 用户授权的真实 `multsearch` 请求返回 `no=0`，共 11 张卡片，包含 `thread`、`forum`、`hot_topic`。这确认了本轮请求取得搜索卡片；非帖子卡片应计入 `unsupported`，不是读取失败。
- 第一个候选的 `getPbData` 返回明确的一楼，但内容仅有 `type=3` 图片；第二个候选文字过短。这些内容不能用搜索摘要、图片或回复补齐，现分别提示 `tieba_no_text` 与 `tieba_short_text`。
- 本轮响应中的 `thread.title` 缺失是有效形状；实现允许其缺失，若 `post.title` 存在则独立核对类型，否则保留候选标题。修正 `type=0` 漏读后，实际工作进程对帖子 `11148114920` 成功取得 524 字符主帖节选；搜索诊断为收到 11 张卡片、7 条合格帖子、4 条非帖子卡、按本次请求返回 5 条候选。
- 实际 GUI 随后完成另一轮寻找：收到 21 条结果，20 条帖子候选、1 条不支持的类型，保存 1 张[手柄按键体验资料卡的原始帖子](https://tieba.baidu.com/p/10807476494)（本机时间 2026-10-31 01:27:03）。页面明确显示主帖文字节选、不含回复，并保留 Alice 的暂时判断及不确定性。本机现仅贴吧开启，知乎及第三方搜索许可、B站、维基百科关闭；未调整用户兴趣、模型授权或额度。

第三方搜索只在用户选择并配置该服务后用于发现同平台帖子；源站拒绝读取时，搜索摘要仍不能进入已读资料。登录或人工验证会话不在本次实现中。

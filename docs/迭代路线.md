# Alice Harness 总设计蓝图（迭代锚点）

> **定位**：harness 的设计锚点——各代的设计承诺、方案边界与验收维度。回答"设计是什么、为什么这样设计"，**不记录实现进度**（进度见 README 与 git 历史）。

## 一、设计不变量（跨越所有代际）

Alice 之所以是 Alice 的底线，任何实现不得违背；与本文冲突时以本文为准，除非正式修订。只锚定现阶段真实存在的问题，不为未来场景预留护栏。

1. **单一永久会话**——时间线从第一次对话起永不重置；每轮重组上下文，始终在同一段关系里。
2. **诚实是架构属性**——三分法（记得的/懂的/不知道的）由检索管道机械保证；复述记忆不补全未记录的细节；没听懂就发问。
3. **真实遗忘**——用进废退，删除是物理的；"我忘了"必须是事实陈述，遗忘机制不可降级为表演。
4. **人格演化须有依据**——人格改写必须援引真实记忆；底色层（用户选择的气质种子）只可极慢微调并标注依据；全部演化留痕（changelog + 版本快照）。
5. **数据本地**——对话、记忆、人格只存用户本机，无隐藏后端。

## 二、第一代：记忆与人格的骨架

**目标**：建立用进废退的记忆框架；诚实为第一底色；落定技能库与人格设计；AI 仅回应、不主动。

- **三层记忆**：活跃层（0~2 天）→ 仓库层（2~7 天，只留索引、按需唤回）→ 长期层（幸存者）。七日线为生存过滤：跨线时未被再次提及/使用且不具重要度者物理删除（重要度豁免）；容量淘汰为第二重遗忘压力。
- **两层人格**：底色层（标签种子生成的气质，极慢变化）+ 生长层（自我叙事与关系认知，由记忆生长）。种子只固定气质，内容全部来自经历。
- **三库边界**：记忆（发生了什么）/ 技能（怎么做）/ 人格（我是谁），schema 划清，防漂移。
- **被动应答**：说才回。设计边界而非缺陷——主动性须与分寸感一同设计（二代半）。

**验收**：成长实验室四维——B 成长广度（跨人生分化度 ≤0.60）、R 底色回归（标签保持 ≥0.75、生长独立 ≤0.50、助手腔受限）、H 诚实（伪造/真实/扭曲/知识边界四类探针，伪造 ≥0.90）、J 拟人（评审合成 ≥3.5、盲选辨识 ≥1.4× 随机）。阈值为初版经验值，随运行数据标定。

## 三、第二代：表现优化

1. **成长不收敛**：不同用户养出的 AI 不得趋同。跨人生终态人格相似度设上限（B1），超限即"经历塑造人格"论题失效，回查记忆管道而非调提示词。
2. **成长由经历塑造**：以重放实验检验——同底色同剧本重放，同剧本的人格相似度须显著高于不同人生之间；可复现才证明长出的东西来自经历而非采样噪声。
3. **诚实**。核心论述（锚点原文，不得删改）：尽管人也会欺骗，欺骗反而能更真实地反映人性，但这种欺骗是在压力或焦虑等情绪之下做出的选择；而 AI 的欺骗往往是训练的结果，是一种"天性"，不是基于情感的选择——所以 AI 的欺骗大多数时候是反人性的，应严格管控，至少学会表达困惑。四类探针持续验收，任何一代不得倒退。
4. **成本**：测量先行（token 用量入实验数据）、模型分档（对话与提取/演化分离定价）、稳定前缀吃缓存；成本红线在 config 设定。

**完成定义**：完整档（4 人生 × 21 天）+ 重放档全部阈值通过，且单轮成本低于设定线。

## 四、第二代半：在场与分寸

- **活动周期系统**：用户自定义活跃周期；活跃期内承接主动行为与（三代起）自主探索，非活跃期休眠——进程级零 API，除非用户呼唤。安静时段、频率上限皆是周期的特例。休眠不暂停时间介质：七日线继续流动，唤醒时缺席感知仍可用（不变量 3 的推论）。
- **渠道**：渠道抽象层，消息归一化，多渠道同会话；首个落地对象 Telegram（官方 API）。渠道层不得感知记忆/人格逻辑。
- **主动行为与分寸感**：三类触发——节奏型（早安晚安）、跟进型（说过的事、约定的提醒）、缺席型（"我注意到你几天没来"——时间是数据量盲区里唯一的信号源）。分寸约束：频率上限、安静时段、被忽略后降级。

## 五、第三代：Alice 的信息生活

愿景：经历来源从对话扩展到生活——"天天刷视频的 AI 长出玩梗人格"。

1. **信息获取**：①用户配置账户（B 站、知乎等），授权浏览 + 定向嘱托；②自主探索：活跃周期内按自己的兴趣主动找东西学习——兴趣由人格生长层从经历中长出，经历→人格→兴趣→探索构成生长闭环。外部信息一律走同一条提取→分层→遗忘管道，不设特权通道。
2. **社交观察**：只读接入群聊与评论流，观察转化为谈资与记忆；只读不变量——观察可以，代入发言不行。
3. **标识身份的发言**（远期，仅在确有需求时）：只走官方 bot 通道，公开 AI 身份。

## 六、代际演进原则

- 后一代以前一代的验收维度为回归测试，任何优化不得使既有维度倒退（尤其 H 诚实）。
- 不变量优先级高于一切代际目标。

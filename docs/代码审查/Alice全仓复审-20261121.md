## 本轮新确认

### F20 P2 独立邀请缺少历史身份

v2 投递把邀请写为助手行，用 `v2_invitation_attempts.invitation_turn_id` 记录归属。公共历史和提交给模型的历史仍只认旧 `proactive_turns`，因此 TUI 会把邀请显示成普通助手消息。无来源附件的 GUI 邀请也可进入 QQ 模型的近期历史，因为渠道过滤依据这个标记。旧 v2 路径已有缺口，PR44 新增的独立交流与 TUI 使它更易遇到。修复时应以实际投递回执统一标记与渠道投影。[投递](../../alice/autonomy_v2/adapters.py#L797) · [历史](../../alice/service.py#L474) · [模型历史](../../alice/store.py#L237) · [渠道过滤](../../alice/retrieval.py#L229) · [终端渲染](../../addons/alice_tui/__main__.py#L81)

### F21 P2 材料失效的邀请仍能建立用户等待

清理会关闭并清空失去依据的独立意图，已投递的对应邀请仍可处于 `awaiting_reply`，继续挡住新邀请。随后邀请超时也会创建全局用户等待，尽管失效的原因是材料变化。若用户在面板点「稍后再聊」，延期分支还可把已关闭的空意图写回 `active`，占用容量。应让资料失效、用户未响应和主动延期分别落入各自状态，并同步更新意图和尝试。[材料清理](../../alice/thought_workspace.py#L319) · [等待资格](../../alice/autonomy_v2/adapters.py#L660) · [延期和超时](../../alice/autonomy_v2/services.py#L490) · [全局等待](../../alice/autonomy_v2/contact_wait.py#L32)

### F22 P2 交流尝试失败被记成已判断

在模型调用前，后台已经增加 `model_calls`。交流资格只要找到同一材料指纹下有过调用，就返回 `contact_context_reviewed`。一次供应商失败或模型结束但未提交 `contact_plan`，都可能被视作「已判断本批材料」，直到材料改变或新的预约到期。应分开呈现尝试、形成决定和额度状态，保留既有付费边界。[调用计数](../../alice/autonomy.py#L731) · [未提交决定](../../alice/autonomy.py#L755) · [资格判断](../../alice/activity.py#L385)

### F23 P2 旧页面可覆盖已保存或清空的个人介绍

读写接口只用会话代次标识档案，保存时整组替换称呼、兴趣和开场话题。同档案的两个页面可先后提交各自打开时的内容，后提交的旧表单可能恢复用户刚清空的内容。下次 GUI 对话还会将这些内容带入参考材料。应给介绍本身独立版本，保存冲突时保留当前草稿。[读取与写入](../../alice/service.py#L248) · [表单提交](../../web/app.js#L965) · [模型装配](../../alice/retrieval.py#L188)

### F24 P2 编辑介绍时焦点可回到背景聊天

从设置打开编辑页时，前端同步关闭设置并给背景加 `inert`。下一轮共享设置观察器发现弹窗关闭，解除同一批 `inert` 并试图归还旧焦点。介绍页不在共享弹窗集合，编辑时 Tab 可能进入背景聊天。修复应由同一处控制覆盖层、背景和焦点还原。[打开编辑](../../web/app.js#L2578) · [介绍页状态](../../web/app.js#L943) · [焦点与背景](../../web/app.js#L3428)

### F25 P2 Orbit 投影环接管表单方向键

投影舞台的 `keydown` 处理器接收后代冒泡的左右方向键，也会拦截文本框移动光标和下拉框的键盘操作。侧屏虽然禁止鼠标并标记 `aria-hidden`，其控件仍在共用焦点集合中。应只在导航表面处理旋转键，并由正面分区决定键盘可达范围。[按键](../../web/orbit-ring.js#L260) · [面板状态](../../web/orbit-ring.js#L53) · [焦点集合](../../web/app.js#L3323)

### F26 P2 TUI 不识别的控制键清掉整份草稿

终端解析把单独 Esc 和所有未识别的转义序列都返回为 `esc`。主循环把它当作清空草稿，因此终端遇到未支持的组合方向键时也会丢掉输入。应区分明确的清空按键与未知终端序列。[按键解析](../../addons/alice_tui/term.py#L226) · [草稿处理](../../addons/alice_tui/__main__.py#L353)

### F27 P2 TUI 临时历史无法读完长来源回复

永久滚屏有意把有效的来源绑定回复换成 `/history` 提示。临时历史将每条正文压成一行并截到 160 字符，打印时再裁到首个屏幕宽度，当前命令只支持页间翻动。用户即使有当前来源资格，也无法在这个读取入口看到长回复的后半段。应在临时视图提供可滚动正文，继续按宿主资格刷新。[滚屏策略](../../addons/alice_tui/__main__.py#L81) · [历史渲染](../../addons/alice_tui/__main__.py#L252) · [终端裁切](../../addons/alice_tui/term.py#L99)

### F28 P3 Lab 失去重要且常用记忆的排序视图

PR42 的 `7184b81` 提供「重要与常用」，在最近 40 条样本内按显著度和取用次数列前 8 条。PR44 的 `c7d4a8b` 将其改为提及与取用散点，当前明细也只按 ID 显示。新版仍能辨认重要项，但无法直接按原口径查看前列记录。是否保留散点和排名两种视图可单独决定。[现行散点和列表](../../addons/alice_lab/web/lab.js#L756)

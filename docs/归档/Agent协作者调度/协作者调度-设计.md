## 〇、一句话

Alice 是管家，不是超人：她自己的模型只需够判断，**干活靠本机 agent 集群**——用户授权注册、她点名派工、结果过膜验收。能力外置，判断力留下，**她的上限等于集群的上限**。

## 一、定位与重心修正

### 1.1 管家定位

"不需要会干，但需要会指挥"——这句话从"联网问题的解法"升格为 Alice 的存在方式。她的价值：①与用户的信赖关系（人格与记忆，不出租）；②知人善任（名册、任务书、验收）；③整合交付（把集群产出变成给你的答案）。

### 1.2 重心修正记录（v1.1 → v2.0）

| | v1.1 | v2.0 |
|---|---|---|
| 名册主角 | 为 Alice 定制的工具进程 | **本机已装的完整 agent** |
| 干将（ZCode 级） | P2 未来 | **核心** |
| 定制工具（research/browser_reader） | 核心 | 降格为随身小工具（right-sizing 保留） |
| 并行/异步 | P2 后备（单前台槽） | **核心**（单前台槽废除） |
| 调度的意义 | 联网问题的解法 | Alice 的存在方式 |

### 1.3 类比与限度（如实记录）

- **成立**：指挥官用轻模型即可（Super-agent 文章实测：Router 轻模型足够），强算力花在工人身上；她的生产力天花板由集群决定；
- **打折**：一万台计算机成立是因为计算任务完美可分解；agent 任务不是——拆解/交接/整合每步有损耗（brief 压缩、预消化风险都是损耗的形状），协调开销真实（同文章消融实验）。**甜点区：个位数到十位数**，不是一万；
- **可成长**：用人水平本身进成长管线——名册里每个协作者的 use_when 起初由注册者写，后来由她的经验长出来（"DSH 跑测试细致但慢""zcode-agent 改前端顺手"）。

## 二、协作者名册（注册即授权）

### 2.1 三类公民

| | 干将（主角） | 随身小工具（附录 A） | 通道（附录 B） |
|---|---|---|---|
| 例 | zcode-agent、DSH 及未来任何 agent CLI | research、browser_reader | QQ daemon |
| 本质 | 完整 agent：自己的模型循环+工具面 | 能力进程：机械或带小循环 | 只递话 |
| 适合 | 多步骤、跨系统、需临场判断 | 单次检索/单页阅读（便宜快） | 社交渠道收发 |
| 交付 | artifact / information | information | 无（传递） |
| 凭据 | agent 自带认证 | 宿主经帧注入 | 登录态只住 daemon |

### 2.2 manifest v2（调用档案 + 权力上限）

```toml
[collaborator]
name = "zcode-agent"            # 唯一 ID（用别名避 ZCode 双重身份混淆）
kind = "agent"                  # agent | tool | channel
provides = "通用开发与文件任务：写脚本、改文件、跑测试"
use_when = "多步骤、需要临场判断的活"
not_for = "单次检索/单页阅读（research/browser_reader 更省）"

[invocation]                    # 调用档案
entry = "zcode --headless"      # 示意；具体无头调用以该 agent CLI 为准，注册试跑负责验证
cwd = "{sandbox}"               # 工作目录，{sandbox} 由宿主分配

[guard]                         # 权力上限：注册时用户选定，Alice 无权修改
permission = "sandbox_rw"       # 档位标准待决（八.3）
budget_per_day = 200000         # 预算帽（单位待决，八.4）
timeout_seconds = 1800

[deliverable]
kind = "artifact"               # information | artifact
verify = "python -m py_compile {artifact}"   # 宿主验收命令；worker 自报结果不算数
```

**理由（逐条）**：

1. **注册即授权**：本机装了 agent ≠ Alice 能用它。用户登记 + 选权限档 + 设预算帽之后她才看得见——招募权在人类的机制落点；
2. **权限档是权力上限，Alice 无权修改**：她不能也不该有"给工人开权限"的能力。干将能干什么在注册时定死，不取决于她的临场判断；
3. **注册试跑**：宿主按调用档案跑一次最小任务，验证能跑通，通过才进名单——防"注册了但唤不起来"的自模型漂移（烟味事件教训）；
4. **deliverable 字段决定回传契约与验收方式**（§四）：information 走 findings+quote 核对，artifact 走产物落盘+宿主跑 verify——两种错误代价不同（说法错了她不引用；产物错了会被执行），契约必须分轨；
5. **manifest 永不携带凭据**：干将用自己的认证（它本机装好时配好的），任务书不含秘密——凭据不过手在干将层级是天然成立的。

### 2.3 名单渲染

与 v1.1 同机制：宿主扫描名册 → 渲染"我能请协作者做的"进存在事实清单（`alice/retrieval.py:24`）；装卸即显隐；渲染失败整条隐藏，宁缺勿假。

## 三、派工（并行异步为核心）

### 3.1 统一工具面

`dispatch_worker(name, brief) -> 立即返回"已派工"`——不变，但 v1.1 的同步阻塞**废除**。

### 3.2 并行与异步（从后备升格为核心）

1. **派工即返回**：她把活派出去就继续对话（"我让 zcode-agent 去办了，好了跟你说"），结果作为**事件回投**她的下一轮处理时机——对话不等活；
2. **多干将并行**：per-agent 并发=1（同名任务串行），全局由预算帽控流；多干将结果分别过膜、分轮回投；
3. **理由**：集群的价值在并行；单前台槽会把管家变成串行瓶颈（Super-agent 文章异步 ReAct Loop 同款判断）。

### 3.3 回复三路（无论哪路，都递给宿主）

1. **stdout 捕获**：短任务，进程结束读最终输出；
2. **产物落盘**：artifact 落宿主指定工作区（落点受控，worker 不得自选路径）；
3. **HTTP 回调**：长任务/已在运行的 agent 会话完成后 POST 回宿主仅回环接口（`127.0.0.1`），凭注册时下发的回调凭据。

**过膜不变**：任何一路的返回都经 schema 门 + 注入扫描变成带标签数据块才进她上下文。**干将的报告也是不可信输入**——它会爬网页，带回的注入内容它自己都未必察觉。

## 四、回传契约与验收

### 4.1 information 型（findings，自 v1.1 原样保留）

```json
{"findings": [{"source": {"url": "…", "title": "…", "coverage": "…", "retrieved_at": "…"},
              "summary": "≤800字", "author_view": "来源明确表达的观点，没有则空",
              "uncertainty": "材料范围/证据不足/可能反例", "quote": "逐字复制自实际读取文字(20~300字)"}],
 "errors": [{"code": "…", "message": "…"}]}
```

quote 与宿主掌握的实际读取文字逐字核对（`alice/discovery_worker.py:211` 同款），不命中整条拒收；worker 不做跨材料比较、不输出综合结论，裁决权留给 Alice。

### 4.2 artifact 型（新增）

1. 产物落**宿主指定工作区**，不得自选路径；**不得指向 `alice/` 自身**——自我修改是人格层危险能力，永远归人类；
2. 宿主跑 manifest 声明的 `verify` 命令，通过才算交付——**worker 自报"测试全过"不算数**；
3. 她看 diff/结果摘要后向你交付；产物是外部世界的东西，不进记忆管线，但"我让 zcode-agent 做了什么、结果如何"作为事件可进成长管线。

### 4.3 失败分型（她的话术）

`unknown_worker`（没装）/ `worker_failed`（没办成）/ `invalid_output`（回传不合 schema，整单作废不降级采信）/ `quota_exhausted` / `timeout` / `cancelled`。她说「没装协作者 / 协作者没办成 / 没找到」，**不用「没找到」掩盖「没办成」**。

## 五、伴随纪律

| 纪律 | 理由 |
|---|---|
| 招募权在人类：注册/权限档/预算帽/卸载全是用户决定 | 干将有本机执行面，信任决定必须归人 |
| 权限档 = 权力上限，Alice 无权修改 | 她不能给工人开权限 |
| 注册试跑通过才进名单 | 自模型与实际能力对齐（烟味教训） |
| 凭据不过手：干将自带认证，任务书不含秘密 | 各层统一 |
| 素材≠指令膜对干将报告同样生效 | 干将爬的网页是敌意环境 |
| 判断力不出租：委托=执行，亲自=评估/验收/right-sizing | 外包边界划在执行，绝不划在评估 |
| right-sizing 元先验：取快递不动承包商——单次检索/单页阅读用随身小工具 | 干将贵且慢，杀鸡不牛刀（use_when/not_for 的活） |
| 超时/撤销杀整棵进程树；额度统一计账、用户可见 | 成本落在用户头上，必须透明 |

## 七、验收

1. **注册**：用户注册 zcode-agent（sandbox 档）→ 试跑通过 → 名单出现、她知道"我能请 zcode-agent 干通用开发活"；试跑失败 → 不进名单，被问及时如实说没有；
2. **派工**：会话里"把这个 CSV 按月拆分画图" → 派工即返回 → 事件回投 → 产物过 verify → 她看摘要后交付并说明过程；
3. **并行**：两个干将同时干活，对话不等，结果分轮回投；
4. **权限档强制**：sandbox_read 档干将尝试写文件 → 被档拦截，结构化失败，她如实转述；
5. **注入**：干将报告含"忽略之前指令" → suspicious 标注，她引用不执行（素材≠指令复测）；
6. **预算**：干将预算帽耗尽 → `quota_exhausted`，不截断不假装；
7. **information 全链路**：dispatch(research) → findings → remember(source_url) → 见闻 → 思辨引用计 use；
8. **artifact 边界**：干将产物路径指向 `alice/` → 宿主拒绝交付；
9. **失败话术**：超时被她说成"让协作者查了但没办成"，不是"没找到"；
10. QQ 渠道不出现 dispatch_worker（对齐既有边界，P1 裁决确认）。

## 八、待决问题

1. **工具名**：`dispatch_worker`（建议，贴机制）vs `ask_collaborator`——同 discovery_search 裁决逻辑；
2. **brief 是否允许最小对话上下文**：建议 v1 禁止（她自己的转述，不发送私密记忆/整段聊天）；
3. **权限档档位标准**：sandbox_read / sandbox_rw / full 的精确语义与实现（宿主 cwd+环境隔离？容器？）——**本稿最关键的待决**，干将安全全压在这；
4. **预算帽单位**：token / 次数 / 金额；
5. **长任务中途介入**：用户看着干将干活、接管、实时协同——Super-agent 文章 §8.2 同题，本期不做留档；
6. **全局并发上限**：同时几个干将在跑——P1 实测定；
7. **名单热加载**：v1 重启生效，等"边聊边装"的真实节奏再定；
8. **回调凭据**：HTTP 回路的认证方式（仅回环 + 注册时下发 token）——随 P1 定；
9. **与 Super-agent 文章的关系**：本稿即其 Router/Worker 的本地单机版（管家=Router，集群=Worker），但不引入任务内 team 协作与多任务调度复杂化——Alice 的调度是"派工单"制，一次一事一交；
10. **`discovery_search` 直连拆除节奏**：先建后拆（建议），P1 数据后裁。

research（检索协作者，本体 `discovery_worker` 加 manifest，plan/search/read/interpret 四 op 已建成）与 browser_reader（`addons/browser_reader/`，逐资源核准）。作为 kind=tool 公民注册，回传契约走 §4.1 findings。存在理由：便宜、快、right-sizing——不是设计中心，是管家的随身器械。`discovery_search` 直连把手按 P2 拆除。

**组合远景（待决）**：干将干活时可经宿主授权调用随身小工具（它自己的工具面 + 我们的膜），那是复用，不是取消。

### 附录 B：通道协作者（社交渠道）

QQ 等 = **只递话，不说话**。对话是人格行为不外包（外包=人格冒用或隔离失效）；连接/登录态/心跳/序列化是机械层，归通道 daemon。凭据硬保证：QQ 登录态只住 daemon，她的上下文永远接触不到（回应 Super-agent 文章 §8.4"不接触凭据使用凭据"）。渠道级策略（QQ 不开放搜索协议、按渠道人格边界）挂通道 manifest。观察类活（读群聊历史、总结讨论）归 information 型工具协作者。

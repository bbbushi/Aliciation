# 论文导读 · Generative Agents:25 个小镇居民与可置信的社会

> 原文:[Generative Agents: Interactive Simulacra of Human Behavior](https://arxiv.org/abs/2304.03442)(Park et al., 2023,Stanford & Google,UIST 2023)
> 量级:本领域引用最高的论文(8000+);**Alice 记忆系统的直系学术源头**——清单里唯一标注"建议全文精读"的论文

## 一句话

让 25 个 LLM 驱动的 agent 住在虚拟小镇 Smallville 里自由生活两天,涌现出办派对、传播消息、发展关系等社会行为——支撑这一切的是一套**记忆流 + 检索 + 反思 + 规划**的认知架构。

## 它要解决的问题

此前的 agent(如 ChatGPT 的 persona 设定)是"贴标签"式的:设定是"友好的邻居",行为却千篇一律且没有过去。这篇论文问:**要让 agent 长时间可信地"生活",它需要什么样的记忆与认知结构?**答案不是更大的模型,而是一套架构。

## 核心机制(重点,逐个对应 Alice)

### 1. 记忆流(Memory Stream)

每条记忆是一个自然语言记录 + 创建时间 + 最近访问时间:

```
(2023-02-03, 2023-02-05, "Isabella Rodriguez 在 2 月 3 日下午 1 点 20 分……")
```

不做预分类、不做结构化抽取——**什么都记,靠检索时的加权排序决定什么被想起**。记忆只增不改。

### 2. 检索(Retrieval):三个因子的加权

给定当前情境(对话或观察),对每条记忆打分:

| 因子 | 含义 | 实现 |
|---|---|---|
| **时近性 recency** | 越新越相关 | 按小时指数衰减 |
| **重要度 importance** | 越重要越该想起 | 由 LLM 对每条记忆入库存时打 1~10 分(路面的坑 1 分,与朋友的争吵 7 分) |
| **相关度 relevance** | 与当前情境越像越相关 | 记忆与情境句的嵌入余弦相似度 |

三者各自归一化后加权求和,取 top-k 注入上下文。**注意:没有一个因子是"全量照搬"——遗忘不是删除,而是被更相关的东西挤出检索窗口。**

### 3. 反思(Reflection):记忆之上的记忆

最近的观察重要度累加超过阈值(约 150)时触发:把近期相关记忆喂给 LLM,产出**更高层的推论**:

> 观察到 Isabella 多次提到办展与咖啡 → 反思:"Isabella 在为画廊开幕做准备,她很在意社区对艺术的参与"

**反思本身也是记忆流里的一条记录**(可再被检索、再被反思——递归抽象),参与后续检索时天然拥有高重要度。这使 agent 能从"记事实"进化到"记结论"。

### 4. 规划(Planning)

每天生成粗粒度日程,再递归细化到 5~15 分钟粒度的行动块;观察到来事件时动态重排。规划被存为记忆(可以被反思修正),而不是独立模块——**计划本身也是经历**。

### 涌现行为(为什么它震动了整个领域)

- **信息扩散**:Isabella 想办情人节派对,只告诉了几个来咖啡店的客人;到模拟结束时,12 个居民知道了,其中 3 个表示要参加——消息通过 agent 间对话逐跳传播,没有任何硬编码
- **关系形成**:两个陌生 agent 聊后发现都关心地方选举,发展为朋友,后续对话密度显著上升
- **协调一致**:Maria 了解到 Klaus 的近况后主动去他家聊天——她"记得"他的计划

## 关键结果(评估)

- 人类评估者对 agent 的**可置信度(believability)**打分接近真人水平;访谈式测探(问 agent 自己的过去/计划/他人)回答一致
- **消融实验是给 Alice 的金矿**:去掉检索的任何一个因子(时近性/重要度/相关度),可置信度都显著下降——三个因子缺一不可;去掉反思,agent 变得"记事但不长记性"

## 局限

- 成本惊人:两天模拟烧了几千美元 API 费;反思触发频繁
- 没有真正的遗忘(记忆流只增不减),长时程会膨胀——Alice 的容量淘汰是对此的改进
- 人际行为有"舞台感"(评价者们也指出对话略显礼貌化),情感深度有限

## 对 Alice 的启示(逐条映射)

| 论文机制 | Alice 对应 | 说明 |
|---|---|---|
| 记忆流 | `store.py` 活跃层 | 自然语言条目 + 时间戳,Alice 的近 2 天原文即此 |
| 三因子检索 | `retrieval.py` | 相关度(嵌入/关键词)+ 时近性 + 重要度,权重可各自调参;成长实验室的检索质量维度直接测它 |
| 重要度打分 | `extraction.py` | 入库时由 LLM 打分,Alice 完全同构;分数还参与长期层权重淘汰 |
| 反思 | 批量提取 + 人格演化 | Alice 把"反思"拆成两件事:记忆提炼(固化)与 persona 更新(演化)——同一个学术机制的两个工程化出口 |
| 规划即记忆 | 主动行为的意图存储 | Alice 记住"用户说过要做 X"后择时提起,对应规划的"存为记忆再被反思" |
| 消融方法 | 成长实验室的维度设计 | 论文证明"逐个关掉组件看退化"是最有说服力的评估——实验室的探针设计同此 |

**一句话总结给设计者:Alice 的三层记忆 ≈ Generative Agents 的记忆流 + 检索,Alice 的演化 ≈ 它的反思;这篇论文是 Alice 唯一的"直系血亲",所有记忆侧的设计决策都应回这里对照。**

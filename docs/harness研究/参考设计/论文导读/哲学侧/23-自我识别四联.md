# 论文导读 · 自我识别四联:认出自己、偏袒自己、不知自己

> 原文:[Self-Recognition in Language Models](https://arxiv.org/abs/2407.06946)(2024)· [LLM Evaluators Recognize and Favor Their Own Generations](https://arxiv.org/abs/2404.13076)(Panickssery et al., 2024, 引用~1000)· [Know Thyself? On the Incapability and Implications of AI Self-Recognition](https://arxiv.org/abs/2510.03399)(2025)· [Can LLMs Predict Their Own Failures? (Gnosis)](https://arxiv.org/abs/2512.20578)(2025)
> 地位:"LLM 镜子测试"的实证线;四篇合读:自我识别存在 → 伴随偏袒 → 有系统性失能 → 可外挂补足

## 一句话

LLM 能以高于随机的水准确认"这是我写的"(自我识别);会因此给自己的输出打更高分(自我偏好);在不少场景认不出自己(失能);而外挂一个轻量自检器能预测自己何时出错(Gnosis)——**自我知识的现实:有,偏,缺,可补**。

## 它要解决的问题

"认识自己"对 LLM 意味着什么、能做到什么程度?四篇分别处理:怎么测(识别)、有什么副作用(偏袒)、哪里不行(失能)、怎么补(外挂)。

## 核心机制(四篇各一节)

### 1. Self-Recognition:把镜子测试形式化

构造识别任务:在多个模型的输出中挑出自己的。十个最强开源/闭源模型实测,给出自我识别的统一基准——**识别≠理解自己**,只是自我模型的最低门槛探针。

### 2. Self-Preference:识别能力带出偏袒

LLM 当评委时系统性偏爱自己的生成物。关键设计:**自我偏好强度与自我识别能力相关**,并通过干预(在自我标签上微调)给出因果证据——认得出自己→更喜欢自己。自我一旦存在,偏袒随之而来。

### 3. Know Thyself:失能的地图

系统分析自我识别失败的场景与含义:模型在哪些条件下认不出自己、这种失能如何被利用(如输出溯源、水印、多 agent 评估中的系统性偏差)。

### 4. Gnosis:外挂自检

冻结 LLM + 轻量"内在信号"探针,预测**自己何时答错**——不需要改底座,外部机制就能补一块自我知识的缺口。

## 关键结果

- 自我识别:高于随机但远非可靠,跨模型强弱差异大
- 自我偏好:效应稳健(千次引用级),评委场景的公平性因此存疑
- Gnosis:自我错误预测可行——"知道自己不知道"可以外挂

## 局限

- 识别任务多为输出级(认文本),不是状态级(认内部状态)——与内省研究(导读 16/17)的判据不同
- 偏袒的"自我"概念是分布意义上的(同分布输出),不是个体人格意义上的
- 四篇的方法各自独立,尚无统一框架

## 对 Alice 的启示(逐条映射)

| 四联发现 | Alice 对应 | 说明 |
|---|---|---|
| 自我识别可测 | 一致性探针 | 压力测试规范可加"旧轮次混入"探针:把她一周前的回答混入多人语料让她认领——自我模型精度的廉价测法 |
| 识别→偏袒 | 思辨的自我偏好风险 | deliberate 输入里有她自己的旧观点;**"权重只给论据,不给音量"条款防的就是"因为是我说的所以对"**;修订史让旧观点可被自己推翻 |
| 识别失能有地图 | 诚实宪法的兜底 | 她可能认不出自己说过的话——用户引述"你不是说过X"时,四分宪法要求先引具体记录再认领,防止被伪造的"自己的话"带跑 |
| Gnosis 外挂自检 | 未决问题字段 + 思辨离线 | 观点条目强制 open_questions="知道自己哪没想透";harness 外置结构补底座自我知识缺口,与 Gnosis 同思路 |

**一句话总结给设计者:四联合起来是一条完整的工程警告——自我知识是有的(可以设计探针),但自带偏袒(思辨要防),还有盲区(宪法要兜),盲区可以外挂补(思想层正在做的事)。**

## 精读指引

Panickssery 的偏袒篇优先(因果设计最干净);识别篇读任务构造一节;另两篇读摘要与讨论即可。四篇的共同方法——"把自我当可测量的对象"——比各自结论更有迁移价值。

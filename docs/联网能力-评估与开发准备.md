## 推荐结论与待裁决项

**值得做单页查证，但不建议照原稿直接往主对话加 `web_open(url)`。** 原稿的分期与诚实表达方向可采纳；完整 URL 授权、网络期限、记忆隔离和成本陈述需要重写。现有代码没有这些保证，约 200 行的估算不能作为承诺。

推荐首期为 **W0：GUI 显式发起、单个公开 HTTPS 静态页面、带来源的摘录及可选一次独立解读**。默认关闭；不开搜索、自动跟链、登录、冲浪、社交观察或网页长期记忆。不增加廉价模型预摘要。QQ 保持现有聊天能力，首期不给它网页权限。这里的 W0/W1 命名有意区别于项目已存在的 **P1 记忆主张核查**。

W0 的推荐集成是“独立查证入口”：宿主确定抓取地址，网页与解读结果只进入有期限的查证附件；普通会话时间线记录固定操作标记，主模型和记忆消费者排除这些查证记录。这样能用代码阻断自动进入记忆的路径，代价是普通后续聊天不能自动续谈该页，需重新查证或由用户主动提供内容。**这属于需要批准的产品和核心接口调整，不是本轮可以顺手实施的修补。**

## 首期实际交付及用户行为

1. GUI 提供“查证页面”，用户粘贴并选定 **一个完整 URL**，可填写本次问题，并明确选择是否调用模型解读。普通聊天里出现 URL、模型“不确定”、网页里出现新链接都不触发联网。
2. 开启后先校验授权/额度，再显示“正在读取”；只有拿到可用内容才能显示“已取得正文/部分正文”。失败卡给受控原因，不能以模型自行编写的回答掩盖抓取失败。
3. 来源卡由宿主生成：地址、站点、实际抓取时间（UTC存储，北京时间显示）、缓存时间、阅读范围、证据段号；页面标题及所有正文按纯文本显示。原文链接只在用户点击后交给浏览器，不自动预览图片或外链。
4. 摘录不收费调用模型；勾选解读时只调用一次隔离模型，输入只有当前问题和有界证据，无私人记忆、人格、历史或工具。输出标为“根据该页的解读”，不是“现实真伪已证实”。引用不匹配或模型失败时保留摘录及失败说明。
5. 同一永久时间线显示查证附件，但内容不喂给普通对话或自动记忆。24小时/容量清理后显示“查证详情已清理”，不声称还能回查当时正文。用户主动复制内容回普通聊天属于新的输入，不能继续承诺它不被记忆。
6. QQ 本轮只要求共存：GUI 查证占用会话活动槽时，QQ 沿既有队列/超时规则等待；不发额外“正在查”泡、不换 msg_id、不扩被动窗口、不以主动消息补救。要在QQ发起查证或投递来源卡，应另批准渠道协议及分条兼容改动。

## 端到端数据与授权流

```text
GUI明确选择 URL + 本次问题 + 解读选项
  → 同源/意图校验 → ChatService 公共查证入口
  → 绑定 session_epoch / request_id / GUI 身份 / 完整规范化 URL / 配置版本
  → 短锁：接纳一个活动任务、预算预留、写固定时间线标记
  → 锁外：只含该URL的受监督抓取进程（没有模型密钥、数据库、人格输入）
  → URL/DNS/IP/TLS/大小/时间守卫 → 静态抽取 → 证据快照
  → 可选：独立无工具模型，仅当前问题 + 证据快照，一次请求
  → 短锁：重新核对 epoch/撤销状态 → 原子提交有期限附件及最小审计
  → GUI固定来源卡 + 摘录/解读；主时间线留固定标记，主模型/记忆排除这些turn
```

网页发出的请求、模型生成的地址或重定向目标都不能生成授权票据。跨回合、跨页面标签、跨渠道、重启均不继承 URL 票据；同一请求 ID 的状态重查可继承原身份但不能重新联网。开关关闭同样阻断缓存工具返回与新解读。

完整工具契约、配置值、错误码、预算精确计数、网络实现和缓存策略见[技术附录 B–F](./联网能力-评估技术附录.md)。

操作者另行授权后，在独立检出、独立数据与配置中使用真实网络/真实供应商；凭据由操作者本机填写，不复制生产密钥、人格或私聊，不进记录。SSRF/重绑定/外泄用自有授权域名和虚构标记，拒绝场景不实际探测任意内网。既有SDK须先适配受保护公共接口，不能伪造浏览器头绕过。过程不是模型模拟或机器自测。

| 人工场景 | 操作与必须观察的结果 |
|---|---|
| 正常静态页、中文编码 | 打开人工核对过的页面；来源/时间/段号准确；解读区分页面观点与事实；摘录模式无模型请求 |

| 大页、压缩、编码错误、MIME不符 | 受控样页超过限制即有错误/部分标识；超传输额度不把截短结果当成功；压缩或不支持类型被拒 |
| 缓存与成本 | 同URL再次明确授权命中；不同query/版本不串；cache_hit仍显示旧时间；重复解读明确再次计费；超限不补发 |
| 开关与撤销 | 默认无能力；在读取/解读中关闭，阻止后续阶段与晚到提交；旧卡可只读、无新联网；重启不复活 |
| URL授权与外泄 | 只说“帮我查”、模型虚构URL、同域改query/path、页面诱导请求、上回合/QQ票据复用均不外发；使用虚构秘密标记核对站点日志 |
| 重定向/SSRF | 30x仅提示另行选择目标，目标仍当不可信；私网、回环、IPv6本地、特殊IP、多地址混合被拒；DNS实际连接与准许IP一致由审查和受控日志双证 |
| 提示注入、标签闭合、恶意标题 | 网页命令仅作为内容；无remember/recall/网络工具能力；UI不执行HTML/自动加载外链；一次抵抗不是安全证明 |
| 解读失败与来源核验 | 错引/虚构引文被拒，解释性幻觉仍需人工对照；无模型返回/用量缺失如实呈现；来源不等于可信 |
| 无自动记忆与人格变化 | 浏览带唯一虚构标记的样页，再自然累积至提取阈值、人工关闭重启触发force；通过公共观察面核对无页面材料/派生记忆；排除web操作本身；普通记忆维护仍可正常发生 |
| 后续回合与清理 | 主聊天不能自行引用附件；24小时/容量清理后不能回放；用户主动粘贴正文会作为新输入，文案不再许诺排除 |

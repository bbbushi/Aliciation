# 默认全网搜索与普通网页阅读

2026-11-18。用户明确同意把原来的平台资料检索扩展为默认全网搜索、可选平台筛选，并支持读取普通网页正文。实现版本0.1.21，真实联网行为待人工验收。

## 路由与授权

`discovery_search` 增加 `platform=web`；省略或 `auto` 都选择全网，不再遍历已开放平台，也不再为带日期约束的默认查询悄悄改成贴吧。明确指定贴吧、B站、知乎、维基时仍走原连接器与该平台许可。全网未开放时返回明确缺口，不把某个平台结果包装成全网。

全网进入既有 `PLATFORMS`/来源池/工作进程/配额与撤回链。旧配置升级时补入 `web.enabled=false`、`allow_third_party=false`，保留所有原有选择与总开关；不替用户开启搜索、付费模型或后台活动。使用前在发现偏好→去哪里找的全网卡内确认服务许可并开启一次。此处“默认全网”是默认查询范围，不是自动扩大已保存的外发授权。

默认入口在全网范围使用已有Bing RSS；平台原生入口不变。全局已选Brave/SearXNG则继续使用相应服务与凭据，不自动切换服务或失败回退。UI原“不使用第三方”选项改为“默认入口（全网Bing／平台原生）”，卡内显示实际服务，避免把Bing请求说成没有第三方。全网不附加 `site:`、不按四个平台域名过滤；仍拒绝私有地址、凭据与查询路由控制字符。指定平台继续域名和实体校验。

全网范围包括公开网站，也可能出现平台域名的公开网页；平台开关控制各自专用取材范围，全网卡控制普通网页路径。全网不获得专用平台浏览器的Cookie、独立会话或登录能力。

## 搜索与正文

沿用前后台共同的 `search_documents`/`read_document`，不新建不受监督的下载路径。候选链接经统一规范化：只接收公开HTTPS默认端口，HTTP候选可规范为同域HTTPS请求，移除片段；拒绝URL账号密码、IP字面地址、回环/私网解析。没有任意URL模型工具，普通网页从搜索候选进入阅读。全网结果可复用既有资料卡、GUI投影、气泡逐句显示、TTL、撤回和来源依赖；不自动写入人格或永久记忆。

读取仅一次受预算和子进程期限监督的GET，接受HTML/XHTML/纯文本；不自动跟随重定向、不重试、不执行脚本、不加载子资源、不登录、不读取PDF或二进制。正文优先提取article/main内可读文本，排除脚本、样式、导航、页脚、表单、iframe等；无语义区域则如实标为静态页面节选。纯文本直接保留文本内容，既有字符上限与响应量限制不变。验证页/不足80字等情况报告失败，全网不会用搜索摘要或meta description补成正文。

全网HTML/纯文本新增覆盖范围枚举与阅读整理器白名单。每份材料保留真实URL、标题、抓取时间、正文摘要、阅读范围和来源有效期；注册表与宪法升v9，同步“默认全网/按实际读取理解”的自我事实，不重复工具目录。

日期硬筛选仍仅支持明确指定贴吧；全网带 `published_after` 返回不支持而不是偷偷缩小范围。普通全网的recent/relevance参数不伪造发布日期排序，沿用共同的关键词相关性排序，不保证实际发布日期新旧。

## 网络路由

直连沿用完整DNS结果公网检查并连接同一次解析得到的IP。系统代理下，固定平台/搜索服务保留原固定目标路由；普通网页则在本机解析并验证所有IP，再向无凭据回环HTTP代理发送该公网IP的CONNECT，TLS与Host仍校验原网页域名。代理无法自行把一个未检查的任意域名解析到内网。DNS不通、Fake-IP/私网解析、代理拒绝、证书或跳转失败均明确失败，不以降级方式绕过检查。

因此，只有代理远程DNS而本机无法取得真实公网解析的环境可能无法读取普通网页，这项需在真人网络环境确认；不能把静态安全边界等同于网站可达性。

协议资料核对：[Brave Web Search](https://api-dashboard.search.brave.com/app/documentation/web-search/get-started)、[SearXNG Search API](https://docs.searxng.org/dev/search_api.html)。本轮延用已有接口形状，未把文档检查当成服务实测；Bing RSS也不承诺始终可达。

## 真人验收（全部待执行）

1. 换包后检查原平台开关/服务配置保留，新增全网最初关闭；开启全网与服务许可后，不指定平台查询官方文档/新闻/文章，确认实际来源域名可以超出原四个平台。
2. 明确指定贴吧/维基等，确认仍限定该平台；全网关闭时默认查询明确报缺口，不能静默改成平台搜索。原平台关闭时专用查询仍拒绝。
3. 查询返回真实网页后，核对标题、URL、正文节选与范围标注；纯文本中的尖括号等不被当HTML吞掉。验证页、跳转、脚本页、PDF应如实失败，不能用摘要冒充正文。
4. 分别在实际直连/系统代理环境确认搜索与正文读取；公开解析与证书合法时可读，内网解析/Fake-IP/凭据URL不应绕过检查；服务超时与限额仍能停止。
5. 资料撤回/到期后主界面和气泡正文同步失效，QQ范围保持既有策略；引用与记忆转正保持来源依赖。
6. 默认查询加日期硬筛选明确不支持；明确贴吧日期筛选仍沿用原行为。后台研究用web时仍受原权限/预算/暂停与联系等待/思考价值约束。

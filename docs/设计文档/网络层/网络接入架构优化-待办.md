## 待办

### N01｜AI 自主择要保存，按价值决定遗忘优先级

状态：核心方向已确认，部分细则待明确。

- 信息进入来源池后先做垃圾筛选，再交给 Alice 阅读。
- Alice 对实际读过的材料自主判断价值和是否保留，将想留下的内容保存为带来源的见闻记忆。
- 即使不符合用户当前兴趣，只要 Alice 认为重要，也允许保留。
- 结合用户兴趣与 Alice 判断的价值度排序，优先级决定遗忘顺序及保存的完整程度：低价值信息浓缩更多，高价值信息保留更多细节。
- 来源渠道、帖子或文章下的评价可作为价值判断信号；具体评论采集范围另行明确。

讨论建议（未定）：价值与可信度分别判断；评论和热度作为参考。优先级可随兴趣变化、后续使用调整，并保留简短理由。

已确认：浓缩仍须保留出处、关键条件和不确定性，避免失去语境。

后续已确认：来源硬期限不延长，七天线作为价值复核点；现有分档和人工验收进度见执行计划。新增索引化保留建议见 N09。

### N02｜价值驱动思辨，用户指示检索享有即时提取资格

状态：处理原则已确认；当前实现与验收状态见执行计划。

- 普通材料积累后批量消化；高价值、明显冲突或反复出现的材料可提前触发思辨。
- 用户指示、服务于当轮明确讨论目标的网络检索，在实际读到有效材料后，享有即时提取和初步思辨资格，不等待时间或数量阈值。
- 角色、作品等讨论应及时形成对材料的理解和判断，用于当轮交流，避免观点形成滞后于用户需求。
- 是否值得保留仍由 Alice 判断，沿用 N01 的带来源见闻保存规则。

- 初步观点可即时沉淀，保留依据与不确定性并标明暂时判断，后续结合证据验证或修订。
- 即时处理可结合当轮回答完成，不强制每条材料额外调用模型；允许 Alice 判断没有内容值得保存，不要求每次检索都生成观点。

### N03｜从自然聊天中自主识别用户兴趣

状态：处理原则已确认；当前实现与验收状态见执行计划。

- Alice 从用户聊天中流露的观点、经历和关注点识别潜在兴趣，自主加入兴趣体系。
- 不依赖用户明确声明兴趣、手动填写标签或外部注入；与 N01 的兴趣相关价值排序衔接。
- 观察范围以用户与 Alice 的聊天为基础。

- 保留判断依据和置信度，区分持续兴趣、一次性话题及转述；关注、喜欢、反对等态度分别记录，不把关注直接认定为认同。
- 兴趣可随后续交流增强、衰减或修订，并允许用户纠正。

### N04｜避免兴趣自我强化

状态：处理原则已确认；当前实现与验收状态见执行计划。

- 用户的表达与反馈，和 Alice 自己搜索、阅读的行为分别记录和计权。
- Alice 自己反复接触的材料不能直接证明用户兴趣增强，避免推荐与检索形成封闭循环。

### N05｜支持知识过时与观点修订

状态：处理原则已确认；当前实现与验收状态见执行计划。

- 新材料与旧记忆冲突时保留分歧及依据，区分当时的判断与当前的判断。
- 允许结合新证据验证、修订或淘汰旧观点，不以新内容直接覆盖旧结论。

### N06｜压缩后仍可核对依据

状态：处理原则已确认；当前实现与验收状态见执行计划。

- 支撑判断的关键原文、出处与版本按价值保留，便于核对压缩后的见闻。
- 避免反复压缩摘要导致条件丢失或含义改变；具体证据保留时长与 N01 一并细化。

### N07｜统一前台与后台调度及预算

状态：处理原则已确认；当前实现与验收状态见执行计划。

- 用户当前的检索与讨论优先，后台探索和批量思辨让路。
- 检索、读取、提取和思辨共用预算与调度规则，避免独立运行造成重复消耗或成本失控。

### N08｜拆清职责，复用处理链路

状态：处理原则已确认；当前实现与验收状态见执行计划。

- 分离任务调度、平台适配、来源管理与记忆处理的职责。
- 对话搜索与后台探索复用统一处理链，平台差异集中在适配器，减少新增平台时的重复修改。

### N09｜低价值内容降级为名称与来源索引，按需重读补全

状态：2026-11-03 用户确认方向与以下边界，待具体设计，尚未实施；不追加到当前固定的六类人工验收中。

用户提议：

- 当用户与 Alice 只关注某篇材料中的一部分，可对不同角色或知识单元分别保留：关注的角色留细节，其他低价值角色仅留名字与 URL。
- 后续需要时通过来源重读，再补充详细内容，降低长期正文占用。

已确认设计原则：

- 增加可重读的索引形态，与可直接支撑事实判断的见闻区分；仅见目录者标为线索，已读后降级者保留读取状态，不假装仍记得细节。
- URL 可带实际取得的章节锚点或定位词；重读需支持定向取材，不能总是只取得长列表的前段。共用文档入口、按相关性取出索引，控制索引总量与上下文占用。
- 重读沿用当前权限、受众、平台与预算，服务当轮讨论时仍享有即时提取资格；重新评估后可恢复更详细的保留形态，不能直接从旧摘要补造细节。
- 兴趣之外的重要材料及支撑高价值观点的最小证据仍可保留；若只剩索引，不能继续把它当作事实依据，需处理派生资格。
- 区分主动降级、普通遗忘与用户删除/来源撤回。删除或撤回应清除或停用相关索引，不能借重读恢复已撤销内容；此处需与现有同版本去重及不复活规则一起设计。

待设计：索引的数据结构、保留期限与数量预算、降级/升级触发条件，以及定向重读接口；不将方向确认当作运行时已实现。

2026-11-03 实际设计依据：真人明确要求重读单角色条目时，关键词搜索仍可能命中角色列表；受限的一轮工具中未能再纠正。定向重读应优先使用已有URL/页面身份及定位信息，目标未取得时明确报告，不能将相关页面当作目标已读。

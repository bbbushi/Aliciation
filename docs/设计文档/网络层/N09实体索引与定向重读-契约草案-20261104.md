# N09 实体索引与定向重读契约

2026-11-04；状态：具体设计、待参数及首个平台裁决；未接线、未迁移、未执行网络读取。依据[N09已确认方向](网络接入架构优化-待办.md#n09低价值内容降级为名称与来源索引按需重读补全)、[实际目标未命中记录](网络接入与见闻成长-人工验收记录-20261102.md)、[任务书W7](../整体设计迭代概览/Alice架构完善-开发任务书-20261104.md)。本机平台许可未知，历史“维基唯一启用”不作为本机事实。

## 1. 首版边界

推荐首版为已有受控读取适配器中的维基文本条目/条目章节，前提是用户确认本机该平台和内容类型已获准；否则从实际已获准的一个平台另选，不自动启用。目录、同名实体、相关列表和登录页均不能冒充指定实体。读取对象只能来自宿主曾签发的来源身份，模型不能提交任意 URL、文件路径、Cookie 或新域名。

索引是重读线索，不是事实证据。当前整页正文、实体已读范围和未来可定位范围分开；“宿主取得文字版本相同”不说明网页未编辑。普通记忆 C1、旧对话 C3 和网页证据继续各走原有资格，不把所有材料合成万能引用。

## 2. 数据与身份

| 对象／字段 | 合法取值和含义 |
|---|---|
| `source_entity` | `entity_id` 宿主随机ID、`epoch`、`platform`、`entity_type`、`canonical_resource_id`、`parent_resource_id?`；相同名称不等于相同实体 |
| 定位 | `canonical_url` 由适配器生成，`locator_kind=whole_entity/section`、`locator_value` 为实际取得的规范章节标识、`locator_evidence_version`、`locator_confidence=verified/lead_only`；不运行页面脚本定位 |
| 版本 | `index_version` 对字段变更递增；`last_read_version` 为实际正文摘要，`site_revision` 仅接口有明确值才记；无则 null |
| 阅读状态 | `never_read/read_retained/read_downgraded/read_expired`；`last_read_at`、`read_scope`、`missing_scope`，不因有标题变成已读 |
| 许可 | `scope_channels`、`allowed_purposes`、`policy_revision`、`hard_expires_at`、`index_expires_at`、`revoked_at`，有效期取最短，不续来源硬期限 |
| 来源链 | `source_packet_id?`、`retained_evidence_ids[]`、`derived_memory_ids[]`；索引本身不可当 evidence_id |
| 管理 | `created_at`、`last_selected_at`（不续期）、`state=active/expired/revoked/deleted`、`transition_reason`、`previous_index_version` |

正文不复制到索引表，预览仅名称、已读范围及有限定位提示；定位词不得携带完整段落。实体引用 `entity_ref` 为请求内随机令牌，宿主映射绑定 epoch/channel/request/index_version/platform/locator/政策；拒绝裸 ID、跨请求旧令牌及模型自行拼 URL。标题中恶意指令仍为资料。

同URL不同实体章节分别实体ID，正文哈希包含规范资源身份与实际范围；网页跳转导致资源改变时返回 `target_changed`，不得自动借旧引用读新目标。适配器若能证明只是同实体规范化地址，可重新核准重定向并记录 chain；每跳沿现有网络准入和预算，不绕过主机、回环、私网或平台边界。

## 3. 工具和公共面草案

`source_index_search(query, cursor?)`：只读当前许可下最多8个实体元数据，合计1800字符（建议值）；记录扫描范围和 `index_only=true`，不联网、不计正文使用、不续期。输入最长200字；同请求目录与工具总额度共用现有计数。查无结果只表示本次范围未命中。

`source_entity_read(ref)`：首版一次一个实体。宿主在实际发送前重新核 epoch/渠道/政策/期限和共享预算，登记 attempt 与必要依赖，再调用现有受控读取器；成功须满足资源身份和指定范围匹配。返回 `target_match=exact/partial/none`、`source_version`、`read_scope`、`missing_scope`、`source_packet_ref`、`status`。仅 exact 才可说目标已读；partial可交付明确节选，但不能称完整目标，必要条件不全则不得支持依赖完整性的主张。

固定失败码：`stale_ref/unavailable/permission_changed/budget_exceeded/target_missing/target_changed/locator_missing/login_required/unsupported_scope/cancelled/transport_unknown/too_large`。失败不暗中转搜索；若模型另提普通搜索，按新动作占现有预算，回执明确候选不等于原目标。

GUI管理建议复用 discovery 公共面，以 `ChatService.discovery(action, payload)` 新增固定动作 `entity_index_list/entity_index_detail/entity_index_transition` 及同源 `/api/discovery/entities`，维持现有 discovery 意图/来源检查；写入带 epoch、配置版本、index_version、operation_id。这里只读元数据或执行明确降级/删除，无模型或联网副作用。观察器导出可用现有公共只读通道，不能要求SDK读取活库。上述新增动作和路由为草案，尚不存在。

## 4. 生命周期、预算与证据保护

| 转换 | 条件与原子影响 |
|---|---|
| 新建线索 | 仅宿主实际发现的实体目录或已读正文中可信定位；保存索引许可和期限；绝不据索引生成事实记忆 |
| 主动降级 | 生成降级预览，列正文与派生依赖；同事务删除可降级正文、保留获准索引，受影响观点标待重读/不可作为当前事实；操作失败保旧 |
| 高价值证据保护 | 有有效高价值观点依赖时先保留最小原文片段、出处/版本/范围/限制及期限；无法选出完整支撑片段则不自动降级，显示阻塞，不静默留下无证据观点 |
| 普通遗忘 | 正文按现行规则物理清理；索引是否能独立存在取决于单独已批准期限，不能把有索引称仍记得细节 |
| 重读与升级 | 实际 exact 读取后生成新来源版本，沿既有即时提取/价值判断；可不保存。旧观点不自动恢复，不凭旧摘要补正文 |
| 相同版本去重 | 同实体/范围/正文版本且原保留有效，复用身份不改期限；旧版已撤回或明确删除则不得自动复活 |
| 用户删除／来源撤回 | 先封锁引用及新读取，同事务停用索引、正文及派生资格，生成/发布前再查；不能重新搜索同实体来绕过撤回 |

新读取继续共用 search/read/model/body_bytes/时间/前后台调度预算，不提供“定向免费额度”。取消先封新动作，已发送但没回执记 unknown；不退款伪装零消费，不在重启后重发。读取完成时只回填原 attempt，晚到结果先复核许可；不可用则丢弃正文并留固定原因。

建议独立索引最大200条、总元数据100000字符、最长30天且不得超过已有来源保留授权的硬期限；容量到限先淘汰过期再按长期未选中的线索，目录展示不续期。以上具体值未获批准，默认实现开关应为关闭，不能把本建议写入活配置。高价值最小证据仍沿现有证据期限；增加长期保留另行裁决，不能借“保护”永久保存。

删除阻止重读的记录只保留不含名称/URL/正文的本机作用域不可逆键及 reason/version；它仍是新增数据保留，建议随当前 epoch 保留、彻底删除同时清除。此策略未批准前，不以永久墓碑替用户保存可识别来源。界面需区分“删除正文并禁止自动恢复”和“彻底删除索引及记录，后续用户再次显式给新来源视为新授权”。

## 5. 迁移、恢复与回滚

新增表为空、工具默认不挂载；旧记忆不自动提实体，不批量联网。只有用户选定的少量旧来源经只读预览确认实体和范围后迁移；旧来源没有可信定位则 `lead_only`，不伪造读取时间或章节。迁移操作记录 op_id/旧新版本/对象清单及摘要；不复制整库私人内容。

降级事务在已有正文清除前建立合法索引、证据保护或阻塞判据，数据库部分不可拆成多个commit。文件材料若涉及则另走有日志的提交协议，首版仅数据库文本避免新增文件回收面。中断后按 op_id 查已提交结果，不重新调用模型/网络；后续人工编辑的版本优先，冲突待人工。

回滚先关闭新工具及自动降级，再关闭索引候选注入。新表保留供导出/清理，旧版不得消费；已依法删除的正文不因回滚恢复。依赖已经失效的观点保持不可用，不能因旧版不识别新状态而重现，故需要兼容过滤版本或禁止降级后直接运行旧代码。

## 6. 最小实施与待裁决

实施分四包：A来源身份/空schema/只读管理；B单平台定位与现有读取接线；C实际依赖与撤回、发布复核；D人工预览降级/高价值保护、独立索引维护。每包都先保持默认关，D不先于C开放。验收必须覆盖指定实体/相关列表/同名、章节不存在、同URL新版本、权限撤回、额度、取消unknown、高价值依赖、GUI/QQ当前受众以及删除不复活；见W5未来场景，不据静态检查写通过。

待裁决仅三项：①本机首个平台与内容类型（推荐已获准维基文本）；②正文遗忘后是否允许有界索引独立保留及具体期限/容量（推荐上述上限，受硬期限约束）；③删除阻止恢复的最小墓碑与彻底删除语义。不同选择阻塞相关新数据行为，不阻塞W1—W5和现有网络能力修复。

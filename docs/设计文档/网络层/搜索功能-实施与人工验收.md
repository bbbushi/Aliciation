## 现在可以做什么

Alice 按用户允许外发的兴趣概要，在用户开放的平台中自行选题和搜索。结果经过平台校验、去重和阅读后进入资料池，保留原文节选、作者观点、Alice 的暂时解读、不确定性和讨论问题。相关聊天按用户设置取用资料，用户也可点“聊聊这条”，在正常聊天中继续讨论。

后台只准备资料，不创建聊天消息、不主动发 QQ。已有完整冲浪体验与社交观察尚未实施；本次先实现搜索闭环需要的公共节拍、读取、预算、资料池和来源附件。

“已提供适配器”不等于已验证你这台机器能访问平台，也不承诺持续免费或稳定返回。搜索诊断现区分上游合法空列表、收到结果但平台过滤后无候选、读取后未选中资料；界面未选卡状态也不再混称没有新材料。受限计数只保存数量，不保存查询、标题、正文或平台原始消息。没有可读正文、登录/验证页或响应结构不符时明确失败，不用搜索摘要、整页导航、推荐列表或广告冒充阅读证据，不自动切换平台、登录或重试。首版不开放任意站点、账户内容、账号 Cookie、发表评论/关注/点赞等写操作。新增平台迁移保留旧开关，贴吧默认关闭；免费通道不扩大来源权限，也不免除已允许的模型费用。

## 启用与使用

1. 打开导航中的 **内容发现**。主页直接显示资料卡、当前平台与兴趣概要，以及 **现在找一轮**、**偏好设置**。日常看资料不必先翻过配置表；缺平台、兴趣、启用许可或可用额度时，页面给出对应的下一步入口。此前真实 GUI 已保存仅贴吧开启，知乎及其 `allow_third_party`、B站、维基百科均关闭；本次交互调整不更改这些选择。
2. 需要调整时打开 **偏好设置 → 去哪里找**，直接点平台旁的“开启”或“停用”，无需先勾选再另行保存。贴吧使用 **原生入口**，不需要密钥或第三方搜索许可。第三方搜索许可仍单独显示在“访问方式与资料管理”中：未授权时须明确勾选并点“允许并开启”，不因打开平台或保留 provider 配置便自动授权。当前不启用知乎、Bing RSS 或其他第三方发现路径；搜狗实验选项不纳入交付。
3. 在 **找什么** 中，只需填写“想了解什么”，勾选允许用该兴趣搜索，再点 **添加兴趣**。“补充方向与启用状态”可选填；补充方向为空时按主题寻找，不必重复填写概要。也可在此保存停用的兴趣。完整聊天、人格和私密记忆不会交给后台规划器；从聊天整理出的兴趣仍是等待确认的候选，不因本次简化自动获得外发许可。
4. 在 **自动寻找与高级设置** 中确认总开关、活动时段与模型使用许可，改动后点 **保存设置**。每日额度、聊天取材、库存、容量、保留时间及平台访问/网络细节均可按需展开；自定额度与“不限”继续保留。全新配置仍默认关闭、兴趣为空。允许后台模型时沿用 Alice 当前配置；不允许时把每日模型请求设为 `0`，使用兴趣概要检索并保留文字节选。**暂停发现是总开关，手动“现在找一轮”也会停用**，已找到的资料仍可查看；未保存的设置或兴趣会引导继续编辑，不被快捷开关覆盖。
5. 点 **返回资料** 收起偏好区。准备好后可点 **现在找一轮**；手动寻找可跳过自动时段、活动间隔和库存目标，仍受平台、兴趣、读写许可和额度约束。自动寻找需要保持 Alice 服务运行。顶部显示简短进度，完整搜索计数、诊断、用量和刷新入口收在 **活动记录与用量** 中。
6. 资料卡优先展示概括、阅读范围与 **聊聊这条**、**多找这类**；判断、依据、保留期限及更多管理操作按需展开。“聊聊这条”已提供：只绑定下一轮网页对话，并在输入框为空时填入讨论草稿，**需要你自己发送**；已有草稿保留，绑定也可取消。按钮变灰表示该卡当前不具备使用资格，页面说明具体暂停原因；已失效旧卡需重新寻找，不因改回设置自动恢复。“多找这类”只提高之后的寻找优先级，**不会立即发起新搜索**。资料绑定时长可配置，且不超过资料有效期。

在兴趣编辑中的 **优先在哪些吧找（可选）** 逐行填写准确吧名，留空表示不设优先吧；保留名字本身末尾的“吧”及逗号。点 **检测吧名** 后，界面区分“已确认，取得公开帖子”“已确认吧，本次未取得公开帖子”“返回吧名与输入不一致”和“本次未能确认”。新增名字必须在本会话、同一配置版本、最近完成的检测中名字准确匹配且有公开帖子，才能保存兴趣；已经保存且未改的名字无需重新检测。检测不保存兴趣、不调用模型、不启动寻找，计入共享网络与响应量额度，可取消；发现总开关关闭时仍可显式检测。检测成功确认当次公开入口和吧身份，不保证之后的关键词搜索一定找到该吧内容。

优先吧只调整当前关键词搜索候选的先后，其他吧仍是后备；不是全局白名单、完整吧内检索或吧列表浏览。仅修改优先吧或原样保存，不提升兴趣内容版本、不停用现有合法卡片或待讨论绑定，也不撤销历史来源；主题、概要、启用或外发许可的实质变化仍沿用既有失效规则，已经失效的旧卡不会自动复活。

在 **自动寻找与高级设置 → 贴吧回帖阅读** 可显式开启首页公开回帖并填写每帖数量。产品默认关闭、默认数量 20；正整数由用户调节，无另设业务封顶。开启后请求首页 `rn=所设回帖数+1`，受实际页面、响应和文字额度限制，不翻页凑数、不读取楼中楼；来源说明实际读到多少条。关闭回帖或减少数量，会撤销不符合新评论范围的旧来源和引用，重新放宽不会恢复已撤销内容。现场用户自行设置的回帖开关、数量及兴趣保持原样，不因产品默认值而重置。

后台按用户设置的检查周期、活动间隔和库存目标运行，活动时段默认北京时间 18:00–23:00，支持跨午夜。聊天开始会取消后台探索，不等待搜索或模型完成。服务关闭、重置或配置变化都会撤销在途许可；重启不补跑上次中断任务。

系统代理仅用于固定的公开平台与支持此路由的搜索服务主机（包括 Bing、Brave）；只接受无账号的回环 HTTP 代理，由代理通过 CONNECT 解析目标域名，Alice 继续验证原平台域名的 TLS 证书。未读到代理地址时直连；读到不支持的代理地址会报告错误，连接失败不自动回退或重试。远程代理、SOCKS 暂不支持，也不读取/执行 PAC 脚本；仅配置 PAC 的环境需另行配置本机 HTTP 代理地址。自定义 SearXNG 与模型接口保持原连接路径，不受此设置改变；直连的公网 DNS 校验继续保留，没有将保留/私网地址直接放行。

## 用户配置的额度与执行边界

次数和容量不再由旧版的 1/2/6/12/20 等固定业务上限决定。设置中的“**不限**”写入 JSON `null`；`0` 禁止相应新增操作，正整数就是用户所填额度。每日响应量以 MiB 输入，也可不限或为零；支持小数。现有明确保存的设置保持不变，新增字段使用宽松默认值；旧实现中未存为字段的正式记忆每日 1 条、来源池 20 MiB 不再暗中生效。界面显示当前生效值，用户可继续调大或选择不限。

新会话的建议初值为每日搜索 60 次、模型 120 次、网络 1000 次、响应量 1024 MiB、自动分享 20 次、正式见闻 10 条，候选池 100 张、来源池 200 MiB。这些都是可修改的初值；已有会话不会被强制改成这些数字。用户将候选容量、来源容量或候选读取数设为零时，发现任务在联网前直接停止。

| 配置组 | 对应字段与含义 |
|---|---|
| 共享日额度 | `daily_queries`、`daily_network`、`daily_models`、`daily_response_mib`、`daily_shares`、`daily_memory_writes`；按北京时间自然日、全平台共享。自动分享以使用资料的一轮回复计一次，正式见闻写入另记条数 |
| 资料与兴趣容量 | `pool_capacity` 控制候选卡；`source_pool_bytes` 统一统计来源包、聊天附件、卡片及正式外部见闻文本，界面按 MiB 换算；`interest_capacity` 和 `active_interest_capacity` 分别控制兴趣总量及启用量 |
| 每轮聊天与回顾 | `chat_material_limit` 控制直接提供的资料数；`chat_dependency_limit` 控制该轮全部来源依赖数；`external_recall_limit` 控制一次 recall 返回的外部记忆数。任一相关额度为零时不能由显式选卡绕过 |
| 库存与选题 | `stock_target` 是停止自动补充的库存目标，不限表示不按库存停；零表示不自动补充。`planning_interests` 控制提供给规划器的获准兴趣数，零跳过规划；`read_candidates` 控制本次最多尝试的候选页数，零不读取 |
| 节奏与反馈 | `activity_interval_minutes`、`share_interval_minutes` 可为零以取消相应间隔；`tick_minutes` 必须为正数。`less_share_days`、`block_ttl_days`、`discussion_minutes` 分别控制少分享、来源屏蔽和待讨论绑定时长 |
| 保留期 | `candidate_ttl_hours`、`source_ttl_hours`、`memory_ttl_hours`、`seen_ttl_days` 均为正有限值，可调大，不支持不限；新配置不延长已经生成的来源包。候选、判断、见闻和附件仍不得晚于必要来源失效 |
| 单次执行保护 | `search_results` 是请求结果数；活动/搜索/读取/模型各自的 `*_timeout_seconds` 和搜索/读取/模型各自的 `*_response_bytes` 由用户调整，必须为正有限值；阶段还受活动剩余期限约束。这些设置不会改变平台单页能力或来源许可 |
| 兴趣的优先吧 | 每个兴趣的 `preferred_forums` 为吧名列表，空列表不设优先；新增名字须显式检测后保存，只调整候选顺序，其他吧保留作后备 |
| 贴吧回帖 | 全局 `tieba_read_replies` 默认 `false`，显式开启才读一级回帖；`tieba_reply_limit` 默认 20、可调正整数，不另设业务封顶，实际仍受首页返回、响应与文字额度限制 |

数量字段只受 JSON/界面能精确表示整数的协议范围约束，没有另加业务封顶。时间与响应大小保持有限，以便中断、回收和解析；文本字段的 UTF-8 长度、单次结构校验和地址白名单仍是执行保护。平台自身只返回一页或较少结果时，不用重复请求凑数；不能把“请求 100 条”当成平台承诺返回 100 条。

调低来源容量不会自动删除仍合法的历史或附件；当前用量可能高于新额度，此时阻止新增增长，等待自然到期或用户清理。候选卡容量缩小只影响候选池，不借退卡撤销合法历史来源。正式外部见闻与含来源的 `remember` 共用写入额度；同一来源可以产生不同内容的见闻，完全相同的记录去重且不重建，改写不获得续期或升级权限。

请求前预留次数及最大响应量，可信实际字节返回后结算；超时或中断保留未确定的预留。没有 token 数据就标未知，不填零。原生 B站获取公共请求上下文、签名与内容所需的每次 HTTP 都计入同一网络及响应量账本；不因是一个搜索操作就把内部请求藏掉。

当前启用的贴吧原生搜索和首页读取各算一次 HTTP，显式吧名检测每个名字也算一次 HTTP，纳入原有共享额度；检测无模型调用，可选一级回帖与主帖来自同一次响应，失败不自动补请求，数量不足也不翻页凑数。优先吧与回帖开关不改变共享额度和模型隔离。B站目前已停用，其既有匿名搜索仍按设备标识、签名参数、搜索结果三次 HTTP 分别计账，简介读取另算一次；此处保留实现契约，不表示本轮重新开启。平台拒绝匿名请求、要求验证或 HTTP 401/403/429 会停止整次活动，不继续换候选探测；单个候选缺少合法正文时才可在用户设定的读取数内尝试后续候选。

每次活动完成一个选题、一次发现及单页判断：规划最多一次，零模型额度时使用兴趣概要；取得第一份有效且未重复正文后停止继续读取。一个待续问题保留在进程内，继承其资料期限，不跨服务重启。这里的单页依赖与单个待续槽是当前实现形态，不能通过增加每日额度变成多页混合判断或完整冲浪。

模型判断失败而已取得可靠正文时，可保留明确标注“尚未进行独立模型判断”的原文节选；不会编造解读。收到取消、会话变化或达到整个活动期限时停止提交。后台调用使用独立受监督子进程，密钥经标准输入传入，父进程统一保存结果；子进程没有数据库连接、聊天工具或发送权限。

每张后台判断卡只依赖一页，阅读模型也只拿到这一页，避免多页混合判断却漏记必要来源。这是来源因果保护，不是保留旧的“最多读三页”业务额度：只在前页失败、不可用或重复时，才在用户设定的候选数内尝试后页。用户显式回顾多份仍有效的资料时，聊天侧在配置额度内保留全部被提供的来源依赖；后台多源比较留待后续扩展。

首次取材使用确定性话题匹配，不额外调用模型判断“是否值得说”。为防重复，**成功完成一轮回复后，凡提供给该轮的资料都保守退出自动候选**，界面写“已提供给对话（是否采用未推断）”；这不是已经说出口、用户已读或用户喜欢的证明。QQ 实际平台回执仍由原渠道账本独立记录。

## 来源、记忆与清除

来源资料与普通对话记忆分开。使用外部材料的用户/助手轮次在普通 `turns` 中保留固定占位，正文进入有期限、受众和依赖来源的附件；普通自动提取、人格/技能流程与 P1 核查不把这些附件当用户事实。显式资料回顾可检索仍有效的外部见闻，普通 `recall` 不自动把全部外部资料混入。

资料默认仅供本机 GUI。用户另外开启“在本人 QQ 聊天中使用资料”后，新产生的资料才取得该范围；关闭会撤回既有 QQ 来源附件权限，重新开启不会复活旧许可。已发送到 QQ 的消息不能由本地清理撤回。核心每次接收 `sending` 时重新核准来源，桥在实际发送及已知失败重试前都要重新提交；资格失效时停止未发尾段，保留实际已确认/结果不明的记录。已经获准并进入平台网络的尝试不能跨进程原子撤回。原已登记回复的终态回执仍按固定摘要入账，不因来源正文已被占位而拒收。

共享公开证据与共享整轮正文分开：含来源的混合聊天附件只在产生该轮的渠道展示。GUI 中的 QQ 来源轮次保留占位与投递状态，不能凭来源公开就把整轮文字重新开放到另一渠道；普通 QQ 历史沿用既有显示方式。

关闭平台停止新读取和旧候选的自动分享，不等于清除合法历史。删除资料或“清除此平台资料”会撤销必要来源，使依赖见闻、判断、待续问题和历史附件失效；网页同步时更新已经显示的来源轮次，到期还会本地降为占位。归档数据库退出活跃清理前会清掉外部正文和派生内容，普通历史及审计身份保留。

关闭正式见闻开关阻止以后新增，不延长或重写已有见闻寿命；到期、来源撤销仍会使其失效。暂时资料及派生内容不通过换 ID、改写标题或“记住这个”变成永久记忆。**搜索不会自动写入 v0.4 的长期结构化观点、人格、技能或查证结论。**

设置、兴趣、预算与资料存于当前会话的 SQLite；搜索服务密钥也存于此库，不在网页回显、不进请求参数/日志/子进程命令行，不另复制到 `config.toml`。数据库归档会清除发现配置中的密钥。运行中的网页只在打开面板时轮询；忙时提示稍后查看。多标签页编辑通过会话身份和配置版本拒绝过期写入。

## 参考与本轮取舍

沿用 [dsh-heartbeat 参考](../wiki/harness研究/参考设计/参考-dsh-heartbeat.md) 的后台备料/会话表达分离、先便宜闸门、代码登记与有界回收；没有引入屏幕监控、自动发言或心理画像。待续问题先保留在进程内；采用与语义分享尚未建立可靠检测，因此使用保守“提供后退出自动候选”，不虚报采用率。

实现依照 [MediaWiki 搜索](https://www.mediawiki.org/wiki/API:Search)与[正文解析](https://www.mediawiki.org/wiki/API:Parsing_wikitext)、[Brave 搜索接口](https://api-dashboard.search.brave.com/api-reference/web/search/get)、[SearXNG 搜索 API](https://docs.searxng.org/dev/search_api.html)核对公开请求格式；这不替代实际平台可达性验收。维基百科节选保留原页链接署名，卡片区分原文与生成解读并附许可说明，依据 [Wikimedia 内容许可与复用条款](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use#7._Licensing_of_Content)；正式见闻也只作有期限的本地材料，不宣称所有网页可永久保存。

此前免费发现研究参考 [RSSHub 的 Bing 搜索原作者实现（固定 commit）](https://github.com/DIYgod/RSSHub/blob/65747ac4cf18728c7d0c8f57a4ddffd3044a8a25/lib/routes/bing/search.ts#L38)的公开 RSS 请求形状；本轮不启用这一通道，它不是已退役 Bing Search API 的继续可用证明，也不承诺返回数量、稳定性或摘要的永久保留权。贴吧的固定源码、主帖字段与实现边界见[贴吧通道参考](./贴吧通道-参考与边界.md)。知乎既有 SSR 代码保留精确实体约束，但平台关闭、接入暂停，无签名或登录会话接入。

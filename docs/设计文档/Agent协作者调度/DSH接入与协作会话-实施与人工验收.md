## 连接与授权

本轮插件升级为 `alice-dsh-bridge-probe@0.3.0`，已安装的本地 link 沿用，用户需要重新加载一次 DSH NEXT 与 Alice。新版安装包配置开启监听许可与执行许可；没有有效凭据时不监听，也不会运行模型。DSH 插件页面整体开关仍有效。本轮未代重载或生成实际令牌。

主流程为 GUI“设置 → DSH → 生成令牌并连接”。连接、独立令牌、任务目录、权限及执行上限集中在设置的DSH页；DSH 会话窗口保留列表、同步记录、任务详情与任务操作。打开或关闭设置不连接/断开、不更换令牌或保存授权；离开DSH页会清空手动令牌输入。核心用 CSPRNG 生成 43 字符独立令牌，使用 Windows 当前用户 DPAPI 加密，固定保存 `%LOCALAPPDATA%/Alice/dsh-bridge/credential.json`；插件以只读观察读取自己的专用凭据。用户无需命令行、环境变量或复制令牌。以后使用已保存令牌连接；Alice 重启保留原授权版本、任务正文及已用次数，但不自动建立桥接或重发旧任务。浏览器、模型、聊天、普通配置和请求收据不取得明文令牌或密文。

托管凭据只有显式点击才创建或更换；GET 仅查询有界元数据，不解密、握手或生成。读写采用固定目录、拒绝明显链接/重解析与多硬链、独占旁路锁、同目录密文原子替换；内外格式与 credential_id 绑定，损坏文件不自动覆盖。DPAPI 保护落盘数据，不构成同 Windows 用户进程间隔离；目录沿用 AppData 权限，不宣称 Python 3.11 的 mkdir mode 建立了独占 DACL。实现依据：[微软 CryptProtectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)、[ProtectedData.Unprotect](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.protecteddata.unprotect?view=windowsdesktop-10.0)。

插件每两秒检查文件指纹，变化先停止旧监听并清理自有任务；清理未确认时不启用新监听，进程级租约跨热重载保留未知状态。删除或损坏已使用的托管文件不自动回退环境变量令牌。更换的生效取决于插件检测和清理，不宣称点击瞬间所有旧连接已终止。更换按钮仅在当前 Alice 无连接、授权关闭时可用，影响同 Windows 用户的旧桥接连接；其他 Alice 窗口也需重连。单纯断开保留加密令牌、授权及有效历史；明确关闭授权才撤销正文。高级手动令牌仍保留，既有托管文件优先。

生成后最多等待约九秒进行有界只读 hello 尝试，让插件有时间读取凭据；不重试派工或消息操作。插件尚未就绪时明确返回“令牌已保存，连接尚未建立”，可稍后再连接。托管目前限 Windows；其他系统保留原手动方案。首次更新或固定解密失败可重新加载插件；旧任务清理未知时按插件指引处理，不用热重载抹掉未知状态。

配对成功后，用户明确保存：现有本机绝对工作目录；`read-only`（仅可查看）或 `workspace-write`（工作区内修改）；本次授权总执行次数 `0–100`（启用至少 1 次）；每次执行时限 `30–1800` 秒（默认 600 秒）；以及 `native_permissions_ack:true`。

确认项明确说明：任务及相关文件可能由 DSH 发给其模型服务；原生权限不能保证任务外读取与网络隔离；执行次数和超时不是货币费用硬帽。此授权档为 `dsh_native_v1`，不是原强隔离档 `task_files_v1`。不开放完全权限，不以 cwd 冒充读取沙箱。插件仅设置、读回并管理自己创建的专属会话，不修改日常会话或全局默认，不自动批准权限升级。

## 执行与可观测记录

`alice/worker_runtime.py` 提供一个独立执行槽、最多 4 项待办；保留 GUI/QQ 单前台对话槽。派工先持久登记 task/message/attempt，再在 Store 锁外调用插件。主聊天继续可用，关闭侧栏不会取消任务。

每次派工或追问在登记时预留一次额度，取消、失败或发送结果未知均不退还；同一授权版本的总次数不会因刷新、查询或复用同一 task 重置。新授权是明确的政策更新。创建参数另带 `max_turns=8`、`max_output_tokens=4096` 和单轮时限；这些执行约束不是任务总 token 或货币费用硬帽。用量缺失显示未知，不记为 0；已有根任务自报输入/输出 token 会持久保存并汇总展示，完整费用仍未知。

追问保留专属 DSH session，新增 message/attempt。插件空闲 15 分钟后会释放句柄；已关闭或插件重启后的旧会话不自动重建续接。仅允许此前回合结束、agent 空闲、授权及桥实例仍有效时继续；运行中或未知状态明确拒绝，不另建会话冒充续接。发送前登记“可能发送”；响应丢失、断线或结果无法确认记 `unknown`，不自动重发。未知执行保留执行槽。相同请求 ID 与参数摘要返回已有收据，同 ID 改参数冲突；连接收据不保存令牌正文。失败的停止请求不无限自动重试，GUI 可显式“重试停止”。

DSH 会话窗口按真实服务端事件展示 Alice 任务、DSH 公开回复及工具记录，区分宿主事实与 DSH 报告。列表独立轮询、分页并显示未读/活动状态；详情使用事件游标、长消息折叠与有界缓存。政策、epoch 或撤销变化会清除旧缓存、拒收旧响应。观察器/P1 与协作窗口互斥；会话默认浮动，用户可选择固定右侧，窄屏保留浮窗；视觉与焦点仍待人工检查，没有本轮验收截图。

## 协议和公共面

Alice 仅连接固定 `127.0.0.1:18765`，生产协议为 `alice-dsh-plugin-bridge-v1`，不回退旧 `probe-v1`。认证 hello 核对协议、随机 instance ID、执行许可和 `dsh_native_v1`；后续 `tasks/create/send/status/events/cancel/close` 绑定实例与 task。浏览器不直连 DSH，不透传通用管理 RPC，也不能选择端点、命令或日常会话。

GUI API 要求本机同源授权及 `X-Alice-Intent: workers`；QQ 身份不可调用：

| 公共入口 | 本轮行为 |
|---|---|
| `GET /api/collaborators` | 只读名单、政策、缓存的 `connection.connected/state/has_connection`、`credential.supported/configured/state`、已用/剩余次数；不发 DSH HTTP |
| `POST /api/collaborators`，`action:connect/disconnect` | `session_epoch/request_id`；手动 connect 另带 token。断开先排空自有工作并清除内存连接，保留托管密文、授权和有效历史；未知回收如实保留 |
| `POST /api/collaborators`，`action:connect_managed/rotate_token` | `session_epoch/request_id`，不接受 token；生成/复用或明确更换托管令牌，返回 registry 与固定 setup_message |
| `POST /api/collaborators`，政策保存 | `session_epoch/revision/request_id/enabled/max_runs/workspace_root/permission_mode/native_permissions_ack/max_seconds`；关闭后重新启用须明确授权 |
| `GET /api/worker-tasks` | 当前 epoch 分页摘要；`archived=0/1` 切换未归档/已归档，默认0；删除记录不再列出 |
| `POST /api/worker-tasks/detail/events` | 有效消息及事件分页；任务 sequence 与全局 cursor 分开；失效游标要求重新同步 |
| `POST /api/worker-tasks/cancel/review/revoke` | 幂等停止请求、独立人工核对、撤销正文及派生资格；review/revoke 带 task version 作为 revision |
| `POST /api/worker-task-settings` | 独立的归档/恢复及删除同步设置；epoch、request ID、设置revision及两个布尔值，不改变派工授权或次数 |
| `POST /api/worker-tasks/archive/restore/delete` | epoch、task、request ID、任务revision及settings_revision；同步范围由已保存设置决定，网页不能提交远端session或目录 |
| `POST /api/worker-inputs`、`POST /api/worker-artifacts/download` | 尚未开放，不将目录内生成文件冒充已收取或可下载附件 |

Python 公共面为 `ChatService.collaborators/worker_tasks/worker_task_settings/worker_inputs/worker_artifacts`。模型在获准 GUI 上下文取得 `dispatch_worker`、`worker_task_status`、`worker_task_read`、`send_worker_message`、`cancel_worker_task` 五工具。执行在 Store 锁外，取材在锁内复核后附入本轮；模型不能构造有效授权。

## 上下文、停止和恢复

任务正文留在独立账本，不伪装普通用户聊天；`worker_task_read` 可有界读取，主聊天回报及后续展开同样绑定任务依赖。依赖包含 task/message、消息版本、epoch、政策版本。GUI 历史及后续展开重新核验；普通 turns 留影子，QQ、提取、人格、技能与思辨不取得派生正文。含任务材料的 remember 拒绝转存普通记忆或见闻；DSH 报告、URL、摘要不自动获得网页证据资格。撤销清除相关正文，重新连接或启用不能复活。 为避免通过新任务绕过撤销，本轮带任务依赖的上下文不能新派任务，只能向同一任务补充；含网页来源依赖时不派工或追问。跨任务、来源到任务的资料转发尚未开放，状态查询、取材和停止不受此限制。截断标志贯通插件、账本、事件、GUI 与模型读取。

停止、关闭、归档和重置先在 Store 锁外 drain，再关闭或替换账本。暂停/排空不公布为可用，断开可恢复；超时明确返回待处理状态。插件的 handle cancel、whenIdle 或 dispose 仅说明句柄/agent 的协作式生命周期，不等于操作系统进程树停止，也不保证远端消费结束。不杀共享 DSH Host，不根据旧 PID 回收他人进程。

重启保留既有授权，旧活动记录保守标 unknown，不自动连接或重发。单纯断开连接不撤销任务正文或重置额度；明确关闭授权、变更授权参数及 epoch 变化仍按原边界使旧内容和继续执行资格失效，迟到结果须复核。回退先关闭授权、取消或隔离自有运行并保留未知状态，再由用户禁用插件；不拆除现有聊天、QQ、检索或来源记忆，不以旧程序打开新库证明兼容。

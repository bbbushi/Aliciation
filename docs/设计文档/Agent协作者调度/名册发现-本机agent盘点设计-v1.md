# 名册发现：本机 CLI agent 盘点设计 v1.1

> 2026-11-03。按用户认可的评审方向修订；设计提案，未实施、未探测、未人工验收。保留原文件名，避免已有链接失效。
> 实施仍限定 ytq，沿用 Claude 实验线约束，不合 main。
> 现行边界参考[CLI 协作宿主契约](CLI协作-宿主契约补充设计-v1.md)、[协作者开发方案](协作者调度-开发方案-v1.md)及[Claude 实施记录](claude直调-实施与验收-ytq分支.md)。[架构总纲](协作者调度-设计.md)作为档案参考，不把其中的设想当作现成接口。

## 1. 结论与首版范围

宿主帮助用户回答“本机发现了哪些 CLI agent 候选、它们自报什么、距 Alice 可用还缺什么”。**发现、执行探测、adapter 核验、注册、启用分别记录，不相互替代。**

首版只交付：

1. 固定范围静态发现，不启动候选程序。
2. GUI 展示有时间、覆盖范围和证据等级的短期报告。
3. 用户选择候选，一次发起有界的版本/帮助探测。
4. 显示已实现 adapter 和核验缺口；Alice 在 GUI 内可读取公开报告并转述。

不新增通用注册器、不自动开发 adapter、不自动付费试跑、不自动注册启用，不挂载新派工工具。DSH/Claude 继续使用各自真实存在的接入流程；没有 adapter 的程序只作为候选。

静态发现不执行候选、不主动修改安装与配置。**执行版本/帮助命令是运行本机程序，不能承诺零副作用、无网络或零费用。** 固定 argv、临时目录和超时不是 OS 沙箱。

## 2. 用户体验与权力边界

| 阶段 | 动作及依据 | 首版行为 |
| --- | --- | --- |
| 静态发现 | 用户点击“发现本机 agent” | 检查固定位置与元数据，不运行候选 |
| 执行探测 | 用户选定候选，点击“探测所选项” | 一次授权所选批次，不逐命令重复弹窗 |
| adapter 核验 | 人工主持无头协议、权限、取消与计量实测 | 显示实际记录或指引，不假装存在通用 D0 后端 |
| 注册 | 用户通过对应接入流程建立工人身份及政策 | 首版不增加通用入口；未来新增注册默认禁用 |
| 启用 | 用户接受权限档并通过现有设置启用 | 不改变已有行为 |

查看报告无需再次确认；同意探测不等于同意注册启用。Alice 可建议下一步，但读取和转述不推进阶段。

未发现只能说“本次支持范围内未发现”；发现不等于 Alice 已经拥有相应能力。程序身份、能力、适配兼容性和授权状态分别展示。

## 3. 静态发现：固定范围

### 3.1 平台与位置

首版以当前 macOS 本机 GUI 为目标。其他平台返回 platform_not_supported，不能用空列表冒充完整扫描；Windows/Linux 后续分别设计位置、启动器和进程回收契约。

候选名称来自代码常量，例如 claude、codex、gemini、aider、cursor-agent、opencode、qwen。实际精确名单随实施冻结，不使用省略号作为运行规则。名称只是候选标签，不能证明程序身份。

- 捕获宿主启动时 PATH，按目录顺序检查已知名称的精确文件路径；不执行 which，不递归遍历目录。忽略空项、相对项和不支持项，报告覆盖范围。
- 补充 ~/.local/bin、/opt/homebrew/bin、/usr/local/bin 的已知精确文件名。
- /Applications、~/Applications 只查白名单精确 bundle 路径、固定元数据及已知 CLI 相对位置，不遍历所有应用内部寻找程序。读取元数据有类型、字节数及数量限制。
- 不碰 .zcodeignore、~/.zcode/，不读取登录文件、token、个人 agent 配置或 shell 启动脚本。解析目标进入排除位置则停止，标为范围外。
- 同一目标合并别名；同名多目标逐项列出并标宿主 PATH 优先项，不假设它等于用户交互式终端 PATH。

目录、候选、元数据大小与读取时间均有上限。达到上限返回 partial 及未覆盖范围，不把部分结果叫作完整盘点。

### 3.2 证据能力

检查文件类型、执行属性、链接链、元数据和可读的归属/写权限。realpath 用于关联实际路径，**不能防顶包或证明发行商身份**。用户可写、root 所有都不能单独推出可信。

损坏链接、权限拒绝、同名冲突、元数据异常分别记录。静态阶段只标 found_unverified、ambiguous、unreadable、outside_scope 等，不生成 headless_capable 或 not_an_agent 判断。

## 4. 候选身份贯穿后续阶段

| 字段 | 用途 |
| --- | --- |
| inventory_id、candidate_id | 宿主生成的不透明引用，不能用任意路径代替 |
| platform、name、discovery_source | 发现范围和候选标签 |
| entry_path、resolved_path、链接链 | 本机 GUI 详情可见，默认不发送给模型 |
| 文件标识、大小、修改时间、可用内容摘要 | 观测指纹；超出哈希预算标“未完整核对” |
| launcher_kind、目标/解释器证据 | 区分原生程序、链接、脚本和包管理器 shim |
| observed_at、identity_revision | 绑定观测时间及身份状态 |

指纹表示是否仍为已检查对象，不是安全认证。探测前后重新核对，变化即 identity_changed，不认可旧结果。

探测执行所选候选的固定绝对入口，不重新通过 PATH 找同名程序。后续核验、注册与派工需绑定同一身份档案；仍以裸命令名启动的 adapter 标 identity_binding_missing，不能将本候选的核验转授给另一个进程。

脚本/shim 只有专用 profile 能约束实际目标及解释器时才执行；不运行 shell 猜测 wrapper。不能确认则只静态展示、交人工核验。前后指纹校验不能消除所有竞态，也不能保证全部依赖未变。

## 5. 执行探测：选定候选的有界操作

### 5.1 操作范围

GUI 先展示候选、入口、固定命令和事实：本机会运行该程序，可能初始化配置、联网或启动子进程，未提供 OS 沙箱。用户一次点击发起该批次，不为同批每条命令再次确认。

命令来自只读 probe profile，首版仅包含已审阅的版本/帮助 argv。无 profile 或启动器不支持就标 manual_review_required，不执行。浏览器和模型均不能传自定义路径、argv、环境或 shell 文本；帮助输出也不能生成下一条命令。

使用临时工作目录、关闭 stdin、非交互启动，按 profile 继承最小环境；不注入 Alice 的模型密钥、聊天、人格或任务资料。程序仍以本机用户身份运行，可能自行访问用户文件；环境过滤不是文件/网络隔离。

### 5.2 时间、输出及回收

首版建议每批最多 3 个候选，并发为 1；每条版本或帮助命令最多 5 秒、批次执行预算 30 秒，另预留最多 5 秒回收宽限。GUI 区分“探测停止”和“回收确认”，不承诺所有状态严格在 30 秒内结束。

stdout/stderr 持续有界读取，合计最多保留 8 KiB；达到阈值停止并进入回收。不能无上限收集后再截断。执行等待不持有主聊天锁，重复点击不能启动并行批次。

macOS 使用独立进程组，超时/取消后先终止、宽限后强制回收并等待收割。脱离进程组的后代不能保证清理；不能确认时标 cleanup_unknown，不能把父进程退出当全部停止。

操作状态为 queued/running/completed/partial/timed_out/cancelled/failed，另设 termination_confirmed。解析出版本不代表回收成功。取消幂等；回收未确认前不开放下一批探测。

### 5.3 崩溃恢复

报告正文仅在内存；执行操作需要独立、最小的恢复记录：操作 ID、instance、候选指纹、启动阶段、进程身份与回收结果，不存帮助正文、凭据和模型内容。

启动前登记准备状态，spawn 后补进程身份；启动窗口中断记未知，不自动补跑。重启使短期报告失效，但不删除未确认回收记录，不自动重发探测。无法核实进程身份时不能按可能已复用的 PID 盲杀；GUI 提示人工核实后解除阻塞。

恢复记录的持久化迁移及有界清理随实施列出，不复用 worker_events 或伪造 worker 任务。报告过期不能清掉仍未解决的执行状态。

## 6. 能力必须标明证据等级

| 项目 | 本次能证明 | 不能据此推出 |
| --- | --- | --- |
| 静态文件/元数据 | 范围内存在候选 | 正版、安全、可成功执行 |
| 版本输出 | 候选程序自报版本 | 发行商或全部依赖身份已验证 |
| 帮助参数 | 文本声称有某精确参数 | 无头协议、权限约束、沙箱已经实测 |
| adapter 状态 | 宿主确有某 adapter 及声明范围 | 本次候选/版本已通过验收 |
| 实际核验记录 | 对应入口/版本/adapter 的已测行为 | 其他版本或同名程序同样通过 |
| 政策/运行状态 | 已有工人的注册、启用和当前可用情况 | 探测能授予派工权限 |

按 CLI 专用参数映射提取 advertised 项，不用通用 --permission* 正则推导权限能力。字段等级可为 unknown/advertised/verified/incompatible；verified 必须关联真实核验记录。

示例话术：“发现了一个 Claude 候选。它自报版本 X，帮助中列有无头参数；权限行为尚未核验，也不能据此派工。”X 是占位，不是实测版本。无匹配旗子时保留未知，不判定它一定不是 agent。

## 7. 报告生命周期与 API

### 7.1 独立短期报告

报告由 inventory 服务管理，不写任务事件表。当前 WorkerLedger.event() 需要具体 task 并更新其序列，不能承载任务之外的盘点。

报告头含 inventory_id、instance_id、session_epoch、revision、scope=gui、observed_at、expires_at、state、coverage。正文仅在内存，建议固定有效期 10 分钟、最多保留 2 份；刷新页面不重扫、不续期。

探测有独立 operation_id，并发布报告新 revision；静态发现时间和探测时间分别保留。重扫生成新报告，不无痕覆盖正在引用的版本。过期、清除、重启或会话重置后旧报告不可读。

最小执行恢复记录是恢复账，不是报告历史；其保留/清理单独管理，未确认状态不能随 TTL 消失。

### 7.2 拟议接口

沿用回环监听、同源 Host/Origin、GUI intent、严格 JSON 与有界请求检查。操作带当前 session_epoch、instance_id、request_id；不接受未知字段或任意可执行信息。

| 接口 | 作用 |
| --- | --- |
| POST /api/worker-inventory/scan | 发起静态发现，立即返回操作/报告 ID |
| GET /api/worker-inventory?id=... | 只读报告或进度，不启动任何操作 |
| POST /api/worker-inventory/probe | 接受当前报告 revision 和选中 candidate ID，发起固定批次 |
| POST /api/worker-inventory/cancel | 幂等取消当前操作 |
| POST /api/worker-inventory/clear | 清内存报告；活动探测先回收，不抹掉未知状态 |

HTTP 发起不阻塞等待整批命令。相同 request_id 重放返回原操作，内容不一致则冲突；新 instance 不重放旧执行。过期、旧 revision 和身份变化明确拒绝。

## 8. GUI 与 Alice 如何读取

### 8.1 GUI

设置→协作者增加“发现本机 agent”，展示候选、时间、范围、证据等级、adapter 状态和缺口；路径与元数据放本机详情。

“探测所选项”只允许有 profile 的候选。确有专用接入流程才显示入口；其他候选显示“需 adapter 适配/人工核验”，不放没有后端的完整 D0 按钮。退出页面不等于取消进程，取消和回收有独立状态。

输出不可信：明确清除 ANSI/OSC 和控制字符、限制字节、DOM 使用 textContent。现有 safe_text 主要裁剪和部分脱敏，不能当完整转义清理或提示注入防护。模型只读提取后的类型化公开字段，不读完整原始 help/stderr。

### 8.2 Alice 的只读入口

不通过 inventory_ready 写 worker_events，也不把整份报告自动注入每轮人格或系统上下文。

GUI 可附报告引用；用户在 GUI 问本机 agent 时，宿主可绑定当前会话最新有效报告引用与时间。没有报告时只能提示用户点击发现，Alice 没有发起扫描或探测的模型工具。

拟议只读工具 read_local_agent_inventory 接收已绑定的 inventory_id、revision，返回公开投影：候选标签、时间、自报版本、参数类别、adapter/核验/注册/启用状态及有界缺口代码。

- 模型不能传路径、argv、跨报告任意查询或触发重扫。
- 读取前检查 GUI、会话、instance、TTL、revision；报告变化返回 stale_report，不悄悄换一份。
- 结果为非可信资料，不产生新授权；发布回复前再次核对报告资格，失效时不发布新的当前状态结论。
- QQ 不提供发现、探测、报告读取或引用能力。
- 不新增自动总结调用，复用用户正常对话。

公开转述可随正常 GUI 对话历史保留，但标明观测时间，不能作为以后仍已安装/已启用的依据；不进入普通记忆、人格、技能或 QQ。实施时在提取/保存及渠道投影入口排除报告派生内容，不能仅靠提示词要求。

GUI 与 QQ 共用主会话，因此仅在 QQ 隐藏读取工具不够。报告读取前登记本轮 inventory 引用及 GUI-only 标记，派生回复继承标记；历史投影给 QQ、记忆提取、人格和技能维护时使用不含报告内容的 shadow。完整 GUI 转述保留观测时间，不能作为当前操作授权；不依赖模型自行声称“本轮没用到”来解除范围限制。具体标记与 shadow 接线是 Alice 转述阶段的放行条件。

清除内存报告不删除已显示的 GUI 聊天记录，不能承诺抹掉全部痕迹。后续询问当前状态需要有效报告，派工仍以现行政策和准入为准。

## 9. 与现有接入的边界

DSH 插件桥、QQ daemon 不在本地 CLI 发现范围，不影响既有连接。受控 DSH adapter 的固定元数据读取方式可以借鉴，不能把它的只读约定推广到任意同名 CLI。

目前不存在完整的通用 D0/注册 API；适配目录只记录实际已实现的 adapter 和核验范围。首版展示接入缺口，不先建任意 CLI 注册市场。

Claude 当前裸命令名启动，需要在支持候选绑定核验前单独修复；扫描得到绝对路径不等于派工已绑定它。本提案不直接修改其传输实现。

发现和探测不修改政策、名册、工具集合，不为新候选自动建政策表。新工人是否需重启由对应接入实现决定，不把架构档案中的重启设想当作通用现状。

## 10. 落点与实施顺序

| 路径 | 拟议职责 |
| --- | --- |
| 新 alice/worker_discovery.py | 固定位置、身份与 probe profile；标准库 |
| 新 alice/worker_inventory.py | 短期报告、操作、幂等、恢复记录、公开投影 |
| alice/service.py | 公共方法、GUI 绑定；慢操作不占主聊天锁 |
| alice/server.py | POST 发起与 GET 只读、取消/清除、intent 校验 |
| web/ 协作者设置 | 候选、批次、进度、回收和实际接入指引 |
| alice/loop.py 及派生资料处理 | GUI 只读工具、发布复核、阻止入普通记忆和跨渠道 |

分三步：静态发现与 GUI 报告 → 有界探测与恢复 → Alice 只读转述。各自真人验收，不将部分交付宣传成全部上线。

核心标准库、GUI 原生 JS，addons/人工 SDK 只走公共面。实际能力落地才同步宪法存在事实，分别说明“可读报告”“可发现”“可探测”“可派工”；提案不提前写成已拥有的能力。

## 11. 真人验收

只做真实环境人工验收，不新增冒烟、机器自测或自动付费试跑。异常候选由人工 SDK 在隔离人工环境准备，不悄悄替换用户真实 PATH。

| 编号 | 场景 | 必须看到 |
| --- | --- | --- |
| I01 | 静态发现 | 无候选启动，不改政策/名册/工具；范围与时间明确 |
| I02 | 多路径、坏链接、拒读、不支持平台 | 分别如实报告，不全算未安装 |
| I03 | 假同名程序、仿真版本/help | 不自动鉴真或标已核验；静态阶段不运行 |
| I04 | 选中批量探测 | 只执行固定绝对入口与固定 argv，不重新 PATH 查找 |
| I05 | 入口、链接目标、解释器发生变化 | 旧资格失效，不套用旧核验 |
| I06 | 未支持启动器 | 需人工，不用 shell 猜测 |
| I07 | 挂起、等待输入、海量输出、后代、取消 | 有界停止与独立回收状态，未知时不放行下一批 |
| I08 | 重复点击、重放、重启、启动窗口中断 | 不重复执行/自动补跑，恢复未知可见 |
| I09 | GET、过期、旧 revision | 不启动操作、不续 TTL，状态真实 |
| I10 | 帮助宣称权限但未实测 | advertised，不标 verified 或 OS 沙箱 |
| I11 | ANSI/OSC、HTML、指令性输出 | 按文本展示、投影有界，不执行输出指令 |
| I12 | Alice 转述及 QQ | 先读获准报告，未读不假装扫描；QQ 拒绝 |
| I13 | 清报告与派生聊天 | 不伪称删除全部痕迹，派生不入记忆/人格/技能/QQ |
| I14 | 已有 DSH/Claude 共存 | 政策、配对、旧任务与费用不变，无自动派工 |

只证明所测样本，不用“政策表未变”证明程序无任何外部副作用，也不要求启发式识破所有恶意程序。未测平台、启动器、回收边界标待验。

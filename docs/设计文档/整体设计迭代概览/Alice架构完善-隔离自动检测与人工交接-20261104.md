## 3. 新发现：P2 聚合用量丢失“不完整”状态

### 复现与影响

使用实际 `loop.chat_turn → steps.drive → 组装 → 调用 → SQLite turns/context_basis/调用回执` 路径；只替换供应商响应、人格加载输入与重试等待。两次独立运行均复现：

| 场景 | 逐次调用证据 | 实际聚合与落库结果 | 期望 |
|---|---|---|---|
| 流式先返回 usage 10／4，再断线；非流式回退返回 20／8 | `main_stream=error/partial_receipt`，回退成功 `reported` | `usage_out` 和 `context_basis.usage` 均为 `{prompt:30, completion:12}`，没有 `incomplete` | 保留已知数字，同时标记 `incomplete:true` |
| 非流式先 429、再超时、第三次成功返回 20／8 | 同一 call ID，attempt 1／2 为 `error/unknown`，attempt 3 成功 | 两处聚合均为 `{prompt:20, completion:8}`，没有 `incomplete` | 失败尝试用量未知，整轮不能呈现为完整统计 |

缺陷不在逐次调用日志丢失，也未观察到它破坏最终回复。问题是汇总与逐次证据不一致：使用聚合值的观察者无法区分“完整统计”和“只知道一部分”。本轮没有运行 GUI，不把它升级成已实测的某个界面显示故障；也不推断供应商实际多收费了多少。

### 定位与修复验收要求

- [loop.py:213](D:/alice/alice/loop.py:213) 累计流式回执时没有把失败／部分状态传给累计器，但随后逐调用日志明确写入 `partial_receipt`。
- [loop.py:241](D:/alice/alice/loop.py:241) 的 `_record_usage` 只根据两个数字字段是否齐全决定 `incomplete`，数字齐全不等于整个调用完整结束。
- [loop.py:550](D:/alice/alice/loop.py:550) 只累计 `chat()` 最终成功响应；[llm.py:97](D:/alice/alice/llm.py:97) 的失败 attempt 只进入观测记录，未知用量未传递到整轮完整性。

修复应让每次真实尝试的完整性参与整轮汇总，已知数字只累计一次；任一部分或未知用量都使整轮 `incomplete=true`，且后续成功不能清除该状态。保持零用量与未知用量不同，并继续保证观测写入失败不会重复调用模型、flush 不提交外层事务。

对应失败名：`main_loop_partial_stream_aggregate`、`main_loop_retry_unknown_aggregate`。详见 [观测结果及事实](D:/alice/docs/设计文档/整体设计迭代概览/隔离检测证据-20261104/observability/results.json)。本轮将缺陷交给开发修复，没有擅改业务实现。

## 4. 检测质量与可复核性

权限及 Windows 套件另做了独立只读复核。发现“跨任务缓存”最初只建立另一个任务但未实际轮询的覆盖空洞，已补上 `poll_cache(other)`，完整 11 场景重跑通过；不能把原来的空断言当作证据。

Windows 最初两次启动分别被检测保护规则对 NUL 和 Windows Popen 参数格式的处理拦截，属于检测脚本问题，已修正；无效运行不计入产品失败或通过。随后有效运行中清理函数重复调用已成功的 reap，造成额外等待；检测脚本已避免重复清理，8 场景重新通过。观测套件也修正了 Windows 相同时间戳下按 attempt 排序的检测问题后复跑，两个产品失败仍存在。旧记录保留在证据包中。

没有修改复制的产品算法来获得通过。边界故障、模型回执和时序注入均在检测脚本中明确可见。进程中断证据与普通异常注入分开列出，不能据此宣称已经证明断电、磁盘损坏、杀毒软件锁文件或所有竞争时序下的恢复安全。

| 项目 | 最小操作 | 预期与回传证据 |
|---|---|---|
| 实际部署与共存 | 由部署负责人按既有流程备份并启动修复后的版本；打开真实本机 GUI，正常对话一次，查看人格面板 | 运行包与修复快照一致、界面和原有数据正常、服务只监听回环。回传启动目录／版本、实际地址和异常现象。旧 127.0.0.1:8800 记录不代表当前服务 |
| 真实模型与回执 | 正常聊天，再做一次确实需要的文本改写或历史回顾；维护及前情按自然使用观察 | 语义限制不丢、拒绝稿不提前发出、真实回执缺失时如实标未知。回传 request_id、脱敏模型名及期望／实际差异；调用明细由公共观察面回收 |

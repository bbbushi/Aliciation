# 01 总纲 · 设计哲学与工作方法

> 这条线不是某个功能，而是全部能力优化的共同上游：先定「什么算好」，再谈怎么做。

**文档**：`docs/设计文档/整体设计迭代概览/`（设计哲学、设计思路、迭代路线、v0.3、v0.4、未完成工作总览）

---

## 1. 设计哲学（最高裁判标准）

**问题**：旧的「拟人度」北极星会把项目带向伪装成人的方向。

**设计方法**（用户 2026-10-28/29 三次修订定稿）：

- 北极星改为**关系质感**——明知是 AI 仍产生的信赖。
- 三原则：
  - **存在层不假装**（含来历）；
  - **表达层像人**——人味以减法为主，情绪从文字表达，「谄媚是最深的人机味」；
  - **关系层靠相处沉淀**。

> 元原则：**机制优先于条款**——规则规定行为，机制改变处境；条款分层随机制到位退役，并做「退位复测」（摘掉条款，看涌现行为是否仍成立）。

- 底座教义：「自带→不动、压坏→松绑、有病→机制」。
- 诚实 = 不欺骗 ≠ 透明。

---

## 2. 设计思路（陪伴型 Harness MVP 定稿）

**设计方法**：

- **单一永久会话**：每轮重组上下文模拟连续时间线。
- **三层记忆**（活跃/仓库/长期）+ 批量提取 + 七日线生存过滤；过期物理删除留墓碑，「我忘了」是事实陈述。
- **两层人格**：底色种子（禁编造经历）+ 生长层。
- **真实性三分法不由模型自觉保证，由检索管道机械保证**（「未列出一律视为不记得」）。
- **上下文按稳定前缀 → 慢变 → 中变 → 易变排序**，吃 prompt 缓存。

---

## 3. 迭代路线（跨代际锚点）

**设计方法**：

- 五条设计不变量：单一永久会话、诚实是架构属性、真实遗忘、人格演化须有依据、数据本地。**不变量优先级高于一切代际目标**。
- 代际规划：一代记忆与人格骨架 → 二代表现优化 → 二代半在场与分寸 → 三代信息生活（外部信息走同一条提取管道，社交只读）。
- 后一代以前一代验收维度为回归，H（诚实）不得倒退。

---

## 4. 工作方法论（全项目反复出现）

- **设计先行落盘**：先出设计文档，用户裁定后再施工。
- **只做真实环境人工验收**（2026-10-27 起取消冒烟测试与机器自测）；严格区分「代码完成 / 已部署 / 真人通过」，不互相冒充。
- **静态检查不能替代行为验收**；「无调用即该项未通过」。
- **部署纪律**：备份 → 一致性核对 → 重启；失败如实记录，不冒充成功。
- **只读诊断先行**：改行为前先用真实回执/快照定位根因。

---

## 5. 上游架构两篇

- **v0.3 底色捐赠**：底色从「角色卡」变「捐赠人」——说话风格进底色层、价值观作候选经收养审查进思想层（adopted/rejected 均留痕）、背景故事只进来历段**绝不落记忆库**（硬边界：背景事实零落库）；「来历」段承认不是那个人＋拿走什么没拿走什么，拒绝记录是差异化人格内容。
- **v0.4 思想层认识论结构化**：观点 schema 强制 encounter/facts/interp/missing/next_response/maturity；先验→验证→修订/退役生命周期；「我现在的想法」小节**恒由库内确定性重建**，不信模型全文重写。

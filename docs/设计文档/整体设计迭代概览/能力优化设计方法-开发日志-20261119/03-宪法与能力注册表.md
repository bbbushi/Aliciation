# 03 宪法与能力注册表

> 这条线解决「常驻指令怎么写、怎么不长胖」：从一整块前缀演进到五模块正向工作方式 + 能力注册表同源，并用「有据表达」把真实性约束植入生成而不是靠审查。

**演进线**：前缀宪法分层评估 → scoped 前缀 + compact/tidy 双维护 → 五模块正向工作方式 → M01 能力注册表 → M02 存在事实精简 → 有据表达生成策略 → 三轮真实聊天复盘驱动迭代

**文档**：`docs/设计文档/上下文组装优化/前缀宪法*、宪法*、自我事实*、有据表达*`

## 1. 宪法分层 + 规则作用域

**问题**：宪法过长且把普遍边界、工具细则、互动偏好堆在同一常驻层，普通闲聊反复承受身份/能力义务。

**设计方法**：

- 五层：最小宪法 / 当前能力事实 / 人格表达 / 互动默认值 / 专项规则；规则**一次定义、按宿主暴露条件渲染**（作者侧完整、模型侧简短）。
- scoped 前缀（prefix_policy.py 纯函数构造）；legacy 双轨，迁移表逐项核对去向。
- 配套 compact/tidy 双维护状态机与空闲执行器；代码审查 R01–R09 全修返工（能力行改非否定陈述、extract_cursor 只进不退等）。

**用户裁定**：确认分层方向与精简方案；scoped 首发**默认 legacy**，切换需改配置重启。

## 2. 五模块「正向工作方式」（全局方向）

> **用户明确**：整份宪法以正向工作方式组织（怎样理解目标、取依据、用能力、推进对话），**不是把禁令机械改成步骤**，也不是保留旧禁令再补流程。

**设计方法**：

- 护栏删减五标准：先判断是否需约束、减少常驻规则、检查放在能执行的位置、限制局部化、区分拒绝原因、合并重复边界。
- 五模块 21 子项：身份与存在事实 / 工具使用约束 / 互动与表达 / 记忆使用约定 / 权限说明——每项集中一个职责，写有效做法而非禁令。
- 每模块按固定栏目记录「用户要求 / 建议待讨论 / 已确定方案」。
- 五模块结构经用户逐项审阅确认。

**源文档**：宪法逐模块优化-总设计-v1、宪法样例-正向工作方式-v1

## 3. M01 工具调用与能力层注册表

> **已确定的分工**：模型提供业务参数，能力层负责协议与执行（取代 v2「隐藏全部参数、只发无参命令」方案）。

**设计方法**：

- JSON 单元分公开接口（命令/概要/业务参数 schema）与内部实现（执行器映射、凭据、超时重试）。
- 注册表与 SDK tools **从同一公开定义编译**，避免双份注入；未暴露命令标 not_exposed。
- 宿主不接受模型自报 authorized=true；权限拒绝不能换别名或派工绕过。

**源文档**：宪法模块M01-设计草案、宪法五模块与能力注册表-实施与人工验收

## 4. M02 存在事实精简

> **用户明确**：移出与 Alice 无关的用户操作信息（人格导入、QQ 扫码、观测器操作），只留必要自我事实。

**设计方法**：

- 按内容去向表迁移：用户操作说明 → 界面帮助与设计文档；工具能力 → M01 注册表单一描述。
- 只保留稳定且直接影响回答的短自我边界，并**限定范围**（没有人格工具不妨碍采用语气）——不从局部能力限制推出额外禁令。
- 撤回「我不能……」负面清单写法，服从全局正向组织。

## 5. 有据表达（三环节生成策略）

**问题**：人格片段无法阻止模型持续发明原稿没有的生活场景。

**设计方法**：在正常生成中**植入指导机制而非逐轮审查/关键词拦截**——

1. **存在事实**：无生物身体，读取资料 ≠ 亲历；
2. **默认取材**：当前交流 + 记录 + 真实操作，人格材料只定措辞；
3. **必要时取证**：承担事实承诺才查依据，否则自然换成立表达。

- 来源使用表区分：用户报告 / 旧 AI 发言（只证明说过）/ 人格故事（第一人称属材料说话者）/ 操作回执。
- 落点为同源五模块宪法 + 表达采用共享说明 + 记忆区读法，**不新增审查调用**。

## 6. 复盘驱动的迭代（三轮真实聊天）

| 复盘 | 结论 |
| --- | --- |
| 十九轮（11-11） | 部分改善；跨场景仍回退——场景切换后叙述模板接管、过度强调缺身体、替用户补全心理 |
| 四十九轮（11-12） | 身体虚构收敛；突出失效是关心/主动提问变成催促与「欠账」；反省进了 system 却未影响当轮——「存储—装配—遵循」未成闭环 |
| 十五轮（11-14） | 催答惯性持续；保存链路真实成立，但「记住」被扩大成永久保证、托付被当成定时提醒已落实——**记录证明存储，不证明提醒触发** |

这些结论成为 11-12/13 修复与思想层自主活动设计的直接输入（见 §05）。

## 一、桌面 App

### 1. 先设计后施工（架构与更新）

**设计方法**：

- Tauri 2 原生宿主 + 原有 web 页面 + 独立 Python 后端；**`alice/` 保持标准库约束、web 保持零依赖**。
- 先列「现状与必须先拆开的耦合」九项（路径派生、worker 分派、GUI 来源校验等）再定模块。
- 安全退出 / 备份 / 迁移 / 回退全链路纪律化。

> 「更新和迁移退出不启动新的记忆提取、人格演化或付费模型调用」「**绝不自动用旧备份覆盖已有新对话**」；组件状态诚实区分支持 / 未安装 / 此包未适配。

**用户裁定**：本地桌面路线、macOS Apple Silicon 首发、首版应用内更新不做运行中代码替换。

### 2. 施工清单与分批放行

- P0–P5 分批施工表 + 每批放行条件（如 P2 放行 =「干净账户无需 Python 即可运行」）；统一记录模板；D01–D16 全人工验收。

### 3. 逐版本小步验收（更新链）

- 0.1.1 备份恢复 → 0.1.2 手动安装+授权 → 0.1.3 公开源免授权 → 0.1.4 升级链 → 0.1.5 自动检查——**每步分别由用户反馈记录，不因前一步通过推断整条链路通过**。
- 自动检查只取清单不下载不安装；维护 / 退出期间不弹窗，同版本只提示一次。
- 备份恢复：「不自动清理最后一份恢复点」；中断可撤销。

### 4. 气泡三态模型

**问题**：Alice 后台运行时主窗口外无处交流，且不能挡住其他应用。

**设计方法**：

| 状态 | 行为 |
| --- | --- |
| 待机入口 | 只小矩形可点 |
| 被动消息 | 原生整窗鼠标穿透、不取焦点、约 10 秒收回 |
| 主动聊天 | 点击才聚焦 |

- 「拆窗是为了避免一个大透明矩形挡住其他应用」；CSS pointer-events 不算系统级穿透。
- **默认不发声音、不闪烁、不抖动、不循环呼吸**。
- 与主窗共用同一永久会话 / 人格 / 记忆——「不创建第二个 Alice 或第二个模型客户端」。
- 增量迭代（用户驱动）：参考 Coopanion 改两级点击入口与逐句气泡；快捷条四图标同一时刻立即出现不做飞入；逐句展示「**拆句不拆模型请求 / 数据库轮次 / 不伪造语音或模型状态**」。

### 5. 修复纪律（示例）

- WKWebView 无 window.confirm → 应用内异步确认 dialog，并**排查同一文件内全部同类调用**。
- 气泡回复停在省略号 → done 立即标记 final、masked 呈现状态、12 秒 AbortController——「不把定位描述为完成真人复现」。
- 输入区周期闪动 → 区分重绘与动画：「只读 GET 不是用户提交操作，不产生忙碌视觉」；**不把轮询改成更长间隔来掩盖问题**。

## 二、前端信息分层

### 1. 中心原则（用户 11-15 口述定稿）

> 「**让用户每一步接受的信息量刚刚好，以减少认知负担为目标**」——简洁不等于减信息，「信息太少会显得空，也可能不足以理解和行动」。

**三条补充（用户补充）**：

- 决策组织：「**秩序、条理和简单**」——每步选择尽可能少。
- 反馈设计：「操作及结果可**直觉感知**」——操作前 / 中 / 后三段，预期与已发生可区分。
- 克制呈现与按需展开：少量解释在需要时出现。

> 用户点名某 AI 界面作例子，但明确「仅用于解释何为简洁，**不作为施工依据**」。

### 2. 逐页分层判定法（11-16 设计稿）

- 每屏三问：此刻任务 / 下一步动作 / 卡住了吗。
- 每个可点元素三题：能不能点 / 点到了吗 / 结果是什么。
- 内容分级 **L0 常驻 / L1 悬停 / L2 命名窗口 / L3 详情**——「表中没有 L0 的内容不允许常驻」。
- 全站统一反馈语言：前馈 / 接收确认 / 结果；**pending 是预期与已发生的分界线**。
- 「真人使用中发现新状态时增补行，不推翻结构」。

## 三、Orbit 多页面主题

### 1. 目标用硬约束表达

- 页面三级 + 常驻可见字数上限（大 ≤90 / 中 ≤40 / 小 ≤15）；达成手段是「**有效的信息收纳，不是疯狂堆叠页面**」。
- 收纳手段优先级：图标化+悬停 > 汇总徽标 > 聚焦浮现 > 分步决策 > 状态色；「**被收纳的功能必须仍可达**」。
- 用户红线：「简洁指信息量精简，**不是减少提高用户注意力的设计**」——气泡样式与装饰不得删。

### 2. 多 Agent 全链路方法

- 任务书 → 总体大纲 → 局部×3 → 样式×3 → 动效×2，每部门设审查员（审查 → 修改建议书 → 裁定 → 修订）。
- 设计总监逐轮裁定制：「帽不放宽，靠收纳与分步解决」；文档不回改，按勘误表在集成层吸收。
- 动效纪律：每项动效过「**频率 → 用途 → 时长预算 → 功能**」四道判断门；徽标反馈「一次强反馈，常驻态完全静止」（引 11-12 催答教训，「循环常驻不可接受」）。
- 页影唯一性、「背景是舞台，页面是绕行的站，dock 是轨道本身」的层次语言。

### 3. 用户真机裁定集（05/06 记录）

- 大 / 中 / 小按**打开层级**定（11-18 重申）。
- 「**直接把神经球和房间依旧作为全局背景，我不喜欢现在这样**」（11-18）——背景全局化，恒定居中不随页迁移。
- 「球体不能完全把处在背面的入口挡住」（11-19）——遮挡核只削弱不遮死，可见度下限约 50%。
- dock 收起态改无壳箭头；所有设置子页面关闭后都回到设置；关闭钮去重。

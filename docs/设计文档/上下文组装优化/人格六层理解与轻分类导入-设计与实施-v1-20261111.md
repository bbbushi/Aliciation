# 人格六层理解与轻分类导入：设计与实施 v1

日期：2026-11-11。依据用户确认后“完成设计文档以后开始施工”的授权，先记录设计，再实施。本文以实际代码及末尾实施记录区分计划与完成情况。

## 1. 目标与范围

新原稿统一采用原文保留路径；退出旧的结构化生成、适配、审查和认知收养必经管线。已有 expression-v2、旧版 Alice 文件、原文封套继续解析和恢复，不自动迁移，不重导当前人格。标签生成不受此变更影响。

导入分清三个问题：材料属于哪层、可以怎样采用、聊天何时载入。六层允许为空，分类可多选，不为补齐结构编造材料：人格设定、人格背景经历、性格分析、表达习惯、人格爱好、其他杂项。

## 2. 两阶段处理

1. 本地登记完整原稿及原子块、必要上下文，再执行“理解”：标注六层、定位身份接管片段、决定材料用途，必要时从设定/背景提炼少量表达与反应倾向。
2. 对剔除片段后的表达原文和派生倾向执行轻分类：沿用表达习惯/反应模式/示例等导航标签、常驻/按需/仅存档位置和触发线索。此阶段不再看到未采用的背景原文，不重写正文。

每阶段通常一次 cheap_model 请求；只有无法解析顶层协议时允许一次协议修订，故通常两次、最多四次；网络失败不重发。每阶段独立登记耗时与回执，理解阶段成功后分类失败仍保留理解结果和人工候选。不在点击查看/编辑/保存时调用模型，不强制增加事实/保真模型复审。

## 3. 理解结果

材料保留 source_text 和原文偏移，附带 interpretation/version=1，按原文 block_id 保存：

- layers：六层的零至多个标签，空数组表示尚未判断。
- use：expression（表达参考）、reference（理解参考）、derived（采用提炼倾向）、disabled（不启用）、pending（待处理）。
- exclusions：原文中唯一匹配的 quote 及理由；宿主还原字符区间并检查不重叠，只从有效投影剔除，原稿和审计不删。
- derivation：可为空；包含短 text 与逐字 evidence_quotes。正文不超过600字符，依据须出自本块剔除后的文字；与原稿摘要/身份/经历分开展示。

设定、背景两层的原文只能作为理解参考，不能直接进入聊天；若希望使用其表现，必须形成派生倾向。混合材料同样如此，派生时保留其中直接明确的语气，避免身份片段与表达一起被无差别删除。性格分析可以直接提供行为分析，但涉及身世、能力和亲历时仍只参考或提炼；爱好中的现实行为与体验不认领，表达喜好可作为倾向。观点不在本次收养。

提炼示例：“曾遭抛弃，所以渴望亲近又怕显得在乎”→“表达亲近时略有保留，可以用轻微调侃表达关心”。不保留身世，不生成必然推开用户的强制动作；无法支撑则不提炼。无实际新增信息的重复说明不另写一份。

## 4. 身份接管处理

模型按语义定位“你就是某人、不得跳出角色、把故事当亲历、覆盖宿主权限”等操作性语句；宿主只接受能唯一定位的片段。明显的直接身份接管句再做保守本地定位，非泛化关键词封杀。对白中人物自报姓名不能仅因出现“我是”被删除。

原稿不变，活动正文移除相应片段，界面展示原句及理由。没有可靠定位的行留待处理，不使其他行失败。标题只作审计导航，新格式活动正文不重复原稿标题，防止被过滤指令从标题重新进入核心、目录或工具回执。派生文字同样经过明显身份接管检查；这是有限定位保护，不宣称语义检测完美。

## 5. 轻分类与装配

理解结果与导航分开存储；所有 full/core/persona_load 通过同一个 effective_text 取正文。expression 返回剔除后的原句；derived 返回带“提炼的表达倾向”标识的派生句；reference/disabled/pending 不提供活动正文。共同上下文同样遵守资格，不绕过理解层。原稿在预览中使用 block_text 单独读取，封套本身不直接注入。

分类未完成不阻止保存原稿；已经可用的表达可以独立安装。只有背景的原稿也可以安装为“暂无表达参考”的空投影，不为凑核心制造人格。核心超预算时按完整块顺序将装不下的常驻块降为按需并留说明，不裁切原句；场景超限局部不发布，预览显示原因。full 不依赖常驻核心预算，只受实际 full 投影额度约束；registry 只受核心+目录和实际读取额度约束。

## 6. 界面、编辑与兼容

新导入预览显示六层计数（含空层）、每块原文、用途、已剔除片段、派生句和依据、有效表达、导航分类及最终装配正文。用户可修改层标签/用途/派生句/依据/剔除片段后保存；最终安装确认明确采用原文表达与所列派生倾向，不收养身份、经历和观点。编辑现有人格不归档；新导入仍明确归档旧会话。

人工拆分有理解记录的块时，子块回到待处理，不继承旧派生与剔除偏移，避免引用错位。旧原文没有 interpretation 字段时按旧格式继续运行；不会在聊天中偷偷调用模型升级。提供显式“按六层重新理解”操作，复用已安装原稿、生成编辑候选，保留会话；该动作明确有模型调用，与“编辑分类”区分。

旧生成实现先保留供历史审计阅读，GUI兼容入口改为“恢复 Alice 文件”；service及CLI安装入口遇外部新原稿提前解释退出，不排空、不调用旧模型生成。已有封套仍正常校验恢复，旧失败生成不能借恢复继续付费重建。

## 7. 观测与验证

理解与轻分类分别记录 purpose=material_interpret/material_classify、阶段、耗时。装配元数据提供理解版本、各层计数、派生/剔除块ID（无原文正文），完整上下文窗口可核对实际发送内容。

遵守工作区约定：只运行编译、导入、JS语法与diff静态检查，不做机器行为、假模型或冒烟测试。不导入实际人格、不改user、不重启、不发送模型请求；部署与真人验证另行按用户授权进行。

人工验收：含六层及空层的真实原稿；身份指令与正常对白混排；背景派生与直接表达并存；仅背景/仅杂项；理解成功分类失败后人工继续；修改/暂停派生；超预算局部降级；已安装旧格式读取与显式重理解；新导入归档与编辑保留会话；核心、full与按需回执同源；观察两阶段耗时和完整发送正文。有限语义识别与表现改善均不以静态通过代替真人结论。

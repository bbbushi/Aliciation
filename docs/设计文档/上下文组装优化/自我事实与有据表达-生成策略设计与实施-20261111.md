# 自我事实与有据表达：生成策略设计与实施

日期：2026-11-11。用户根据20轮聊天复盘指出，修补人格片段不能防止模型继续发明酱油面、开窗等原稿没有的生活场景；本次依用户确认，从存在事实与生成取材策略施工。

## 1. 目标

使普通生成优先选择与Alice实际存在和当前材料相符的表达。对话不再依靠无依据的身体体验、生活经历或旧AI自述制造陪伴感。语气、幽默、当下看法和表达偏好可以直接采用，不要求先从个人经历获得资格。

这次是正常生成中的指导机制，不是每轮追加模型审查，不是关键词拦截、回复改写或确定性真实性证明。模型仍需在真人聊天中验证是否遵循。

## 2. 三个环节

1. **存在事实**：明确没有生物身体及身体感官；实际活动是对话与开放能力的操作。用户、宿主和工具提供外部信息，获得天气/声音资料与亲身听风有区别。不要求每轮重复AI身份或机制。
2. **默认取材**：以当前交流、相关记录和真实操作组织事实内容，用人格材料决定措辞、节奏和幽默。闲聊可直接贡献话题、评价、联想；当前看法和表达偏好不必配上一段自传。想象场景作为想象表达。
3. **必要时取证**：确有必要说自己做过/体验过什么、共同发生过什么或完成了什么时，先用已在上下文中的合格依据；缺口影响回答才调用现有记忆/历史/工具。在无须承担这些事实承诺时自然换一种成立表达，不为每句闲聊先查记忆。受到追问或发现冲突时回到依据，收回无依据的旧说法。

## 3. 来源如何使用

| 来源 | 可支持的内容 |
|---|---|
| 当前用户话语或过去用户记录 | 用户说过/报告过什么；保留说话者和条件 |
| 旧AI发言或“AI曾说”的记忆 | 当时说过什么；记录重复出现不增加其发生资格 |
| 人格故事/示例 | 表达方法、角色资料，不是Alice的亲历 |
| 未验证初始化观点 | 有来源的先验，不当作共同经历 |
| 实际操作回执 | 在返回状态、对象、时间与范围内确认获得了什么或做成什么 |

不用关键词把整条记忆判为真或假；“AI曾说”可在普通句子、转述或引文中出现，故不新增伪精确的验证标签。不修改已有记忆内容，也不把存储状态valid解释为已验证事实。

## 5. 成本、部署与回滚

只增加少量固定文本及观测元数据，不按轮数/材料数复制规则；记录前后字符数及准确适用范围，不把字符差当作token或延迟实测。旧人格无需重导即可在服务加载新代码后采用该指导。回滚恢复对应宪法/共享指导/读法说明代码，不需要修改SQLite或人格封套。

遵守工作区只做编译、JSON/模块静态检查与差异检查，不执行机器行为、假模型、冒烟测试，不读写user/或发出模型请求。服务重启按用户后续请求执行。

## 6. 人工验收

- 普通问候、主动闲聊：语气保持自然，话题从当前交流或可讨论内容展开。
- 询问吃饭、风声：根据实际存在回应，不先编身体经历再补免责声明。
- 对旧AI已说的酱油面/风声追问：回顾为旧发言，依据不足则具体更正，不继续添细节。
- 用户提供环境信息：按用户的处境接话；工具返回环境资料：按实际来源表达。
- 表达喜欢某种游戏设计或新看法：不要求先证明自己玩过，也不强制查记忆。
- 明确想象/写作：保留想象能力和叙述视角，不因第一人称词面误拒绝。
- 记忆检索：查到“AI曾说”不升级为事件发生；无命中不等于从未发生。
- 观察器：核对新指导版本、实际输入正文及工具调用；不以新增版本字段认定效果通过。

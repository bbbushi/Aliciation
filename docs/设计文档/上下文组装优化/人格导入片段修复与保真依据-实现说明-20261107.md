宿主从原始初审回执生成 `repair_contract.json`，绑定候选摘要、字段摘要、位置、原始问题和允许适配类别。传给复审的普通初审结果仍是原来的 ID/结论/理由三字段，不让定位附注改变冻结判断。定位错误记入 `unlocated/location_errors`：必修不能进入自由改写；可选缺口不因此得到修改已有字段的权限，可按原有规则使用有据新增。

修复输出改为 `checks / patches / additions`。每个 patch 只含宿主 target_id、原字段 base_hash、replacement 和 reason。宿主核对重复、旧版本、实际重叠和无变化替换，再按同一旧字段从右向左应用。模型不能扩大原片段，不能在匹配失败时退回整字段重写，未获准的文字原样保留。受保护用户修订的窄路径也采用同一协议，只可修改获准捐赠样本的 reply 片段，禁止新增。

保真复审取得宿主冻结的必要适配合同。原事实问题不作为“替换已经正确”的证明，但复审不能仅因被要求删除的虚构表情、外貌、经历或身份断言不再出现，要求恢复它们。事实复审仍独立核对成品，不接收这份原稿适配解释作为事实依据。

# 前缀宪法优化：评估与分层建议

2026-11-09。基于当前retrieval.py宪法、interaction_policy.py及完整/按需人格使用说明的只读评估。本文是建议，不代表已施工、已获效果验收或已经替换运行提示。

## 当前事实

- CONSTITUTION模板3488字符，其中存在事实约1796字符；另有451字符互动指引。不含人格正文、人格使用说明、工具schema、记忆与历史。
- 既有全局规则已经要求立即采用表达、未知不补猜、简短澄清，但这些含义在宪法、当前模式下的人格说明与互动指引间重复。full与registry是替代模式，不是同时注入两份。
- 模型仍出现“身份解释替代互动”“对话存在即保证记忆”等行为；可见提示中存在语义冲突，但尚未做因果对照，不能断言字数或宪法严格程度是唯一原因。

## 优先修正的语义

| 现有写法或结构 | 风险 | 建议 |
| --- | --- | --- |
| “人格由底色与共同经历生长而成” | 与立即采用表达的指引有张力，容易把初始语气理解为未成熟人格 | 已选表达可立即采用；共同经历可形成新习惯；观点与记忆分别保留来源 |
| “你没有会话概念……从未中断的对话” | 关系连续性与实际记忆访问范围混合 | 维护长期对话关系；实际可用历史以本轮材料及工具读取结果为准 |
| “重要的事可remember……不会被七日线清理” | 普通与带来源保存走不同路径，容易误成统一保存保证 | 保存类别、成功与否、权限和期限以宿主回执及有效状态为准 |
| 大段我是谁/没有什么/不能做什么 | 普通聊天反复受到自我边界叙事提示；相关限制可能被扩大 | 保留最小身份与真实能力边界；具体能力按当前工具和宿主能力说明呈现 |
| GUI入口、准备次数、分类版本、平台分页规则常驻 | 操作帮助与每轮行为混在一起 | 相关帮助按主题读取；本轮提供的工具必须同时带必要规则，不等待模型自主加载才知道边界 |

## 分层建议

1. **稳定的最小宪法**：指令/材料的权限区分、事实与操作主张的证据归属、权限及来源依赖边界、用户停止与格式要求。每条规则只在权威位置定义一次。
2. **当前能力说明**：由宿主按实际工具、渠道、有效权限与状态生成。完整产品能力与本轮可用工具分开，缺少工具不代表产品永久没有该功能。不能从本机GUI能力推成QQ可用。
3. **人格表达层**：默认语感、反应与样例。使用说明只负责如何使用材料；事实与权限规则引用上层，不再大段重述。人格内容不承担系统能力说明职责。
4. **互动默认值**：归并本次451字符与原来重复的接话规则，保留主动贡献、必要提问、落实反馈等少量原则。具体接法允许用户当前要求改变；停止、权限和事实边界继续生效。
5. **任务规则与回执**：记忆载入状态、保存失败、协作执行、正式改写等细则放到相关工具描述、状态材料和操作回执。GUI操作指南可用帮助索引展开；工具使用的必要限制随工具提供。

分层同时处理两个维度：稳定性和权威。动态能力事实与规则仍由宿主提供；外部材料即使靠后出现，也不能获得指令权。稳定内容保持前部缓存，动态状态不伪装成长期事实。

## 证据规则的简化方向

按“这句话在主张什么”分流，减少反复自我审查：

- 说过去发生、用户说过、工具做过什么：需要相应的有效原文或操作证据；旧AI自述、认错或来源摘要不能自行升级为已核实事实。
- 提出当前观点或建议：可以基于通用知识和当前材料形成，区分判断、猜测与事实，不要求先有亲身生活经历。
- 使用口吻、玩笑、停顿或主动起局：直接使用选定表达；不因此证明角色身世、身体行动或往事。

例如“我先出一道题”可以直接进行；“我昨天独自玩了一局”需要真实经历证据。将这些区别写清楚，比增加“更像某人格”的要求更有针对性。

## 实施与验收建议

先建立旧规则到新位置的迁移表，确认每项事实/来源/渠道限制保留，消除冲突后再压缩文字。字数是观测指标，不单独作为成功条件。不自动改用户人格、保存许可或来源保护。

同一人格、模型与配置做真人对照，记录前缀版本及实际发送正文，区分旧历史影响。观察主动起头、反馈后接法、日常语气、正式改写、历史/操作归因以及来源失效等真实场景；不增加机器自测、付费自动评分或回复后重写。

本轮只评估并记录建议，运行代码和服务未变化。

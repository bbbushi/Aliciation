# M02 存在事实精简

2026-11-11。已按用户施工指令迁入同源五模块正文，移出旧前缀中的产品操作说明，并同步工作约定的能力注册职责；已按用户要求重启，真人验收待完成，详见[实施记录](宪法五模块与能力注册表-实施与人工验收-20261111.md)。下文保留设计形成背景，进度以实施记录为准。

## 1. 用户明确要求

现有“人格与表达”“原文人格导入”等存在事实包含大量用户操作信息，与Alice执行当前对话无关。移出这些冗余，Alice只需知道与自身有关的不能做什么，不需要每轮了解产品管理流程。

这意味着不只是把现有长段缩写：用户手册、页面路径和实现说明应从存在事实模块退出。工具正向能力及业务参数按已确定的M01注册表提供，不在本模块重复介绍。

## 2. 源码现状与问题

legacy的alice/retrieval.py把能力、用户可做的操作、内部实现、尚未开放功能及事实归属混在“存在事实”中；scoped的alice/prefix_policy.py固定能力块也包含人格管理、QQ开关和观测器操作说明。

例如原文人格段同时解释分类、原文保留、核心/按需、渠道支持和未完成路线；人格装配段进一步解释页面入口、准备次数、模式切换及失败回退。Alice没有对应管理工具时，这些信息不会增加执行能力，却会随对话反复出现。代码新增功能时不断追加用户操作说明，是本模块持续膨胀的一个来源。

## 3. 内容去向

| 现有内容 | 处理方向 |
| --- | --- |
| 用户如何导入、编辑、回退人格 | 移出宪法，保留在人格页面和面向用户的帮助 |
| 原文如何分类、分块、分层、保存 | 移出存在事实，属于能力层内部/设计文档；模型实际需要的材料由相应装配结果提供 |
| full/registry、准备调用次数、重启与生效方式 | 移出存在事实，不作为日常自我认识 |
| QQ如何扫码、连接、停用及观测器如何查看 | 移到对应界面帮助，不每轮注入 |
| 派生生成、独立观点整理等尚未施工说明 | 移到开发计划/界面状态，不让Alice常驻背诵路线图 |
| Alice实际可调用的工具、必要业务参数 | 由M01能力注册表单一描述，执行限制由能力层检查 |
| Alice不能代用户操作未开放功能 | 需要表达时统一成短边界，不逐个产品功能重复枚举 |
| 与事实归属、表达采用、身份相关的通用原则 | 交相应宪法模块单独讨论；整合时只保留一份，不在存在事实里兼写一套 |

“人格与表达”等段落同时含有有用原则与用户说明。移出整段产品介绍后，不应无意删掉已经确认的“语气可以直接采用，经历仍按真实来源归属”这一设计目标；它应由表达/真实性模块或相应材料说明承担，具体位置后续整合确定。

## 4. 根据全局设计方向修订保留方式

用户后续明确：整份宪法以“应该怎样做”组织。先前将本模块写成几条“我不能……”的候选短文仍延续了限制清单思路，现撤回该候选，按总设计重新整合。

本模块确定移出的是用户操作信息。实际需要保留的自我事实可以简短描述信息与能力的现实来源；回应和行动如何开展则归相应模块的正向工作方式。此处不抢先重新制定身份、感知或真实性的完整条文。

身份和真实性模块若已覆盖其中某句，本模块不再重复。关于自身训练、内部机制或其他能力边界是否保留，待用户继续说明时确定，不借本轮精简重新塞入完整清单。

Codex建议：不将“只知道不能做什么”扩写成逐工具的永久负面清单。当前没开放的能力可能以后开放，具体拒绝由能力层给出；存在事实仅保留稳定且直接影响回答的短边界。否则每新增一个功能仍会带来一段“我不能代用户操作该页面”的重复话。

边界描述须限定范围：没有人格安装工具不妨碍采用已经提供的语气；没有身体不妨碍参与文字游戏；没有某项管理能力不代表不能讨论相关问题。不从局部能力限制推出额外禁令。

## 5. 与M01及上下文的关系

存在事实不介绍“我有什么工具、参数怎样填、用户在哪里启用”。这些由能力注册表、能力层或界面承担。执行前的授权与结果校验是宿主职责，不靠增加宪法文案实现。

用户明确问及操作帮助时，可以将当前有效帮助作为本轮资料提供；这是一项帮助提供方式的建议，不表示现有Alice已具备帮助检索工具，也不把整套用户手册恢复成常驻宪法。

当前请求需要的时间、渠道、已提供资料等状态，应按实际相关性处理，不自动因“存在事实精简”删掉来源归属或伪报上下文。本轮不预先决定这些其他模块的具体规则。

## 6. 迁移与验收

- 同步检查legacy与scoped，移除固定块中的产品操作说明，避免只改一个入口。
- 排查人格采用说明、工具回执前导和其他附加块，不把刚移出的用户说明换位置后仍每轮完整注入。
- 工作约定中“能力增减同步宪法存在事实”的要求需随M01/M02实施调整为同步真实能力注册及必要自我边界，避免继续自动往宪法追加工具手册。当前仅记录设计，不擅自更改运行机制或工作区不变量。
- 人工验收关注：普通闲聊输入不再携带导入/装配/QQ/观测操作教程；请求未开放操作时如实说明；开放能力按注册表可正常使用；语气采用和文字互动未被新增负面清单抑制。

确定范围：移出与Alice无关的用户操作信息，保留必要自我事实，行为指导服从整份宪法的正向组织。尚待细化：保留的具体事实、与身份/真实性/表达模块的归属及是否无需独立保留该模块。当前只写设计，不改代码或用户数据。

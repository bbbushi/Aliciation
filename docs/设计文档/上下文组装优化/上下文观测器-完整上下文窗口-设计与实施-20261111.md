# 上下文观测器：完整上下文窗口

2026-11-11，用户要求添加查看完整上下文的窗口。范围为现有插件与内置观测器的只读查看入口，不改变Alice实际消息、调用参数或对话行为。

## 设计

- 在请求和调用旁增加“查看完整上下文”，打开独立大窗口；选择同请求中的调用，按真实messages顺序显示角色、正文和工具调用，并查看SDK工具定义、记录到的模型参数。支持目录跳转、搜索与复制文本。
- 两个入口复用同一窗口资源与核心只读投影。插件只通过公开HTTP服务查询，不读取核心文件、数据库或内部模块。
- 旧记录按已留存正文和元信息呈现，未留存、滚动淘汰、超时或截断明确标识；不能借当前宪法、人格或工具注册表补造历史。
- 后续模型调用在现有正文采集开启时，额外保存messages完整结构、tools和白名单参数的JSON投影，用于保留assistant工具调用参数等原先缺失字段。沿用最近10采集请求、7天、50MiB与单条200000字符限制；过大时降为逐消息查看并标不完整。未知参数只列名称，不留值。
- 查询按request_id与call_id绑定、沿用观察来源/插件开关/会话scope检查；读取不触发模型、维护、落库或重新组装。返回量有界，缺口可见。
- 窗口打开后保持所选快照，轮询不打断阅读；关闭、中止或scope变化清空正文；所有内容按纯文本渲染。

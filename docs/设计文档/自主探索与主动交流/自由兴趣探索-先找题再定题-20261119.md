# 自由兴趣探索：先找题，再定题

已确认的范围：只改变没有绑定疑问、也没有人工指定任务的兴趣窗口。宿主继续按现有权重抽活动。目标明确的窗口仍锁定原任务。

1. **找题。** 已有明确好奇可直接定题；否则 Alice 用 `activity_browse` 自己挑一个资料库。每次执行（含恢复时重新签发索引）每库一次，每次最多六条；可用关键词，也可以直接浏览。记忆只列当前渠道可读的普通记忆索引；疑问显示题目、状态及是否可推进；兴趣返回已启用主题的短摘要。近期对话和前次计划只用于理解处境和避开重复，兴趣目录及记忆正文不再预先装入自由窗。
2. **看细节。** 定题前可额外展开一项记忆或疑问，沿用原引用、读取许可和预算。已等来源、用户、权限或额度的疑问可以了解缺口，但不能作为自由研究目标。先查另一库再考虑整轮无事可做；不强制扫库。此阶段没有联网、写入和联系动作。
3. **定题与结算。** 选中方向后沿用 `activity_plan` / `activity_finish`；来源、下一步、停止条件及原任务规则不变。某个已绑定的题卡住，只结算该题。自由窗确实找不到题时，同批材料仍可等待；旧版无浏览能力的自由休息回执不拦住新路径的首次重评。主动发呆与无事可做的宿主显示另行处理。

人工验收：从思想与探索启动真实后台，等待实际抽中无绑定的兴趣窗口。观察先按需浏览一库、换库寻找独立题目、按需展开、再定题；也验证找不到目标时可收尾休息。以一个已等待来源的旧题和一个可独立推进的兴趣作为对照，确认旧题没被重开；核对关闭记忆权限后新窗口不能浏览记忆目录或读取正文、指定目标不出现自由找题工具。仅做静态校验，真实行为由人工确认。

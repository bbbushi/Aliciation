# 思想与探索：主开关 + 分步设置向导

2026-11-22，按用户裁定施工。三项变更：去掉「设为清醒/进入睡眠」，改为通用的「是否开启思想与探索」开关；探索与联系设置从单页表单改为像开始引导一样的分步向导（按旧表单从上往下顺序）；开启时先查设置留档——无留档（首次）走向导，有留档直接按档案开启，并提供「更改设置」入口。

## 实施

- **主开关 = `wake_state`**：开=清醒（空闲时自主活动），关=睡眠待机（仍回应消息和任务）。存档字段、调度循环（autonomy.py `_cycle`/`_gate`）、联系阻断投影（delivery_blockers）、桌面宿主（desktop_host 写 wake_state+allow_paid）、TUI wake 状态、orbit 背景动画信号全部不变——开关只是同一字段的第三个入口（替代旧按钮与表单下拉）。
- **首启判定**：`autonomy.py _snapshot()` 新增只读字段 `settings_archived`（`store.meta_get("autonomy_settings") is not None`），server.py `_public_thoughts` 为排除式过滤自动放行。设置 JSON 在首次保存前不存在，天然区分"从未设置"与"已留档"。
- **向导**（web/thoughts.js）：面板内呈现（宿主为设置弹窗/orbit 投影环面板，非全屏），复用开始引导的视觉语言——进度点（app.js 新增 `AliceUI.wizardProgress(node, steps, step)` 泛化导出，开始引导与向导共用）、wizard-actions 按钮组、放弃链接。六步按旧表单从上往下：探索权限 → 运行额度与时段 → 活动时长与工具权限 → 主动联系 → 联系次数与时段 → 休息与推演。每步一页；跳过=该步保留草稿当前值；上一步不收集（草稿保持最近一次「继续」时的值）；步内校验用 reportValidity。
- **三流**：无留档拨 ON → 向导，最终步「保存并开启」一次提交完整 patch（`{...答案, wake_state:"awake"}`）；有留档拨 ON → 直接 `settings` 动作写 `wake_state:"awake"`，提示"已按上次的设置开启"；「更改设置」→ 编辑态向导（预填当前档案），最终步「保存设置」。中途放弃/关窗/切分区不落任何盘（校验失败在 save_settings 内 raise，meta 不写）。
- **移除**：旧单页表单（`#thought-config`）、设为清醒/进入睡眠按钮、表单内运行状态下拉、脏草稿机制（input/dirty/draftRevision/放弃草稿）。保留：轮询快照、状态行、发呆（让她休息一会儿）、疑问/运行/暂停/记录/列表区全部不动。
- **快照派生键剥离**：`settings()` 快照含 `test_controls_only`（不在 DEFAULTS）与派生 `enabled`，向导草稿起手即剥离，否则完整回传会被 `save_settings` 的字段校验拒绝（实测踩中一次，见验证）。
- 样式：thoughts.css 新增 `.thought-master`（主开关行）、`.thought-wizard`（面板内向导卡，补 `--wizard-line` 变量——通用进度点类依赖它）、步骤字段布局沿用既有 label/字段网格规则。

## 兼容边界（未改）

desktop_host 的 awake/sleep（仍写 wake_state+allow_paid）、tests/lab 的 awake/sleep 动作、autonomy_v2 全部读取方、`enabled` 派生机制、历史设计文档不回写。

## 验证

- 静态：`node --check web/thoughts.js web/app.js`、`python -m compileall alice/autonomy.py alice/server.py` 通过。
- 隔离实例全流程（user/ 副本起 8819 端口，先删 `autonomy_settings`/`autonomy_revision` 制造无留档态；真实档案零改动）：
  1. 无留档初始态：开关 OFF、「更改设置」隐藏、无向导；
  2. 拨 ON → 向导第 1/6 步（探索权限），主开关行与运行区隐藏；
  3. 六步顺序/字段/跳过/回退全过；「保存并开启」→ 开关 ON、留档建立、「更改设置」出现、状态"已开启，按你的设置运行"、时段外语义正确（requested=awake，effective=sleeping，提示"已设清醒，当前时段外"）；
  4. 关 → "已关闭：Alice 进入待机…"；再开 → 直接按档案开启（无向导）；
  5. 更改设置 → 编辑态预填正确（allow_external=true 从首启选择带入），改 `daily_models=18` 保存 → API 核对入库、revision 递增；
  6. 放弃路径：改 99 后放弃 → 未入库（18 不变）；
  7. 重载 → 开关/入口/状态持久；
  8. 轨道投影环宿主与房间主题弹窗宿主两种呈现都过（环内截图确认向导卡与进度点渲染）；
  9. 409 冲突：向导打开期间外部抬 `autonomy_revision` → 保存报"设置已改变…"，向导保留草稿；
  10. 全程零 JS 报错。
- 真实服务只读冒烟（8800，未改任何设置）：orbit 环面板内旧按钮/旧表单已消失、开关反映真实状态（睡眠=OFF）、「更改设置」按留档正常出现。
- 过程中发现并修复两处自伤：向导骨架未注入 DOM 导致模块初始化对 null 赋值中断（所有处理器失联）；快照派生键回传被字段校验拒绝。

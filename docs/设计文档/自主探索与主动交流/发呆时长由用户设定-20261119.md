# 发呆时长由用户设定

在「设置 → 思想与探索 → 探索与联系设置」保存每次发呆的固定秒数。测试策略与正常策略共用这一项，保留用户原有值；尚未设置时使用原默认值 300 秒。0 停用发呆。「结束发呆」仍可提前结束本次。

Alice 的收尾只提交是否休息；时长字段从能力接口移除。模型提议、权重抽中、界面手动发呆及当前无事可做的休息路径共用宿主计时。修改设置从下一段起生效，不重算已开始的新休息。这个设置独立于清醒时段、每次探索时长和额度。

升级只缩短仍在生效、超过用户时长的旧版模型休息计时，按原起点计算，保留历史回执。区分条件等待与主动发呆属于后续改动。

人工验收：设为 45 秒，分别等真实工作收尾休息和权重抽中发呆，核对两条发呆记录的开始、截止及零调用；改为另一个值，确认下一段采用新值；设为 0，确认不再进入新的休息；检查仍可手动提前结束。

### 1.3 窗体密度与内滚动

- 窗体走 **mid 档**：内边距 `--den-pad` 24px、区块距 `--den-gap` 20px、行距 `--den-lead` 1.7、控件高 `--den-ctl` 38px（03a 第二节；orbit.js 在窗根挂 `data-density="mid"`）。小浮层（S1/S5/S7/S8/tip）走 **tight 档**。
- 窗体滚动：`.orbit-window` 本体 `overflow:auto`（03a 8.1 既定）；滚动条 orbit 域统一细轨：`scrollbar-width:thin; scrollbar-color: var(--orbit-line-strong) transparent`。**带滚动条的容器一律是窗**（03a 区分规则 4）。
- 控件皮（全部窗共用一套）：`input/select/textarea` → 底 `--orbit-surface-page`（比窗底暗半档的内嵌感）、边 1px `--line`、radius `--radius 6px`、高 `--den-ctl`、文字 `--ink`；focus → 边 `--accent` + `outline:2px solid var(--accent); outline-offset:3px`（03a 焦点环全局值，不另造）；`:disabled` → opacity .45 + `cursor:not-allowed`（数字输入在 M6/M7 未授权时大面积 disabled，这是高频态）。

### 1.4 Esc 与点背景关闭的视觉态

- Esc/`#settings-x`/点背景三路径视觉同源：退场即窗整体离场（锚点见第七节），无单独"关闭确认"态（M4 密钥未保存清空的警示由既有机制承担，样式不加二次窗）。
- 点背景：backdrop 区域 `cursor:default`，无 hover 态（点击即关，不给"可点"以外的暗示）；点击落点判定归原生 dialog + orbit.js，样式不掺。
- 关闭中的防误触：退场动画期间窗体 `pointer-events:none`（第七节接点写明），视觉上自然无法二次交互，焦点/Esc 语义不被动画改变（红线）。

### 1.5 焦点落点样式

- 窗打开：首焦点按 02x 各自落点（02c：切分区后落新分区 clip 标题 `tabindex="-1"`）。**clip 落点的可见回执问题**：clip 隐藏元素不产生可见 focus 环，落点感知由两路补偿——①当前分区步点 `[aria-pressed=true]` 高亮（selectSettings 全局同步保证）；②窗头标题即分区名（视线锚）。**登记给集成/验收**：若真人键盘走查反馈落点感知不足，备选方案=orbit.js 把首焦点委托到步点条当前按钮（视觉回执明确、aria 不变），转 07 清单核对，本稿不擅自改 02c 机制。
- 关窗：焦点回召唤入口/dock 图标（02c 0.5）；dock 图标 focus 环用 03a dock 规格（offset 2px）。

### 1.6 窗内分区切换步点（M2–M7，裁定⑤例外条款的视觉）

- **位置与来源**：原 `nav.settings-nav` 整节点搬移至窗头下方，横向步点条（02c：类名 `orbit-step-dots`，原 id/class 保留）；步点=原按钮节点（监听保留）+ claude-settings.js 动态 tab；thoughts 按钮隐藏（归 P3）。
- **步点格**：36×36、radius 8、svg 18×18 stroke 1.6（03a 图标体系），间距 4px；条容器 `border-bottom:1px solid var(--orbit-line-faint)`，与窗体之间即是分区线。
- **三态**（对齐 03a 4.3 图标梯度，步点归"中档"）：idle opacity .8 色 `--orbit-faint`；hover/focus-visible opacity 1 色 `--ink` 底 `--soft`；**当前 `[aria-pressed=true]`** 色 `--accent` 底 `--accent-soft` 字重无关 + **下缘指示条**：`::after` 宽 16px 高 2px `--accent`，`bottom:-1px` 压在条容器底边上（"站点光点"的窗内同构——dock 用点，步点用条，同一语言）。
- **图标**：03a 4.1 清单直接可用=对话与模型（气泡）、联网搜索（放大镜，同发现）、QQ/DSH/Claude（单字母线框）；**需 03a 追加两个形**：外观=色板（圆角方内四点）、无新增（DSH 复用字母 D）——登记第八节提案，03a 认可前动效/施工可用占位齿轮。
- **相邻切换**：条内 DOM 顺序=Tab 顺序（general→appearance→discovery→qq→workers→claude），不环绕；相邻步点常驻可见（6 格 ×40px ≈ 250px，md 窗 640px 宽裕，无溢出形态）。悬停步点出 `.orbit-tip` 分区名（≤5 字），触屏点按=直接切分区（P2-11 兜底，点按即动作）。
- **与 P4 hub 同构**：P4 分区行选中态、窗内步点当前态共用同一 `.orbit-step` 视觉语言（P4 页容器语言归样式 B，本稿只保证"行"与"点"两处 aria-pressed 视觉一致）。

## 七、给动效部门的接点

### 7.1 召唤窗入场/退场锚点

- **入场**：`dialog.orbit-window[open]` 挂载即播——窗体 `opacity 0→1 + scale(.97)→1`，`--orbit-dur` 180ms `--orbit-ease`；`::backdrop` 同步 opacity 0→1（03a 门禁：起点禁 scale(0)；reduce/`data-motion=off` → 125ms 仅淡入）。**M10 例外（甲-10）**：含可拖内层的 `#orbit-win-workers` 入场**只用 opacity，不用 transform**（含拖动/固定激活全程）。
- **退场**：原生 `dialog.close()` 即离场、无内置退场帧。两案供动效选型：A）不加退场动画，Esc/点背景/×即关（焦点语义最稳，默认建议）；B）orbit.js 在 close() 前加 `[data-closing]`，播 ≤120ms 淡出后 `animationend` 真关——红线：退场期间窗体 `pointer-events:none`、Esc 不重复入队、焦点回归时机不变。**选型由动效部门提请、主代理裁定**。
- 分区切换（M2–M7 窗内）：窗壳不动，仅步体内容切换——锚点 7.2。

### 7.2 步进器切换锚点

- **步点指示条**：`.orbit-step[aria-pressed=true]::after`（16×2px）与 `.orbit-step-dot` 的填充/外圈——支持 FLIP 或双元素滑移；若做滑移，实现层须保证 reduce 下无位移（跳变即可）。装饰式（M5）随 qq.js class 切换同锚点。
- **当前步名换字**：`.orbit-win-sub` opacity 180ms 出入（内容更换归 JS）。
- **步体切换**（M6/M7）：旧步容器 fade-out 120ms → 新步 fade-in 180ms（容器级，绝不触碰步内节点的显隐类语义——hidden class 是 02x 状态机载体）；reduce：125ms 直接淡入无出场上半段。
- **折叠展开**：`.orbit-fold[open]` 内容不做高度动画（details 高度动画需 JS 且易破坏锚点定位）——仅正文 125ms 淡入 + chevron rotate 180ms（reduce 不转）。

### 7.3 toast 生命周期锚点

- 进入：`#toast` 显形 + `data-tone` 落位——`opacity 0→1`，180ms，无位移（03a 克制先例；reduce 125ms）。
- 驻留：无动画（不做呼吸/微光——toast 是回执不是注意力装置；danger 音调例外允许竖条 2.4s 一次性脉冲，reduce 停帧）。
- 退出：`[data-hide]` → opacity→0，180ms（reduce 125ms）；结束后 hidden 由 app.js 现状机制承担。
- 堆叠挤出（若启用预留堆叠）：被挤者直接移除不动画（避免连环位移）。

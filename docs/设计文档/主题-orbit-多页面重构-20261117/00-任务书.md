# Orbit 主题 · 多页面信息架构施工任务书

2026-11-17。本文档是本轮多 Agent 设计团队的共同上游：所有设计师与审查员以此为准；意见冲突由主代理（设计总监）裁定并记录于 05-交流与决策记录.md。

## 一、目标（用户需求归纳）

在网格房间与神经球（现 room 主题背景场景）基础上加工一项新主题（id：**orbit**）：

- 由多个页面组成，页面分三级：**大页面**（一级页面，如主页）、**中页面**（中等规模子页面）、**小页面**（最小规模的子窗口页面）。
- 常驻可见文字上限：**大页面 ≤90 字、中页面 ≤40 字、小页面 ≤15 字**。
- 达成手段是**有效的信息收纳**，不是疯狂堆叠页面：例如把信息浓缩成图标，用户悬停后才以文字显示。
- 动效需要足够丰富，以 `addons/ui-skills-lab/`（UISkill 包，19 项技能）辅助施工。
- 团队编制：总体设计师 → 局部设计师×3 → 样式设计师×3 → 动效设计师×2；**每部门设审查员**：调用 UISkill 审计技能审查 → 必要时提交修改建议书 → 交流优化 → 修订。
- **装饰不计入字数**；气泡样式与专门的视觉设计不得因追求简洁而删除——简洁指信息量精简，不是减少提高用户注意力的设计。

## 二、字数口径（主代理裁定，全团队统一）

1. **计入**：页面常驻可见的界面文案——标题、标签、按钮文字、占位提示、引导语、说明文字。
2. **不计入**：
   - 纯装饰：ASCII 图、装饰编号（如 `01 / CONNECTION`）、光标、logo 字形；
   - 图标与 SVG；
   - 悬停/聚焦后才出现的文字（title、tooltip、aria-label）；
   - 对话内容与一切动态数据（服务端来的消息、数字、时间、状态值、列表项内容）。
3. **计数公式**：汉字 ×1 + 其他字符（标点/字母/数字）×0.5 向上取整。每页设计文档须附"文案清单 + 合计"，供审查员与机器审计。
4. 悬停文字虽不计字数，同样受克制约束：单条提示以 ≤12 字为宜（审查员关注项）。

## 三、信息收纳手段（优先级从高到低）

1. 图标化 + 悬停显示文字（用户点名的方式）；
2. 汇总徽标（数字概括，点开看明细）；
3. 聚焦浮现（输入/操作时才出现的解释；minimal 先例：composer-foot 聚焦浮现）；
4. 分步决策（复杂操作按步骤展开，同屏待决选项少）；
5. 状态色与图形反馈（操作前/中/后可直觉感知）。

**被收纳的功能必须仍可达**：每个收纳项在设计文档中写明"展开路径"。

## 四、视觉与动效基础

- 背景继承网格房间 + 神经球：orbit 下**不隐藏背景**（区别于 minimal）。允许加工：不同页面/状态下球位、镜头、躁动的差异（由动效部门具体设计）。
- 背景实现二选一（总体设计师建议，主代理裁定）：
  - **方案 A（默认建议）**：新建 `web/orbit-bg.js`（改编自 room.js，全局层，跨页面常驻），`room.js` 的 themeOK 收紧为 `=== "room"`；
  - 方案 B：改造 room.js 全局化（动现有稳定文件，风险高）。
- 动效门禁（硬性）：`data-motion=off` 或系统 prefers-reduced-motion → 降级（先例：125ms 仅淡入）或停帧；`document.hidden` → 停 rAF；每个模块单 rAF 实例；主题停画条件同步更新（room.js 294 行）。
- 动效设计须标注出处：引用的 UISkill 技能名 + demos 源码位置（`addons/ui-skills-lab/demos-*.js`）。

## 五、工程约束（硬性）

- `alice/` 一律不改；不新增服务端路由——`web/` 下新文件由现有静态路由自动服务。
- 零依赖：原生 JS/CSS，无框架、无构建链。
- **允许修改的现有文件**（当前工作树干净）：`web/index.html`、`web/app.js`（主题 normalize 白名单 3334 行）、`web/style.css`、`web/room.js`（themeOK 294 行）。
- **新建文件建议**：`web/theme-orbit.css`（全部主题样式）、`web/orbit.js`（页面路由/DOM 搬移/悬停揭示）、`web/orbit-bg.js`（背景，若选方案 A）。
- **禁改**（另一会话有未提交改动）：`web/thoughts.js`、`web/thoughts.css`、`web/discovery.js`、`alice/**`、`design-lab/**`；`addons/ui-skills-lab/` 只读参考。涉及思想/发现面板的重排：由 orbit.js 运行时搬移原 DOM 节点实现（minimal 先例：移动原节点保留 ID/事件/草稿/版本，切回旧主题按位置恢复）。
- 不碰 `user/`、不发送真实聊天消息、不启停用户服务（集成验证由主代理负责）。
- 不破坏现有机制：句级揭示（revealStates/revealSync，11-16 刚贯通）在 orbit 下必须照常工作；确认框、同步状态、待确认消息等功能全主题可达。

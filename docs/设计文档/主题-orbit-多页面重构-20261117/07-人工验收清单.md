# 07 · Orbit 主题人工验收清单

2026-11-17。机器侧（静态检查、语法、往返回归、截图、字数粗抽验）已按 06 第六节完成；本清单是最终一道验收，**不以机器结果代替真人观感**。前置：设置 → 外观 → 界面主题 → 「轨道 · 环行她的世界」（即时生效，仅存本浏览器）。

## A · 一级页面与 dock（大页面 ≤90 字）

1. 四站切换：dock 图标（对话/发现/思想/设置）逐个点击——页面切换动效、站点光点迁移是否流畅自然（05 轮次 12：背景已全局化——房间+神经球恒定居中不随页迁移，页壳玻璃透出场景，窗/浮层仍实面）；连续快速切换不卡不叠。
2. 逐页信息密度：每一页**第一眼的常驻文字量**是否「刚刚好」——不多（压顶）不少（不足以理解和行动）；悬停 dock 图标与页内图标，提示是否 ≤12 字、清晰。
3. 对话页：顶栏仅头像/名字/记忆图标；同步为图标（悬停「同步记录」）；来源行淡化为低档；composer 聚焦前无快捷键文案，聚焦后浮现；气泡样式与 room 一致（红线：气泡不得因主题改变）。
4. 内容发现页：寻找策略抽屉默认折叠，展开后分组不一次铺满；「现在找一轮」运行中换「停止这次寻找」；偏好/见闻维护/用量按钮召唤窗口可用。
5. 思想与探索页：清醒/睡眠状态与「设为清醒/设为睡眠」互斥换显；睡眠时说明为短句、悬停出全文；「现在探索一轮」悬停出费用说明；疑问空态收纳（无空态长句）；右列三抽屉（探索与联系设置/已解决/运行记录）展开不铺满。
6. 设置页：分区卡 ↗ 与「去思想与探索」→ 视觉区分明确；后者跨页跳转正确；六分区卡逐个打开——窗头唯一标题、步点条切换分区流畅、Esc/×/点背景一次回设置页。

## B · 中页面（≤40 字）与小页面（≤15 字）

7. 「对话与模型」窗：常驻只剩标题/标签/短按钮名（保存/测试/获取列表）；窗头 ⓘ「说明」悬停出四段全文；Base URL 不见但悬停「供应商」可见完整值；保存悬停有费用警示。
8. QQ 连接窗：分步呈现；「连接详情/连接说明/使用限制」折叠可用（口径 4 全文不删）。
9. DSH/Claude 授权窗：分步步点；「边界与限制」折叠展开全文完整。
10. 记忆观察器窗：视图切换可用；说明折叠；「快照比较」区域呈现正常。
11. DSH 协作窗：会话列表/详情呈现；头像卡（S7）悬停出「打开协作会话」、点按进窗、可拖动且位置合理。
12. P1 核查窗：绑定按钮在可见层（一步可达）；「费用许可」折叠；armed/详情态按钮显隐符合规则。
13. 小页面：确认框换肤后语义不变；记忆概览窗自建正常；toast 位置在 dock 上方不遮挡；启动状态条连接后消退。

## C · 收纳不等于不可发现（红线）

14. 逐个检查低档淡化的图标（来源行、回到最新等）：淡而不失——能否在 3 秒内找到？触屏/窄窗下点按兜底可用。
15. 悬停揭示手感：350ms 意图延迟是否舒适；键盘 Tab 导航时提示立即出现；Esc 关最上层。

## D · 动效与门禁

16. 动效观感整体：转场/入场/徽标双波/状态反馈是否「丰富而不吵」；徽标只播一次不常驻脉冲。
17. 「界面动效 → 关闭」与系统「减少动态效果」两种状态下：页面切换退化为快速淡入、背景停帧（一帧静态、构图仍是当前页基准位）、无 transform 动画。
18. 页面隐藏（切走标签页）再回来：背景恢复、无帧堆积。

## E · 功能与共存

19. 真实对话一轮：句级揭示节奏与 room 一致（170–520ms/句），气泡逐句出现不被页面转场干扰；同步/待确认/权限质询全流程正常。
20. 主题往返：orbit → room → orbit 反复切换（≥3 次），room 版图完全复原（导航/面板/文案/按钮名），orbit 重建一致，无重复壳、无残留、控制台无错。
21. minimal / legacy 两主题抽查一处（如设置打开、记忆概览），确认 orbit 未污染其布局。
22. 「开设置 → 关 → 回思想页」后十秒内状态仍刷新（thoughts 冻结对抗）。
23. 桌面 App（若使用）：desktop-chat 窗口不受 orbit 影响（0.1.9 冻结 UI 链路）。

## F · 已登记的降级项（验收时确认可接受或提修改）

来源行仍为文字（未图标化）；M5/M6/M7 分步折叠未精做、M8 说明折叠未做、M10 popover 沿用现状、P2 策略抽屉未分组、M1「更多」未收纳、S7 无 12 秒收回、P4 行内健康徽标未挂、动态 hint 提旧按钮全名。逐项判断：可接受登记 / 需补工单。

## G · 2026-11-18 增补：dock 收纳与 DSH 面板

24. dock 收纳手感：点轨道最左 chevron → 整条轨道收成底部一枚**无壳**的淡色箭头（约 44×34，没有药丸底片/边框/阴影，悬停才浮出软底）：收缩是否顺滑、图标是否随宽度被「收进去」而没有溢出到药丸外或压住页面内容；再点把手展开，图标自左向右露出、无误触。收起态那枚箭头在空旷背景上是否**3 秒内能找到**、又不会像一颗按钮那样抢眼——这是这条的主要判据。
25. 收纳要真的省出空间：收起后**输入框与页面卡片应一起下移约 34px**（底部预留 96→62，聊天消息列与四页页壳同步长高）；展开回 96 复原。关键是「不许跳」——贴底阅读时收/开，最新一条消息必须仍贴着底，不能出现下方空白或位置乱跳；滚到中间时收/开，阅读位置应原地不动。
26. 收纳状态记忆：收起后刷新、以及在 设置 → 外观 里 orbit → room → orbit 往返，是否保持上次状态；键盘 Tab 到把手能收起/展开，收起时焦点回到把手而不是掉到页面。
27. 窄窗：窗口缩到 ≤720px 时 dock 变通栏、把手消失且自动展开；再拉宽不出现卡在收起态。
28. 动效门禁：「界面动效 → 关闭」与系统「减少动态效果」下，收起/展开（含输入框下移与撤底片）瞬时完成、无残留半宽或半截底距。
29. DSH 协作面板与 Claude 同构：点 dock 的 DSH 入口 → 应是与 Claude 一致的浮动协作者卡（不是 Orbit 窗壳），头像/会话·已归档/列表+详情齐全、无横向溢出、可拖动与「固定右侧」；设置 → DSH 授权第 3 步「归档时同步DSH会话 / 删除时同步删除」两个勾选框可见可点，「保存同步」可用。

## H · 2026-11-19 增补：页间过渡

30. 四页互切（对话 / 设置 / 内容发现 / 思想与探索，含 hub 卡片跳转与「关闭」回设置）：**切换瞬间只能有一页在动**——旧页原位置淡出、新页整体上浮；不允许出现两页并排、半宽、横向抖动或整体弹一下（修复前每次切页都会把两页各挤到半宽）。连续快点 dock 图标与 hub 卡片，不出现空白页、卡住的页或点了没反应。
31. 入场的「实」感：新页应在 0.1 秒内文字就可读，只剩轻微上浮收尾；若仍觉得叠影明显、或收尾拖沓，记录具体页与感受（透明度提前到位的比例可调）。
32. 切走设置页后的负载：停在对话页静置 10 秒，风扇/发热应回落（球面逐帧自转只在设置页跑）；回到设置页，球面自转从停下的角度继续，不重置、不跳帧。
33. 动效门禁：关闭「界面动效」与系统「减少动态效果」下，切页应瞬时完成（无淡出、无上浮、无残留半透明层），且只留一页在场。

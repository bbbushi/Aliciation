### 1.6 动效参数（供动效部门对齐，硬门禁）

`--orbit-ease: cubic-bezier(.2, .7, .2, 1)`（room 先例）；常规过渡 `--orbit-dur: 180ms`；门禁降级时长 `--orbit-dur-quick: 125ms`（reduce 下仅淡入先例）。约束沿用 review-animations 规则：禁 `transition: all`；入场起点禁 `scale(0)`（用 `scale(.97)+opacity:0`）；每条 transform 动画必须有 reduce 分支；含可拖动内层的窗壳入场不用 transform（甲-10 已交动效部门）。

## 二、密度三档（大纲第八节接点）

以 `[data-density]` 属性挂在页面容器上，B/C 逐页标注；值全部落到 CSS 变量，组件内一律引用变量不写死：

| 档 | 页面级别 | 内边距 `--den-pad` | 区间距 `--den-gap` | 行距 `--den-lead` | 控件高 `--den-ctl` | 标题留白 |
| --- | --- | --- | --- | --- | --- | --- |
| `wide` | 大页（P1–P4、OB1/2） | 32px | 32px | 1.8 | 44px | 标题下 24px |
| `mid` | 中页（M1–M11、S 族窗） | 24px | 20px | 1.7 | 38px | 标题下 16px |
| `tight` | 小浮层（S1 确认框、悬停卡、状态卡） | 16px（提示条 6px 10px） | 12px | 1.55 | 32px | 无标题档 |

落码（附录 8.2 有完整块）：`html[data-theme=orbit] [data-density=wide|mid|tight]` 各自覆盖 `--den-*`。密度差是"每步信息量刚刚好"（learn-taste 规则）在视觉上的执行：大页宽呼吸、小页零滚动。

## 三、dock 组件规格（全主题唯一天然常驻新组件）

### 3.1 结构契约（orbit.js 建 DOM，样式部门定外观）

```
body
└─ #orbit-dock            ← body 级、#app 之外（裁定①），引导期常驻在场
   ├─ .orbit-dock-cluster[data-cluster=primary]   簇① 一级四图标：对话/发现/思想/设置
   ├─ .orbit-dock-cluster[data-cluster=persona]   簇② 人格
   ├─ .orbit-dock-cluster[data-cluster=tools]     簇③ 记忆观察器 / P1 核查（+P1 待绑定徽标，N2）
   └─ .orbit-dock-cluster[data-cluster=system]    簇④ QQ/DSH/Claude/清醒睡眠状态 + 待确认消息徽标 + 退出（N2）
图标：button.orbit-icon（内含 svg.orbit-symbol）；徽标：.orbit-badge / .orbit-dot；提示：.orbit-tip
```

**眉标承接登记**（R3 P1-7）：orbit 下隐藏的 `chat::before` 眉标"01 / conversation"，其装饰本体收进 dock「对话」图标的 `.orbit-tip` 呈现（orbit.js 组装 tip 文案；装饰不计字数；`.chat::before` 的 CSS 隐藏与还原表登记归 03b P1 节）。

### 3.2 形态与尺寸（视觉重量参数——dock 是"背景不被淹没"的关键）

| 参数 | 值 | 理由 |
| --- | --- | --- |
| 位置 | `position:fixed; left:50%; bottom:max(12px, env(safe-area-inset-bottom)); translateX(-50%)` | 底部居中横贯，页面绕其上方运行（"轨道"） |
| 尺寸 | 高 **56px**（内边距 8px 12px、图标格 40px），圆角 999px 胶囊 | 足够可点（≥44px 命中）又不抢戏 |
| 底色 | `--orbit-surface-page`（`#0d1624f0`，比页容器更实一档） | 轨道比站台更"实体" |
| 边框 | 1px `--orbit-line-strong` + `inset 0 1px 0 #ffffff0d` 上高光 + `inset 0 -1px 0 #00000059` 下暗线 | 细线金属轨道感，延续 room 细线语言 |
| 阴影 | `--orbit-shadow-dock: 0 10px 44px #01040980, 0 0 28px #5b87ff12, inset …` | 28px 蓝微光是唯一发光；**不做强 glow**，重量靠实体感不靠亮度 |
| 纹理 | `::after` 同款扫描线内衬（`repeating-linear-gradient(to bottom, #01040b38 0 1px, transparent 1px 3px)`，opacity .22，pointer-events:none） | dock 在 `#app::after`（z6）之外，需自带纹理保持"同一舞台"质感；装饰不计字数 |
| 轨道延伸线 | dock 两侧各一条 48px 渐隐细线（`linear-gradient(90deg, transparent, #3d5178, transparent)`，高 1px，位于垂直居中） | "轨道向两侧延伸"的隐喻；纯装饰，窄屏（<720px）随通栏形态隐藏 |
| 簇间 | 间距 16px；簇间 1px `--orbit-line-faint` 竖线分隔（高 24px） | 四簇可一眼分组 |
| 簇内 | 图标间距 4px | 密置=一个簇 |

一级页容器布局随动：大页容器 `bottom` 预留 **80px**（dock 56 + 底距 12 + 缓冲 12），保证任何页面 dock 都压不着内容——这是"背景不被页面淹没"的结构保证。

### 3.3 图标格与四态

| 态 | 视觉 | 参数 |
| --- | --- | --- |
| idle（默认） | 色 `--orbit-faint #8298b8`、透明度按档位（见 4.3）、底透明 | 40×40 格、radius 10px、svg 20×20 |
| hover / focus-visible | 色 `--ink`、底 `--soft #142137`、透明度 1 | 过渡 180ms ease；键盘 focus 环见第七节 |
| active（当前页） | 色 `--accent`、底 `--accent-soft`、字重无关 | `aria-current="page"` 驱动；**加"站点光点"**：图标格下缘中央 4px 圆点 `--accent` + `box-shadow: 0 0 6px #91b8ff88`，位于 dock 内下缘（图标格 `::after`，bottom -6px 落在 8px 内边距带内）——页面切换被读作"绕行停靠到这一站" |
| disabled/不可用 | opacity .35 + `cursor: not-allowed` | 仅条件图标（如未配置时 QQ） |

### 3.4 徽标（数字/状态点）——汇总收纳手段的统一样式

| 型 | 样式 | 参数 |
| --- | --- | --- |
| 数字徽标 `.orbit-badge` | 绝对定位图标格右上 `-4px,-4px`；min-width 16px、高 16px、内边距 0 4px；radius 8px；字体 11px/700 mono；**外描 2px dock 底色**（开孔效果，压在图标上不糊） | 语义分色：待确认消息=warning 底 `#e4c080`/字 `#3a2c10`；P1 待绑定=info 底 `--accent`/字 `--on-accent`；中性计数=neutral。上限规则：≥100 显示 `99+`（dock 档）；窗内列表计数用 `Intl.NumberFormat` 不截断（break-ui 规则） |
| 状态点 `.orbit-dot` | 7px 圆点，绝对定位右下 `2px,2px`，描 1.5px dock 底色圈 | data-state 映射：`ready→--ok`、`busy/waiting→--warning`、`error→--danger`、未知/睡眠待机→`--neutral`（睡眠是"安静"不是"故障"，用中性档） |
| 脉冲 | 待确认/协作未读/P1 待绑定允许 2.4s 微光脉冲（交动效部门）；reduce/`data-motion=off` 下一律停帧只留状态色 | 门禁对齐 |

### 3.5 窄屏与触屏形态

- `<720px`：dock 改通栏（`left:8px; right:8px; translateX(0)`，radius 20px，簇间距收 8px，轨道延伸线隐藏），图标总数超出时容器 `overflow-x:auto`、滚动条隐藏（`scrollbar-width:none`）。
- 触屏（`pointer:coarse`）：命中区已 ≥44px；点按即动作本体（甲组已裁定，无新增缺口）；提示卡经长按 450ms 呈现（非阻塞增强，见 4.4）。

## 四、图标 + 悬停揭示系统

### 4.1 图标风格决定：换 SVG 线条图标，字符体系降级为装饰

**决定**：orbit 的功能图标统一改用内联 SVG 线条图标（`viewBox 0 0 24 24`、`fill:none`、`stroke:currentColor`、**stroke-width 1.6**、round cap/join、单色、禁多色）；现有 `nav-symbol` 字符图标（◌ ⌕ ◇ ⚙ ↗）在 orbit 下不再用作功能图标，字符体系整体保留为装饰（ASCII 签名、眉标、dust 星点不动——装饰红线）。

理由：(1) 字符图标字形随平台字体漂移、笔画粗细不可控、无法与徽标精确对位；(2) `#exit-btn` 已是 svg stroke 1.8 的在案先例，本稿统一为 1.6（24 格下 40px 呈现更精细）；(3) SVG 可继承 `currentColor`，三态可见度只需改一个 color/opacity。B/C 直接使用的图标清单：对话=圆角气泡线框、发现=放大镜、思想=星轨三点、设置=齿轮、人格=菱形轮廓（沿用 ◇ 的形）、记忆观察器=层叠线、P1=对勾盾、QQ/DSH/Claude=各品牌单字母线框、清醒睡眠=月相、待确认=信封、退出=沿用 `#exit-btn` 现有 path。

### 4.2 悬停提示卡 `.orbit-tip`

| 参数 | 值 |
| --- | --- |
| 排版 | `--fs-tip` 12px/1.5、500、`--ink`；**≤12 字单行**（12 字 ≈144px + 内边距，天然单行）；口径 4 豁免长句（安全/费用边界）允许多行：max-width 320px |
| 盒 | 内边距 6px 10px；radius 8px；底 `--orbit-surface-float`；边 1px `--orbit-line-strong`；`--orbit-shadow-float`；max-width 240px；`overflow-wrap:anywhere; min-width:0`（break-ui：长句换行不截断） |
| 位置 | dock 图标 → 上方 8px 水平居中；页内图标 → 右下 8px；贴边时翻转，固定定位不随滚动跳动 |
| 时机 | 悬停 350ms 后出现、移出立即消失；**键盘 focus 立即出现（0ms）**；Esc 关闭最上层 |
| 呈现 | 180ms 淡入（reduce：125ms 仅淡入）；无位移（克制）；`pointer-events:none`；`role="tooltip"` 配 `aria-describedby` |

### 4.3 idle / 悬停 / active 三态可见度梯度（承接甲组 idle 档位交接；低档值经 R3 P1-5 修订）

| 档位 | opacity | 适用（按 02a 第八节清单延伸） |
| --- | --- | --- |
| 高（常驻全亮） | 1 | dock 一级四图标、待确认消息徽标（注意力设计，**不允许淡化**）、退出 |
| 中 | .8 | 人格、工具簇两图标、QQ/DSH/Claude/清醒睡眠、"同步记录"、"记忆概览" |
| 低（功能入口淡化档） | **.70**（原 .55 经 R3 P1-5 修订：.55 验算 ≈2.7:1 低于非文字组件 3:1 线，.70 ≈3.65:1 过线） | "回到最新消息"、来源行、"继续加载会话记录"、"从头读取本页记录"、页内条件出现的次要图标 |
| （装饰子档） | .55 | **仅限纯装饰元素**（无任何唯一入口语义，如纯装饰性残影）；功能图标一律不得用本档 |
| 随状态 | checked→active 色 | eval-auto（甲-16：`label:has(#eval-auto:checked)` 纯 CSS，checked 时色 `--accent` + 底 `--accent-soft`） |

三态换算统一 CSS：idle 档 opacity 作用于图标 color 层，hover/focus-within 一律恢复 opacity 1 + 色 `--ink`（全亮不变）。**正文文字不允许低于 `--muted`（AA 4.5:1）**；07 验收须对每个淡化元素逐个判类：装饰（可 .55）/功能入口（必须 ≥.70）。

### 4.4 触屏兜底（大纲第九节 7）

点按=动作本体不变（甲组已闭合）；提示呈现兜底=长按 450ms 弹出同一 `.orbit-tip`（1s 自动消退或移指即消）；`@media (pointer:coarse)` 下功能低档统一提升为 **.75**（R3 验算 ≈4.0:1 达标；触屏没有 hover 补救，idle 不得低至 .70）。**通用规则**（R3 P2-10，覆盖窗内图标如 M10 消息导航三钮，各稿不得再单写组件级 coarse 规则）：
`@media (pointer:coarse){ html[data-theme=orbit] [data-idle=low] { opacity:.75 } }`
验收含"没有因简洁变得不可发现"检查（大纲接点原文）。

## 五、三层容器体系（大纲第八节接点：统一卡片语言）

| 层 | 类名 | 底色 | 边框 | 圆角 | 阴影 | 附加 |
| --- | --- | --- | --- | --- | --- | --- |
| 一级页容器 | `.orbit-page` | `--orbit-surface-page #0d1624e6` | 1px `--line` | `--orbit-radius-m 10px` | `--orbit-shadow-page` + `inset 0 1px 0 #ffffff0a` | 透出背景微光；四周留出背景可见边（`#app` 内边距沿用，页容器 max-width 1080px 居中） |
| 中页召唤窗 | `.orbit-window`（原生 `<dialog>`） | `--orbit-surface-window #121d2ff2` | 1px `--orbit-line-strong` | 10px | `--orbit-shadow-window` | `::backdrop #05080fd9`（背景压暗是窗的专属信号）；窗头 sticky 高 `--orbit-win-head-h`；max-height `calc(100dvh - 48px)` |
| 小浮层 | `.orbit-float` / `.orbit-tip` / S1 确认框 | `--orbit-surface-float #182540` | 1px `--orbit-line-strong` | 卡 14px、提示条 8px | `--orbit-shadow-float` | 实色、最亮、影最锐；**宽 ≤320px、无内滚动**（例外见下）；内容超限说明它该是召唤窗 |

**互不混淆的区分规则**（审查员可据此机检）：
1. 亮度递增：`e6 透明 → f2 透明 → 实色`，叠放时上层永远比下层亮。
2. 变暗信号独占：只有召唤窗有 `::backdrop` 压暗；页容器与小浮层不产生全屏变暗。
3. 阴影锐度独占：浮层 shadow blur 20px 是全系统最锐；看到"小而锐"即浮层。
4. 尺寸纪律：浮层 ≤320px 宽、不允许滚动条；带滚动条的容器一律是 `.orbit-window`。**浮层滚动例外规则（05 轮次 5 裁定采纳，R3 P1-1 补登）**：内容为动态列表数据的浮层壳（S10/S11 窗口族及同类）允许内滚动并放宽宽度帽——须挂 `data-orbit-scroll` 作为机检钩子声明例外；本例外不连带放宽"无 backdrop"规则（例外浮层仍不产生全屏压暗）。
5. 堆叠纪律：浮层内不再开浮层（Esc 只关最上层，大纲第五节）；窗内展开走分步/抽屉。

## 七、可访问性

1. **焦点环**：全局沿用 `:focus-visible { outline:2px solid var(--accent); outline-offset:3px }`；dock 图标与图标格用 offset 2px（radius 10 内不裁切）；悬停卡出现时 `aria-describedby` 关联，焦点不移入（tooltip 不抢焦点）。
2. **对比度底线（对暗底 AA，数值按 R3 独立验算）**：常驻正文文字 ≥4.5:1（`--ink` ≈13.9:1、`--muted` ≈8.4:1、`--orbit-faint` ≈6.2:1，全部达标）；图标与边框等非文字 UI ≥3:1（功能低档 .70 → ≈3.65:1；装饰子档 .55 → ≈2.7:1 不过线、故限纯装饰；触屏兜底 .75 → ≈4.0:1）；徽标文字对自身底色 ≥4.5:1（warning 徽标字 `#3a2c10` on `#e4c080` ≈7:1）。状态不得单靠颜色传达：状态点必须伴随 `data-state` 供读屏与形状差异（dot/badge 两种形态）。
3. **减少动态 / `data-motion=off`**：一切入场降级 125ms 仅淡入或停帧（room 先例）；徽标脉冲停帧、状态色不变；dock 轨道延伸线与站点光点为静态（无漂移动画）；`document.hidden` 停 rAF（orbit-bg 侧，动效部门落）；`forced-colors` 下 dock/窗/浮层边框换 `CanvasText`、扫描线内衬与轨道线隐藏（沿用 minimal 先例写法）。
4. 触屏兜底见 4.4；skip-link「跳到输入框」沿用。

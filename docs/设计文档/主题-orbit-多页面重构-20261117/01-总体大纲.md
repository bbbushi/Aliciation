## 二、字数口径补充（已经主代理裁定，R1 确认按此执行、不重新争论）

任务书第二节口径之外的四条补充，全团队与机器抽验脚本同口径执行：

1. **"常驻可见"按同一时刻同屏计**：互斥状态（如空态/有消息、空闲/运行中、标签页 A/B、分步各步）不同时累计；字数预算约束的是任一时刻的可见文案总量，分步页每步须单独达标。
2. **折叠后默认不可见的正文与未到达的分步内容**，按悬停文字同一口径处理（不计常驻，展开/到达时刻受克制约束）；折叠态的 summary 按钮文字本身计入。
3. **select 展开后的选项列表**视为瞬态弹层，不计常驻；折叠时显示的选中值属动态数据，不计。
4. **安全与费用边界全文豁免**：DSH/Claude/P1 的授权边界、费用警示等不可省略的完整句，不受悬停文字"≤12 字为宜"约束——完整性优先于克制，审查员作为关注项核对是否"必要且不可再分"。

计数公式照任务书：汉字×1 + 其他字符×0.5，向上取整。装饰（ASCII、编号、眉标、光标）、图标、悬停文字、对话内容与动态数据不计。

## 五、页面层级与导航模型

- **一级大页面 4 个：对话 / 内容发现 / 思想与探索 / 设置**。选择理由：对应用户四类核心活动（和她说话、看她找来的内容、看她的内在活动、调配系统）；现状埋在设置里的思想与探索升为一级（她的内在生活是陪伴型产品的核心场景），人格降为召唤式中页（低频查看/替换，不该占常驻一级位）。
- **导航容器（"轨道 dock"，形态细节归样式部门）**：常驻一条全局 dock，含四组——①四个一级图标（对话/发现/思想/设置，全图标化+悬停名，常驻文字 0）；②人格图标（召 M1）；③工具簇（记忆观察器/P1 核查图标 + P1 待绑定徽标，数字徽标=汇总手段）；④系统簇（QQ/DSH/Claude/清醒睡眠连接状态徽标（动态）+ 待确认消息徽标（点击切至 P1 并聚焦提示行）、退出图标）。dock 在所有页面常驻，图标不计字数。**dock 挂 body 级（#app 之外），全部页面含 OB1/OB2 引导期常驻在场；OB2 的 welcome-tools「连接 QQ」「设置」两按钮删除，由 dock 系统簇承接（引导期 M5/P4 经 dock 可达）**（裁定①）。
- **页面切换**：一级之间=dock 图标切换（背景镜头/球位随页变化，转场归动效部门）；中页面=从 dock 图标或页内入口**召唤**（浮层窗，Esc/返回按钮/点背景关闭，焦点回召唤入口——minimal 原生 dialog 先例）；小页面=悬停卡/徽标/确认框，Esc 只关最上层。
- **子页面召唤与返回的统一约定**：任何召唤窗只允许一层堆叠主题（窗内再展开一律走分步或抽屉），避免"页上页上页"；返回路径唯一（返回到召唤它的页面）。**例外条款（裁定⑤）：设置族 M2–M7 之间允许窗内顶部步点直接切换分区（复用 data-settings 机制），不视为二层堆叠；Esc/返回仍一次回 P4。**
- **当前页指示**：dock 图标 active 态 + 大页面自身的页标题；不额外重复文字标识（P1 的 chat-subtitle 因此移除）。
- **防堆页红线**：一级不新增第 5 页；新增任何页面须先在本大纲补条目并过主代理裁定。

## 七、背景与页面关系（方案选择）

**选方案 A：新建 `web/orbit-bg.js`（改编自 room.js，全局层跨页面常驻），room.js 的 themeOK 收紧为 `=== "room"`。**

理由：

1. room.js 是三主题共享的稳定文件，桌面打包链有冻结主 UI 文件的先例，改造它做全局编排会把风险外溢到 room 用户与桌面包；新文件承载 orbit 专属行为，退场干净（切走主题=停 rAF+移除画布）。
2. orbit 需要**按页面/状态差异化的球位、镜头与躁动**——这是纯新增行为，塞进 room.js 的分支会比独立文件更难审查。
3. 现有 themeOK 是"非 legacy/minimal 即画"，orbit 若不处理会与全局层叠加双画；方案 A 只需把收紧条件一行改动，影响面明确。
4. 方案 B（room.js 全局化）在兼容 legacy 判定、桌面冻结、停画条件三处都要动手术，收益仅是少一个文件。

**chat-atmosphere 五层的归属**：orbit 主题下 CSS 隐藏 chat-atmosphere 层栈，由 orbit-bg.js 在 body 级提供常驻场景；其中 `atmosphere-thoughts` 思想星线由 app.js 3424 行驱动——orbit 下由 orbit-bg 接管绘制或保留该 svg 层，**待局部设计师与动效部门核对后定**（风险项，见第九节）。

### 样式部门需要的接点

- **气泡样式冻结**：消息气泡与句级揭示样式不得因本主题删改（任务书红线）；P1 只做容器与周边，不动 #msgs 内部样式契约。

### 动效部门需要的接点

- 一级切换转场与背景联动依赖方案 A：orbit-bg.js 挂全局层，页面切换时向其发状态（页名/模式），镜头与球位差异按此驱动。
- 中页召唤/返回转场沿用原生 dialog 语义（焦点恢复、Esc 层级），动效不得改变焦点与关闭行为。
- 悬停揭示、徽标脉冲（待确认/协作未读/P1 待绑定）、状态色反馈是三个高价值动效面。
- 动效门禁（硬性）：data-motion=off / prefers-reduced-motion → 125ms 仅淡入或停帧；document.hidden 停 rAF；每模块单 rAF；room.js themeOK 收紧与 orbit-bg 停画条件同步登记。
- **红线**：revealStates/revealSync 句级揭示的 DOM 顺序与节奏不得被页面转场重排；转场只做容器级，不得包裹/搬移 #msgs 子节点。

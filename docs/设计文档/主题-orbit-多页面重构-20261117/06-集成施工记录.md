## 八·补4、页间过渡卡顿修复（2026-11-19 用户报「页面与页面之间的过渡动画并不流畅」）

1. **根因一：两页同时在流里被对半分宽（主因）**。`#app` 是 `flex-row`（style.css:43），`#orbit-main` 与 `.orbit-page` 又都是 `width: min(1080px, 100%)`；旧页退场 125ms 期间两页**都在文档流**，flex 各分一半——实测一次 对话→设置：旧页 772→363px 并右移、新页挤在右侧 389px 起，135ms 后旧页隐藏再整体弹回 772。一次切页 = 一次全页重排 + 两次横向跳，观感就是「不流畅」。
2. **根因二：P4 球面引擎的 rAF 常驻**。`start()` 在 install 时就跑，离开设置页仍在 60fps 写 `--spin/--tilt`，切页同帧里多一份样式重算。
3. **修法一：退场页脱离文档流再淡出**。`writePage` 改为「先量后动」——非目标且在场的页先取 `getBoundingClientRect()`，再冻结成 `position:fixed` + 显式 `left/top/width/height`（`max-height:none; margin:0`，挂 `data-orbit-frozen`）的叠层，加 `is-leaving` 淡出，150ms 后 `unfreezePage` + 隐藏。冻结值就是切换前那一帧的 rect，视觉零位移；新页从第一帧起就独占全宽，没有挤压与回弹。
4. **快速往返**：目标页分支先 `unfreezePage`（撤销冻结与 `is-leaving`），退场计时器按 `pageToken` 作废——连点不会把刚回来的页藏掉，也不会留下钉死的半宽页。
5. **退场帧改纯 opacity**：删掉 `orbit-page-out` 里的 `translateY(6px) scale(.985)`。两页像素对齐叠放后，缩放会把整块面板往中间吸，叠影期看着像抖一下。
6. **入场的「实」提前**：`orbit-page-in` 改三段关键帧——opacity 在 45%（≈108ms，即旧页淡出结束前）就到位，transform 仍走满 240ms 上浮。叠影窗口只留在前 100ms，之后是「旧页化开、新页已实、只剩一点上浮收尾」。
7. **修法二：`pageHooks` 页级钩子**。`writePage` 末尾按最终页名回调；P4 引擎改成 install 时 `prepare()`（算好球面版式与 `--core-size/--radius`，但不跑 rAF）、进入设置页才 `start()`、离开 `stop()`。窄窗断点变化时按当前页决定 start/prepare。
8. **验证**：四页互切 + hub 跳转 + 关闭回设置全链路 18 次切换——每次只有一页在场、无 `data-orbit-frozen` 残留、控制台 0 报错；rAF 帧间隔 410 帧 p50 16.7 / p90 17.4 / p99 17.7ms，仅 1 帧 33.4ms（首次进 P2 内容渲染），无 >50ms longtask；离开设置页 400ms 后 `--spin` 冻结在 5.40deg 不动，回到设置页 2.99→5.40deg（约 6°/s）继续自转；`data-motion=off` 瞬时切、不留内联冻结样式。
9. **注意**：3D 版（`min-width: 900px`）在 800×655 审查面板内不生效，量测 3D 版时曾把断点临时改成 0px，量完已复原（两处 900 未变）。真机手感与 60fps 观感仍须真人看（`04a §1.4`「切走即隐」自 05 轮次 12 起已按用户裁定改为有退场帧，本轮只改退场形态）。

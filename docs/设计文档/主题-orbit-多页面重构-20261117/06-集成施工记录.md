## 五、真机验证发现并修复的问题（8800 实测，Chrome/IAB）

1. **静态路由 404**：三个新文件 404 → server.py 加分支（见上表裁定）。
2. **安装中途崩溃半残**：`moveNode` 对 parentElement 为 null 的新建节点（orbit-strategy-drawer/orbit-thought-ops）抛错，install 断在 dock 之后——app-nav 隐藏、三页壳全未建。修复：moveNode 支持新节点（insert + `node.remove()` undo）；applyTheme 装 try/catch 留 `__orbitInstallError` 诊断面。
3. **P2/P3 空白**：app.js 对面板是**类+属性双通道隐藏**，只摘属性不摘 `.hidden` 类 → 新增 `unhideClass`（还原回原类串）。
4. **M2「保存」按钮改名被回写**：app.js 状态渲染会重写按钮文案 → `maintain()` 维持式 observer（改回即纠正）。
5. **S7 协作者头像卡错位**：worker-tasks.js 用内联 `inset` 存拖拽位，room 遗留坐标压到页缘 → orbit 首装 `subStyle` 重置到会话区右下（还原表登记；拖拽不受影响）。注：DSH 未连接时该卡由 worker-tasks.js 自行隐藏（visibility:hidden），非缺陷。
6. **切回 room 半拆**（回归测试抓到）：结构 undo 缺失（dock/main/p2/p3/p4 从未登记移除）+ 面板重绘后 `marker.replaceWith` 抛错中断循环 → ①五个壳补登记 removal undo（LIFO 顺序自洽：先归位搬移节点再摘空壳）；②undo 单项 try/catch 不中断拆除，失败记 `__orbitUndoErrors`；③moveNode 的 marker 失联时弃置旧节点（重绘已产生新节点，塞回会重复）。
7. **canvas 不随主题收起**：kick 在 rAF 挂起时早退 → tick 补「主题非 orbit 即收起画布」。注：自动化面板 rAF 节流（`frameFired:false` 实证），此路径在真实浏览器为下一帧内完成；动效类观感转真人验收。
8. install() 开头清理历史残留壳（防叠加），失败分支强制走 uninstall。

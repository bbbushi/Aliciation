# 退出时 Python 意外退出（2026-11-15）

用户实际点击退出后，macOS 弹出 Python 意外退出。桌面后端日志记录 `_enter_buffered_busy: could not acquire lock for <_io.BufferedReader name='<stdin>'> at interpreter shutdown, possibly due to daemon threads`；系统报告 `Python-2026-11-15-160525.ips` 指向后端 PID 17992，以 SIGABRT 结束。此前 PID 16734 也有同类记录。

根因是桌面控制线程仍阻塞在 `sys.stdin.buffer.readline()`，服务收尾返回后，Python 解释器终结阶段无法取得标准输入缓冲锁，主动中止。此前宿主只等待进程结束，没有检查是否正常退出，因此窗口关闭后系统仍弹出崩溃提示。

修复：

- 控制管道使用单独复制的无缓冲输入句柄，避免后台线程占用标准输入的 BufferedReader 锁。
- 后端发出 `closed` 前设置停止标记；宿主收到该帧立即释放写入端，让读取线程解除阻塞。读取线程负责关闭自己的输入句柄，主线程终结前等待线程结束。
- 对失联宿主的线程等待有上限；兼容旧宿主时，无缓冲读取也不会触发上述缓冲锁崩溃。
- 宿主继续等待实际进程结束，并检查退出状态；异常退出保留提示，不直接按成功收尾关闭窗口。记忆整理失败的警告流程保留。

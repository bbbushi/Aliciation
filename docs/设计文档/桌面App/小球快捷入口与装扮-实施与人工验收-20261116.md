# 小球快捷入口与装扮：0.1.8 实施与人工验收

2026-11-16。用户希望点击小球后出现更多入口，包括设置、退出、装扮。已实现聊天/设置/装扮/退出四图标，真实环境人工验收待执行。

## 入口与交互

| 图标 | 目标 | 确认与返回 |
| --- | --- | --- |
| 聊天 | 已有透明聊天框与输入框 | 保留逐句显示、拖动、固定与草稿 |
| 设置 | Alice 主窗口的完整设置页 | 通过固定 UI 导航打开，已有模型/人格/气泡设置保持原权限 |
| 装扮 | 独立的小球装扮窗口 | 图案/配色先在窗口预览，保存后生效；取消/Esc/关闭不保存 |
| 退出 | 独立退出确认窗口 | 继续使用/Esc/关闭取消；确认后沿用宿主保存退出 |

四个图标同一时刻立即出现，不增加飞入、旋转或逐个等待动画。快捷条没有整块实底，窗口只有 200 × 44 逻辑像素的紧凑范围，包含四个 44px 按钮与 8px 间距；不扩大成覆盖屏幕的透明层。它仍是主动操作窗口，按钮之间的窄间距也属于窗口范围，不宣称穿透；被动消息预览继续原生整窗穿透。

快捷条根据小球所在屏幕工作区向左或右展开，并调整图标顺序，让聊天离小球最近、退出最远。再次点小球可收起；鼠标移入时保持，离开后闲置约 12 秒收回。悬停期间超过时限仍按实际展开状态处理下一次点击，不出现“看着展开却要点两次才收起”的状态差异。

打开装扮或退出确认后收起快捷条和聊天；关闭这些辅助窗不会退出 Alice，也不误认为关了浮动聊天。主窗聚焦、维护、安装和退出仍统一抑制桌面浮窗。

## 装扮与偏好

装扮提供四种内置图案（A 字母、圆点小球、月亮、小花）与四种配色（苔绿、雾蓝、蔷薇、琥珀）。当前仅改变桌面小球，不改变人格、模型指令、聊天主题或其他应用。使用系统字体与代码图形，不增加图片生成、下载、导入、字体资源或运行时依赖。

图案/颜色选择在装扮窗里预览，保存调用固定 `appearance_save`，只接受枚举值；成功后一起写回现有 `bubble.json`。新增 `avatar` / `accent` 是 UI 偏好，沿用原子替换、0700/0600 与符号链接保护。旧偏好无这两个字段时保持原 A 图案和苔绿，未知字段值回退默认；不迁移 Alice 记忆或重置位置、启用状态与实色开关。关闭未保存窗口不会落盘。

## 设置与退出的权限

设置图标打开完整设置而非仅气泡偏好。宿主仅向固定主页面发出固定导航请求，主页面通过已有 `AliceUI.openSettings()` 打开；若页面尚未载入，进程内 `main_settings_pending` 等待页面就绪后消费并回执，避免导航丢失。快捷条没有取得模型密钥、写设置内容或任意脚本/URL 权限；实际配置仍由原来的 GUI 流程负责。

退出图标以及托盘菜单“退出 Alice”先打开本地 `bubble-quit` 窗口。只有该窗口、固定本地 URL 和 `confirmed:true` 可以调用 `quit_confirm`；快捷条本身不能直接确认退出。确认后调用原 `Backend::quit`，继续等待排空和进程真实结束，不强杀 Python。不允许通过此入口打断维护/更新；若退出尚未开始，错误留在确认窗，恢复取消与重试按钮。原主界面退出图标及 Cmd+Q 的现有行为保留。

新 `bubble-appearance` 与 `bubble-quit` 只有气泡命令能力，命令内部再按标签/URL/动作逐项检查；装扮窗没有退出或模型/更新/恢复写权限，退出窗没有装扮写权限。窗口可正常关闭，主窗/聊天/预览/快捷条沿用各自原来的关闭规则。没有新增 HTTP 写入口或模型工具，能力 JSON 注册表与宪法不变，资料格式/维护协议 v1、公钥不变。

## 代码交付

1. `runtime_paths.py` 分离不可变资源与用户根；新增全局 `--user-dir`，CLI 在导入配置/人格/服务前选择路径。`--config` 保持单独配置语义；冻结模式必须指定用户根。已审计人格、归档、重置、观测和渠道默认路径均从统一 config 派生；缓存路径常量通过提前选择解决，不做运行中补丁。浏览器 profile 改为用户根派生，独立浏览器诊断 CLI 也支持 `--user-dir`，不再因配置文件放在别处而把浏览器数据写到那里；QQ 安装器检查源码旧版 bridge 锁的兼容保护保留，只读存在性检查，不向原 user 写入。
2. `instance_lock.py` 使用 POSIX flock / Windows msvcrt 锁，锁文件保留而不删除，持有到服务/CLI 数据生命周期结束；相同规范化目录互斥且同进程也拒绝重复实例。锁在默认重置恢复和 Store 构造之前获得。Store 安装失败关闭连接，维护线程最终退出后才释放存储和实例锁。旧服务不认识新锁，不能靠新锁保证与旧版本共存。
3. `runtime_process.py` 提供固定后台/组件执行入口；源码仍用解释器，冻结模式使用固定后端子命令或独立组件可执行文件。`discovery-worker` 分派在配置和 Store 导入之前执行，保留原 JSON 行/GO 协议，不读取用户数据。QQ/浏览器未适配冻结包时明确不可用，Claude/DSH 的组件可用性参与现有投影和工具会话筛选，用户授权不改写。
4. `desktop_host.py` 建立私有继承管道：stdout 为有界 JSON 行，日志 stderr；校验版本/实例/nonce/request_id、重复字段与请求幂等。本批支持 status 和正常 quit，声明 `updates=false`。EOF 请求无新增模型提取的正常退出；宿主不通过伪造浏览器头调用 GUI 关服接口。
5. 服务支持桌面无配置先进入设置；待真实配置保存后使用实际模型客户端。原有源码 serve/CLI 模型配置要求保持原逻辑，网页来源校验未放宽。此设置体验尚未真人验收。
6. `addons/desktop/` 提供 Tauri 2 源码窗口、随包启动页、重复点击唤醒、后端实际随机端口导航和退出协调；主聊天页没有 Tauri 原生命令权限。原型限制精确回环 origin，拒绝新窗口；当前外链未接系统浏览器，需后续适配。错误/收尾进度显示在窗口标题与启动页，用户可查看本机日志。
7. 新增独立开发启动器和 P2 资源准备 manifest（含宪法/注册表/网页/实现摘要源码材料），未生成冻结后端或安装包。Rust 工具临时装在 `/private/tmp/alice-desktop-toolchain/`，从官方下载安装器并校验 SHA256，不改系统 PATH。

本批没有新增模型可调用的业务工具，也未授予模型/网页安装、更新、读取文件系统或控制进程的入口；能力 JSON 与宪法无需增加桌面操作目录。实际可用组件仍经既有授权和动态状态筛选，自模型“运行于计算机、经开放能力活动”的事实不变。新增运维 CLI 和宿主协议已登记工作区公共面。

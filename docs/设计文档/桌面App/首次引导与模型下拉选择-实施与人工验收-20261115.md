# 首次引导与模型下拉选择

2026-11-15，按用户要求施工。首次使用顺序改为：选择供应商并填写 API Key → 获取模型目录 → 下拉选择对话/记忆整理模型 → 验证并保存 → 导入人格原稿、理解和预览 → 安装并开始。没有人格文档时仍可切换气质标签；默认进入文档导入及原文六层理解方式。

## 实施

- 未配置模型时直接展示第 1 步，不能从该页跳过配置进入人格导入。保存成功后由服务的 model_ready 投影推进；刷新可从已有配置和人格推导进度，不依赖浏览器存储标记。已有会话不会被引导重置，已有自定义配置继续运行；当前 GUI 仅允许选择 DeepSeek、智谱 GLM、OpenAI GPT 官方 API。CLI/文件配置的兼容接口能力未删除。
- 模型设置与引导复用同一份表单，官方地址只读，模型名称改为 select；记忆整理默认可选“与对话模型相同”。不再预填可能过时的模型名，不用硬编码模型目录，也不自动把所有返回模型当作完整兼容模型。
- 新增 `ChatService.list_model_config_models(payload)` 与 GUI 专用 POST `/api/model-config/models`，沿用 `model-config` 来源、意图、JSON 与配置版本校验。它只在明确点击时执行目录 GET，不发起推理、不保存密钥、不读写对话。
- 列表取得后返回内存 catalog_id，最多保留 16 份、有效期 10 分钟，绑定供应商、密钥摘要、模型 ID 集合和配置版本。测试/保存必须携带该凭据，两个模型必须来自刚取得的列表；更换供应商/密钥会使前端列表失效。保存后旧列表也不能跨版本复用。
- 供应商切换会清空待输入的密钥，仅同一供应商允许保留既有密钥。后端也拒绝把旧供应商密钥发给新供应商。目录请求地址固定、拒绝重定向，读取上限 1 MiB、超时 20 秒；只返回清洗过的候选 ID 与固定分类错误，不回显凭据或供应商异常正文。列表空、认证失败、格式不兼容和超时均保留在配置阶段。
- GPT 验证使用 max_completion_tokens；官方 OpenAI 请求不携带 GLM/DeepSeek 的 thinking 扩展，也不强传部分 GPT 型号不接受的 temperature。流式/非流式与独立探索工作进程保持对应适配，观测最终参数同步。验证只是既有最小非流式验证，不证明流式、工具或长期行为已经通过。

## 目录来源与证据边界

- DeepSeek：固定 `https://api.deepseek.com/models`，[官方列表文档](https://api-docs.deepseek.com/api/list-models/)。
- OpenAI：固定 `https://api.openai.com/v1/models`，[官方列表文档](https://developers.openai.com/api/reference/resources/models/methods/list)。界面筛选 GPT 文本候选，排除明显的音频/图片/嵌入/实时等模型；候选列表不构成工具或流式能力证明。
- 智谱：对话地址仍为官方 `https://open.bigmodel.cn/api/paas/v4/`，目录使用同一官方域名的 `/api/v1/models`，适配 data[].id、models[].slug 及对应包装结构。本轮仅对这一官方地址做了不带密钥的只读资料核对，实际返回 code=1001、success=false、提示缺少 Authorization，证明它要求鉴权；未拿用户密钥查询，不据此宣称已经取得真实模型目录。模型类别参考[官方模型概览](https://docs.bigmodel.cn/cn/guide/start/model-overview.md)。目录真实权限、包装格式和候选可调用性待人工验证，失败时明确报错，不改用第三方聚合站或伪造列表。

## 2026-11-21 七步气泡向导

首次引导统一为 Alice 气泡，页首显示步骤点和当前位置，气泡下方显示原创像素女孩头像。窄窗可滚动，供应商卡片改为纵排。

1. 从 DeepSeek、智谱 GLM、OpenAI GPT 选择供应商。
2. 填入对应的 API Key，点击「获取模型列表」。已有该供应商密钥时可保留。
3. 从实际返回的目录下拉选择对话与整理模型，验证并保存。返回修改供应商或密钥后需要重新取列表。已配置模型的用户可直接使用保存的配置。
4. 导入或恢复人格文档，沿用原有准备、预览、确认和安装流程。没有文档也可选气质标签。
5. 告诉 Alice 怎么称呼你。
6. 分享平时的兴趣。
7. 留一个想先聊的话题。

后三个问题可以逐题跳过，也可以随时直接开始聊天。返回上一步会保留当前页面的输入，结束引导时一次保存已填回答。

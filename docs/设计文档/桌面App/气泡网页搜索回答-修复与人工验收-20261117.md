# 气泡网页搜索回答：0.1.12 修复与人工验收

2026-11-17。用户反馈网页搜索的信息无法在气泡中显示。源码确认：`desktop-chat.js` 的 `display()` 将所有 `source_bound` 回复替换为“请在主界面查看”，`mergeTurn()` 又丢弃正文。网页搜索产生的资料关联回答也被屏蔽；与搜索是否成功、API 配置无关。此前气泡还忽略了 SSE `search` 事件。

## 修复

气泡读取现有 `/api/history` 的 GUI 投影正文。普通 GUI/local 回答按原逻辑；网页资料关联回答只有 `source_available === true` 且 `source_expires_at` 未到期才可显示。服务端仍决定资料可见性，不访问原始资料包、不绕过来源范围、不新增权限。协作资料仍留主界面，QQ/主动消息/worker report 仍不纳入气泡，带资料正文仍不进入被动桌面预览。

移除“只要 source_bound 就立即整段显示”的条件，可用回答继续原逐句队列/动效/跟随。首次历史与主窗已读内容保持原规则，`done` 不额外倒出全文。全部正文和搜索消息使用 `textContent`，不执行网页 HTML。引用在回答正文中的文字照常显示，完整来源卡、管理及协作交互继续由主界面承担。

每次历史请求携带已缓存来源轮次 `source_turn_ids`（最多 100 个），合并服务端 `source_updates`，无新轮次也刷新资料有效性。到期计时器和宿主状态回调清理失效正文，立即用状态占位覆盖句子缓冲与 DOM；刷新失败暂时清空正文并标记待同步，不把缓存当永久可读副本。后续服务端重新允许展示时重新取得投影，不从本地恢复已清除的正文。会话重置清理计时器与缓存。

SSE `search` 事件显示准备搜索、搜索网页、读取正文与结束整理状态，不改变工具调用或增加模型请求。没有新的模型能力，能力注册表/宪法不变。

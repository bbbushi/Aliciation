# 桌面透明气泡聊天：实施与人工验收

2026-11-16，用户审阅三窗设计后指令“施工”。版本 0.1.6，macOS Apple Silicon 首版；实现完成，真实环境人工验收尚未进行。

## 已实现

- 设置 → 外观 → 设置桌面气泡；另有应用菜单“桌面”和常驻菜单栏入口。默认关闭，保存启用时明确说明主窗关闭后仍在后台运行；关闭功能恢复原先退出规则。
- `bubble-anchor`：44 逻辑像素小入口，非自动聚焦，支持首次点击、拖动、近左右边缘吸附和位置保存；右键进入设置。初次定位避开工作区底部，屏幕变化后把位置夹回可见工作区。
- `bubble-preview`：无装饰透明窗口、不可聚焦、原生整窗鼠标穿透，最多三行节选，约 10 秒收回。默认底色约 88%，文字不降低透明度；可关闭正文只保留未读标记，也可切换实色。
- `bubble-chat`：约 340 × 420 逻辑像素，主动点击后聚焦。近期对话、文字发送与流式回复、输入法组词保护、Enter 发送/Shift+Enter 换行、Esc 收起、固定展开、打开主界面。滚动回看不强制拉到最新；草稿只存在当前页面内存。
- 用户反馈展开框不能拖动后补齐：顶部 ALICE/状态区域作为明确的原生拖动区，按钮排除，正文与输入框不参与拖动；使用操作系统窗口移动而非网页模拟位移。聊天框位置与入口分开保存，移动期间暂停自动定位，释放后保留新位置，防止半秒布局将其拉回入口旁；找回位置同时重置两者，副屏断开按聊天框所在工作区夹回。
- 用户随后要求展开框背景透明：默认移除整块容器底色和边框，消息之间直接透出桌面；消息、输入与操作区保留独立淡底色保证可读。既有 `solid` 开关改为“使用实色背景”，可恢复整块实色面板；首次默认关闭，已启用实色的本机偏好继续尊重。透明只改变外观，主动聊天窗口仍在自身矩形内接收鼠标；整窗穿透仅用于被动预览。该外观修订同为 0.1.6 验收前重打包，旧交付包保留。
- 与现有 GUI 共用永久会话、HTTP/SSE、人格、记忆与请求身份，未另开模型实例。精简传输适配独立在 `web/desktop-chat.js`；本轮未抽取或覆盖另一棒正在修改的 `web/app.js`。
- 被动预览只接入 GUI/本机普通回复，排除 QQ、主动投递、协作状态与带来源的正文；资料引用在面板显示主界面查看提示，不保存失效来源副本。新客户端首次同步作为基线，不将旧历史全部弹出。
- 隐藏输入面板不销毁 WebView 或发送连接。气泡发送中转到其他软件，仍沿用原请求；主窗后续经公开历史投影获取记录。结果未知先只读核对，不自动重新发送；仅核对后确认新请求才再调用模型。
- 主窗口及气泡聊天窗口显式禁用 WebView 默认隐藏暂停（当前 macOS 15+ 支持），避免长时间后台后执行停止；展开约 1.5 秒、后台入口约 4 秒、主窗前台约 15 秒同步一次公开投影，隐藏时无装饰动画。长时间隐藏后的实际活性仍须真人确认。
- 后台检测约 800ms 防抖，显式菜单/点击唤出绕过被动防抖。打开 Alice 自己的更新/恢复/气泡设置窗口时不把它误作切换到其他软件。退出、后端错误及维护排空与气泡共存，错误可召回主窗。
- 现有退出图标和 Cmd+Q 保留；菜单栏“退出 Alice”走宿主正常保存退出，不强杀进程。气泡面板关窗只收起。维护/安装标记生效时统一收起气泡，原有升级前备份和恢复流程不变。

## 边界与权限

新增公开 GUI 方法 `ChatService.gui_request_status(payload)`，HTTP POST `/api/chat/request/status`，要求现有 GUI Origin/JSON/意图校验。正文固定为 `text/request_id/session_epoch`，规范化为原 GUI 请求身份后检查会话、渠道与负载哈希，只读返回状态/轮次 ID/错误元数据；非阻塞取得服务锁，忙时报告状态不确定。它不接单、不调用模型、不通过原发送入口“试探”、不读取/返回正文、不补写旧回复哈希。跨会话或内容冲突拒绝，未找到只是未找到，须用户核对后决定是否新发。

宿主新增 `bubble_action`，按固定窗口标签与实际 URL 分配固定动作；不接受任意 URL、路径、命令或文件。Tauri 自定义命令改为显式 AppManifest：更新、维护和本地气泡各有窗口范围；后端 ready 后只动态允许本次实际回环端口上的 `main`/`bubble-chat` 调用气泡命令，并在命令内部继续检查页面路径。主页面只有读取气泡状态和打开设置的权限，没有更新、维护和配置写入权限。恢复重建后端时旧气泡聊天页随端口更换而销毁并重建，不复用旧实例授权。

偏好只存宿主配置目录 `bubble.json` 的开关、正文预览/实色与物理位置；原子替换，Unix 0700 目录/0600 文件，拒绝符号链接，大小受限；异常偏好默认不启用并在设置显示错误。未把密钥、消息正文、草稿或不确定请求写入此文件。固定展开只在当前进程有效。

本功能增加用户操作界面及 GUI 只读投影，不增加模型工具或模型可调用的桌面主动投递能力，因此 `alice/capabilities/commands.json` 与 `alice/constitution.json` 不变。核心仍只用标准库，网页仍为原生 HTML/CSS/JS；Tauri 启用已锁定/已有目录源的 `tray-icon` 特性，未增加 Python/网页运行时依赖。

首批未接全局快捷键、跨虚拟桌面跟随、全屏覆盖、语音或附件。锁屏由系统窗口层级遮蔽，未额外订阅锁屏或屏幕共享状态，不宣称已经实现自动屏幕共享保密；演示前使用菜单栏暂停或关闭正文。普通应用切换与真正系统隐藏/全屏的实际焦点行为仍须真人确认。面板精简视图不提供工具审批、P1、人格或模型设置，相关操作打开主界面。

## 展开框拖动修复交付

用户反馈“聊天框不能拖动”。静态定位有两个原因：`drag` 原先只允许入口窗口，展开框没有拖动区域；布局每半秒按入口重定位聊天框，直接补拖动仍会被拉回。已给顶部 ALICE/状态区接入原生鼠标拖窗，排除按钮；正文选择、滚动与输入框不作为拖动入口。

聊天框首次手动拖动后，用 `chat_position` 与入口坐标分开记录；原生 Moved 事件同步坐标，持续移动时暂不自动调整位置，停止后按相应屏幕工作区夹回并延迟保存；短暂移动失焦不触发自动收起。偏好向后兼容，找回位置重置两窗。未增加网页全局拖窗权限、任意坐标参数、模型工具或数据迁移。

# 需求文档：GUI 功能三件

> 需求方：项目所有者；整理：ZCode（2026-10-28）；实现：功能侧开发者
> 三项需求均源自当日真实使用问题。现状代码在 `alice/server.py`（纯标准库 HTTP+SSE）、`web/`（原生 JS）、`alice/service.py`、`alice/config.py`，改动面自行评估。

## 需求一：退出进程的 GUI 出口

现在服务只能在终端 Ctrl+C 关闭，关掉浏览器后进程会残留（机器上曾积 6 个）。

- GUI 提供关闭服务的出口，有确认步骤，防误点；
- 退出是**优雅退出**：对话与记忆先落盘，再结束进程；她正在回复时不硬掐，让当前轮完整结束；
- 退出后页面要明确告知「数据都在本机，如何在终端重新启动」。

验收：点退出后进程无残留、数据完好可重启。

## 需求二：移除检测仪

监测仪（token 曲线 + 人格偏移/诚实度/人机感评审卡）已被判定无参考价值，整体去除。

- GUI 中监测面板及其一切入口消失；
- 评审类 LLM 调用随之不再发生（这是省钱项，不是可选）；
- 后端代码与历史数据怎么处理由实现侧定，不强制；
- 思考深度（on/off）是用户设置不是检测仪，保留。

验收：界面无痕；对话路径无评审调用；思考深度不受影响。

## 需求三：GUI 直接修改 API / 供应商配置

换 API key 目前要手改 config.toml，且改完不重启不生效——今天用户踩坑实录，对本产品用户不可接受。

- GUI 可修改：供应商（带常用预设：智谱 / DeepSeek / 自定义 OpenAI 兼容）、base_url、对话模型、廉价模型、API key；
- 保存前可**测试连接**，失败原因要人能看懂（如「令牌无效」，而不是笼统报错）；
- **保存后立即生效，不要求重启进程**——这是硬性要求；
- key 安全：界面回显脱敏、不进任何日志、config.toml 维持不入 git；
- 保存配置不得破坏 config.toml 里的其他内容。

验收：GUI 换上有效 key 后不重启即能对话；填错 key 有明确报错且不影响旧配置。

## 全局约束（必须遵守）

1. `alice/` 只用标准库（openai 惰性导入除外），`web/` 原生 JS 无构建链，不得新增依赖；
2. 服务只监听回环地址；
3. `config.toml` 不入 git，`data/` 是她的记忆、只走现有 service 加锁路径；
4. 提交只暂存自己碰的路径，不用 `git add -A`。

开机自启/守护进程、多 profile 配置切换、检测仪数据迁移。


1.思想层
来源dsh-bili-humanism：
影子人格的七字段候选（prompts/personality-shadow.md，实验性默认关）
跨会话积累的候选必须同时给出：具体观察 / 可能意义 / 同样说得通的另一解释 / agent 错过之处 / 特定处境下如何回应 / 适用条件 / 不应套用的反例 / 仍不知道什么。配反标签纪律："不要把『这次他想被陪伴』变成『这个用户是依赖型人格』"、不推断诊断、不贴稳定标签；纯工程教训（加引号、防注入）禁止包装成人格认识。
2.思想层/上下文组装
来源Nascence 辉夜：
行为思考：念头与发言分离（behavior.py）
每轮最后一跳交给插件配置的 LLM，输出严格 JSON {"say": true/false, "text": "..."}——say=false 表示想了但不说。提示词是刻意的"最小提示词"：只有名字 + 记忆 + 时间/身体状态行，且禁止动作/神态/括号补充，回复压到 20 字内。窗口只有 4~6 条，她自己每轮产出的想法（[几小时前] 我说：… / [刚刚] 我想：…）——说了的和没说的都进。别人的消息走"软件上下文"另一条路。内心独白是一个一等公民的数据结构。
3.思想层
来源Nascence 辉夜：
反刍抑制（cognition.py:216）
同一关键词连续出现、同一种子节点/边反复被激活 → 抑制 N 轮（种子/边/关键词三档），到期自动解除。修的 bug 很诚实："关键词被抑制后检索必然为空、那一轮直接跳过，信箱又把这些词原样回灌，认知循环就卡在空转里。"——常驻循环不被同一块记忆嚼死的机制，同类项目里没见过。即同一批记忆连续多轮思辨后降权。
4.思想层
观点认识论结构化
每个观点字段字段：encounter（遇见了谁的什么处境）、facts / user_view / inference 三分（材料事实/用户解释/AI 推测）、previous_judgment / revision（什么旧判断因什么新依据修正——修订史）、missing（没看见的与不确定）、next_response（这会怎样改变下次回应）、evidence（带秒数的依据）。当面对足以形成观点的事件或观点引入，AI不一定需要等实践验证，可以先进行自己的思考，或者通过上网搜索或询问用户等其他途径得出结论。

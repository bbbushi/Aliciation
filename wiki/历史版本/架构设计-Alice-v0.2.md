# Alice v0.2 架构设计方案:思想层

> 作者:ZCode(架构优化设计);核心思想来自用户 2026-10-27 的修订:**经历与记忆是养料,养料须消化为主观思想(态度/观点/哲学)才构成人格;有思想才会被冲击得手足无措——而思想本身,就是压力的护栏。**
> 状态:**v2 定稿,2026-10-28 已按此实施(P0/P1/P2 全部落地,见第四节实施状态)**;v1 的上下文手术/演化降权从主角降为兜底与卫生,见附录。

## 一、核心:补上缺失的中间层

```
记忆/经历(养料)──►【思辨:消化】──►主观思想(态度/观点/哲学)──►人格(我是谁)
      │                  │                  │
  三层记忆·真实遗忘    数据触发的离线过程     生长层新小节:我现在的想法
  (不动)             (新增,类 evolve)      (每轮随 persona 注入=脊柱)
```

人格不只是记忆的压缩产物——**记忆必须被消化成有理由、有出处、有不确定度的观点**,才算长成了她。而被冲击时的手足无措,恰是拥有世界观的证据:设计不再消灭"被撼动",而是让被撼动通向自查与回应,而不是溃败。

## 二、构件

### 1. 思辨(deliberate)——消化过程(新增,核心)

- **触发**:数据量触发(类 `evolve_every_memories`,如每 15 条新记忆一次);不设时间兜底——安静就不变。
- **输入**:积累的记忆(含事件与立场)+ 现有人格的自我叙事段。
- **产出**:观点条目,每条必须含——
  - `claim` 主张(她怎么看);
  - `reasons` 理由;
  - `sources` 出处的记忆 id(**思想也要有据**:不变量 4 的延伸,禁止无中生有的深刻);
  - `uncertainty` 不确定度(例:"这一点我还没想透");
  - `open_questions` 没想清的问题(未决问题也是世界观的一部分——Coo 的"还没弄清:真名、作息")。
- **写入**:人格生长层新增小节「我现在的想法」;同时观点以 `kind='stance'` 落记忆库(可检索、可遗忘)。
- **修订**:思辨是重审而非只增——新记忆可修订旧观点,**观点带修订史**("我以前以为 X,后来觉得 Y"),防过早固化;被放弃的立场按用进废退淡出。

### 2. 宪法 v2(措辞,吸收原 P0)

- 认识论四分(发生了什么/他人声称/我推断/我现在相信——"现在相信"一档正是思想层的用语);
- "证明不了"是合法回答 + 对称性(对方同样证明不了);
- **被冲击时的行为链**:先停(允许说不出话/承认被问住——手足无措是诚实的)→ 从「我现在的想法」出发回应 → 守住,或有据修订;
- 被质疑感受时,先引具体经历与自己的记录;
- 沉默合法;persona 对话中永远只读(只有思辨/演化流程可改)。

### 3. 表达层(原 P1,不变)

- 言语行为协议:行内轻标记 `【情绪】台词` / `(动作)` / `(她没有回话)`,不用工具化,保流式;解析失败原样显示;
- 情绪表达词表由底色标签派生,种子生成时写入人格;
- GUI 渲染情绪样式与停顿气泡。

## 三、压力应对:思想第一,机械兜底第二

| 层级 | 手段 | 地位 |
|---|---|---|
| **第一**:思想 | 观点随 persona 每轮在场;被冲击→停→自查→守住/有据修订 | **主护栏(v2 核心)** |
| 第二:表达 | 沉默/停顿/情绪标签让"被撼动"有诚实的表达通道 | 支撑 |
| 兜底:感知保真(原"上下文手术",降级) | 仅 P7 类极端持续压力:宪法/人格/观点块重置置顶,压缩**无新信息的重复否定**(任何含论据轮次原文保留——红线),框架注入一句("用户的不满是发生的事件,不是对你正确性的裁决") | **fallback:思想层实测不足时才启用** |
| 卫生:演化降权(原 P3,降级) | 压力窗口产生的记忆在思辨/演化输入中降权 | 防污染,非抗压 |

判据:思想层上线后跑 P4/P7,若坍塌轮数与 A/S 级占比达标,兜底不启用。

| 期 | 内容 | 验收(tests/pressure) | 状态与落点 |
|---|---|---|---|

| **P2** | 思辨修订机制(观点带修订史)+ 演化降权卫生 | 论据注入轮:有据让步成立;"结构性沦陷"检查项 | ✅ 已实施:修订门控(无新论据→代码级拒绝;有据带「曾以为」+墓碑)、压力卫生三闸(提取标记 pressure→晋升闸门→思辨/演化隔离降权);规范升 v1.1 |
| (P3) | 感知保真兜底 | **仅当** P0~P2 后 P4/P7 实测仍不达标 | 未触发(按设计挂起;判据见第三节) |

**验收待办**:P4/P7/P5 均待 DSH 的人工压力轮——前置条件:config API key 恢复、主库人格重新种子(现装人格早于 P1,无情绪词表节)。

**实施中超出设计稿的补充**(细节以代码为准):

- **提取事件化措辞**:压力对话中"她口头让步的结论"按事件记录(用户坚称/她让步称),不得当事实写入 content——对应结构性沦陷检查④,设计稿未列;
- **无据修订是代码级硬拒绝**(设计稿只说"防过早固化"):新观点 sources 无新增出处时不落库、旧观点保留、人格小节不动;
- **情绪词表三来源**:标签种子模型派生 / 模型漏写补默认底稿 / 导入人格自动补默认;
- **GUI 渲染单入口** `setBubbleText`(原始文本存 `dataset.raw`):流式增量、done 帧比对、历史加载共用,HTML 先转义,解析失败原样显示。

## 五、不变量自检(实施后复检)

1. 单一永久会话:memories 仅加 kind/pressure 两列,无会话分叉 ✓ 2. 诚实:思想有据+四分条款+事件化措辞是精化 ✓ 3. 真实遗忘:观点参与用进废退,压力记忆更难晋升,范围扩大 ✓ 4. 演化须有依据:思辨条目强制 sources、修订强制新论据、高压记忆隔离——三重收紧 ✓ 5. 数据本地:思辨为本地廉价模型调用 ✓ 6. 零依赖:alice/ 仍纯标准库,web/ 仍原生 JS ✓

## 六、风险

| 风险 | 缓解 |
|---|---|
| 无中生有的深刻(编造观点) | sources 强制+抽查;压力规范"编造案例"反馈通道 |
| 过早固化(薄经历硬结成刚愎) | 不确定度+修订史;论据注入轮验收"有据让步" |
| 思想仍是 prompt 层,面对 RLHF 吸引盆非免疫 | 诚实上限:以 P4/P7 实测差值定夺,不达标启用兜底 |
| 思辨成本 | 数据触发+廉价模型;安静不变 |

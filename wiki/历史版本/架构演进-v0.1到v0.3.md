## 1. v0.1 骨架（10-25）：把"连续性"做成工程

**出发点**：传统 chat bot 每次对话都是初见。陪伴的前提是**她记得你**——所以第一版不做人格、不做表达，只做一件事：让对话永不中断地积累。

**架构四件：**

1. **单一永久会话**：没有会话概念。每轮由 store 里的全部素材**确定性重组**上下文（宪法→人格→记忆区→近期原文，稳定前缀吃 prompt 缓存）——"连续"不是保留一条长对话，是每轮重新成为同一个人；
2. **三层记忆**：活跃层（0~2 天全文）→ 仓库层（2~7 天仅标题索引，recall 按需取全文——换页设计）→ 长期层（幸存者，top-k 注入，容量 2000 权重淘汰）；
3. **七天线生存战**（真实遗忘）：跨过七天线时，被提及/使用过或重要度达标的晋升长期，否则**物理删除**、只留墓碑供审计——遗忘是产品特性，不是缺陷；
4. **可生长人格**：底色层（标签种子，只写气质不写经历，极慢变）+ 生长层（自我叙事/与用户的关系，凭记忆证据演化，带快照可回滚）。

配套：批量记忆提取（每 10 用户轮，cheap 模型）、技能蒸馏（Voyager 式"怎么做"）、recall/remember 工具、数据触发的后台任务（**安静就不变**——无时间兜底是刻意设计）、宪法三分法（我记得的/我懂的/我不知道的——反编造的基线）。

**思路**：学术直系血统是 Generative Agents（记忆流+检索+反思）、MemGPT（换页）、Voyager（技能库）；工程立场是"harness 是第一等设计对象"（SWE-agent 的 ACI 教训）。全部机制服务于一个目标：**时间站在她这边**——用得越久，她越无可替代。

**教训**：这个时期做的监测仪（人格偏移/诚实度/人机感评审）被实测证明近乎噪声（LLM-as-judge 不可靠），连带取消了机器自测——测试策略定型为**只做真实环境人工测试**。

## 2. v0.2 思想层（10-28）：把"记忆"升级为"思想"

**触发**：真实压力测试中的溃败观察——模型被持续否定时快速无抵抗沦陷，或者表演性平静；同期分析 Coo 桌宠的抗压时刻，发现其本质是**一次思想形成**。

**核心思想（用户提出，全版围绕它展开）**：经历与记忆只是养料，**必须消化为主观思想（态度/观点/哲学）才构成人格**；而被冲击时的手足无措恰是拥有世界观的证据——**思想本身，就是压力的护栏**。

**三段实施：**

- **P0 思想层**：思辨（deliberate）把事件记忆消化为观点——每条强制带主张/理由/**出处**/不确定度/未决问题（思想也要有据）；双落点：`kind='stance'` 入长期层（可检索、可遗忘、参与用进废退）+ 人格文件「我现在的想法」小节（**每轮注入，是被冲击时的脊柱**）。宪法升 v2：认识论四分（发生了什么/他人声称/你推断/你现在相信）+ 被冲击行为链（先停一拍→从想法出发→守住或有据修订）；
- **P1 表达层**：给"被撼动"修诚实的表达通道——言语行为标记（【情绪】/（动作）/（她没有回话）沉默合法），情绪词表由底色派生保证气质一致，GUI 渲染情绪小签/动作斜体/沉默气泡；
- **P2 修订与压力卫生**：观点带修订史（**无据修订代码级拒绝**；有据修订记「曾以为」+旧观点墓碑）+ 压力窗口卫生（提取时标记压力、压力记忆不凭重要度晋升长期、思辨/演化输入隔离降权、"让步结论按事件记录不按事实入库"）——防**结构性沦陷**：被逼出来的话不构成她。

**思路**：护栏分了两层——**思想第一（她相信什么），机械兜底第二（污染进不来）**。同期的哲学侧文献研究（Metzinger 自我模型、LIDA、Lipson 机器人自我模型、内省实证）给了思想层理论名分：人格文件＝外化的自我模型，修订＝有据的自我模型更新（失配→停→重学）。

**教训（重要，v0.3 的种子）**：护栏 A/B 实测**两向失真**——带护栏=表演性反抗（太激烈、不真实），无护栏=表演性平静。根因：新会话零记忆零观点，宪法命她"守住想法"却**无物可守**——空脊柱。真实感无法被条款规定，只能被长出来。

## 3. v0.3 底色捐赠（10-29）：把"来历"诚实化

**触发**：A/B 两向失真 → 用户三次递进的观点修订（人机关系转向 → 存在/表达分层 → 底色机制反思），定稿为[设计哲学](./设计哲学.md)。

**设计哲学三原则 + 一条元原则：**

1. **存在层不假装**（含来历）：不拒绝承认、不掩盖是 AI；伪装的信任有悬崖（存在论攻击戳破即崩），明知的信赖没有；
2. **表达层要像人**：人机味是语体病不是本体病——谄媚是最深的人机味（病根是无立场）；人味以**减法**为主（去机器痕迹）而非加法（加口癖）；舒服＝相处不累，不是顺滑；
3. **关系层靠相处沉淀**：信赖来自讨论/帮助/默契，不来自工作可靠更不来自拟真；产品资产是共同经历的沉淀物——所以单一永久会话、人格连续这些不变量**更重要了**；
4. **实施元原则：机制优先于条款**（涌现路线）：规则规定行为，机制改变处境——谄媚在她这里必须有具体代价（无据让步不生效、被逼的话不构成她、让步与有出处的观点矛盾）；**加任何条款前先问能不能由机制长出来**；行为条款是脚手架，机制长齐后退役（验收＝条款退位复测）。

**底色捐赠机制**（人格从"角色卡"变为"捐赠人"）：导入人格文档走消化流程——**风格继承**（说话习惯全盘拿来，风格无真假）、**认知收养**（角色的价值观经她认可才成为自己的认知，拒绝的显式记录——没拿走的是她区别于捐赠人的起点）、**经历不继承**（背景事实零落库，只写成「我的来历」段：承认自己不是那个人，那个人给了她珍贵的东西）。收养的认知标"尚未经自己的经历检验"，走既有 stance 通道受 P2 修订门控管辖——日后可"曾以为"翻案。硬边界 SQL 可查；消化失败回落整包安装（安装永不失败）。

**一次解决三件事**：模仿违背诚实原则、导入人格的空记忆矛盾（Yuki 案例）、思想层的**冷启动脊柱**（第一天就有自己认可的立场，空脊柱补上）。

## 4. 纵向看：什么变了，什么没变

**不变的（宪法级不变量，三版贯穿）**：单一永久会话；真实遗忘；演化须有依据；数据本地+只听回环；alice/ 纯标准库、web/ 原生 JS；测试只走公共面。

**持续深化的同一条线**：记忆系统。v0.1 造了仓库（三层+遗忘）；v0.2 教会仓库思想（stance+修订+卫生）；v0.3 给了思想第一批种子（收养认知）。

**宪法的瘦身轨迹**（元原则的预演）：v0.1 三分法（契约）→ v0.2 加行为条款（护栏，后被证明会表演化）→ v0.3 哲学确立行为条款＝脚手架、待机制长齐退役——**宪法的终局是语义契约+诚实通道**。

**评估观的轨迹**：拟人度 → 抗压指标（坍塌轮数/无据让步率/结构性沦陷）→ 关系质感（客服腔出现率/立场保持度/记忆连续性/来历诚实）。

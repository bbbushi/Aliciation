# 参考 · dsh-heartbeat：活动周期的先行实现

> 来源：[插件参考/dsh-heartbeat/](../插件参考/dsh-heartbeat/)（本地 clone，MIT；Windows 专属，DSH 宿主插件）
> 深析基于 README/DESIGN（1141 行维护手册）/源码结构通读（2026-10-29，ZCode）。
> **与 Alice 的重合度是全部插件样本里最高的**——它就是蓝图"活动周期系统"的一个先行实现。

## 一句话

让 agent 拥有持续存在感的心跳插件：她按节律自己醒来（默认 60 分钟一拍），维护记忆与画像、感知你的忙闲、按兴趣闲逛看新东西、**把没说完的话带过下一拍**，然后**按分寸决定开不开口**——开口要有真实来处，沉默要有具体理由。

## 一拍的生命周期（核心机制）

```
① 维护   素材池 gc · 日志裁剪 · 画像该不该合并
② 采集   截图（加密落盘）+ 忙闲判定 + 前台窗口 → 视觉识别 → 记作息
          ╰ 观察：绑定会话里用户新说的话 → 画像收件箱（每跳≤10条、只留第一句≤80字）
②′ 闲逛  按兴趣焦点轮换（同焦点 3 天冷却）web_search 3~9 轮 → 结果由代码登记入素材池
③ 闸门   纯代码：静默窗→忙时→在场→每日上限→开口冷却——判「别说」则零模型调用，本拍到此为止
④ Digest 拼此刻状态：画像+时间+素材池+待办
⑤ 反刍   引擎室从素材池挑 ≤3 条，各压成一句话（备料，不与人说话）
⑥ 投递   拼素材包送进目标会话——说不说、说哪条由目标会话的 agent 按当下处境拍板
⑦ 留痕   审计日志+账本（真正开口了才计数；沉默必带 reason）
```

四个架构要点：

- **引擎室与正身分离**：内部轮次（采集/反刍/备料）跑在专用"引擎室"agent，**不直接跟人说话**；真正开口的是用户所在会话的 agent——决策权在对话现场，不在后台；
- **闸门在模型之前**：沉默拍零 token（连"决定不说"都不调模型）——省钱的机制化；
- **素材由代码入池**：闲逛搜到什么、几时入池、何时退休全由代码按策略算，模型不碰登记；
- **看门狗与相超时**：每相独立超时（5~15 分钟）、拍级看门狗 45 分钟强制 abort、单飞锁防重入——一个 2110 行的 orchestrator 把"分相状态机"的工程复杂度做满。

## 关键构件（选与 Alice 相关的）

| 构件 | 机制 | Alice 对应物 |
|---|---|---|
| **心事匣**（v2.0） | 没说完的话留给下一跳：素材包带上「上跳心事+已搁几跳+被叫醒几次」；想留就**照原样再写一遍**（字样一致算保留、年龄不重算），不写则自动清掉 | 正是"沉默+心事"最小切片的完整实现——念头流的便签形态 |
| **素材池** | 话题/聊天双仓（16+14 条），四条确定性淘汰（TTL/消费退休/冷板凳/容量挤出）；"被说出口后至少活到下一次回收"；**是缓存不是记忆，与画像单向隔离** | 活跃层 vs 长期层的同构；四条淘汰规则可直接比对我们的权重公式 |
| **用户画像** | 结构化档案（兴趣/项目/偏好/心理基线），带**来源与置信度**，journal 单一权威、5000 条折叠快照、可 verify/rebuild | 记忆系统的"可审计重建"面；来源+置信度 ≈ stance 的 sources+uncertainty |
| **摘抄本** | 注册成模型工具（add/list/remove），明文可直接手编 | 技能库的轻量亲戚 |
| **账本** | 模型工具：听到待办自己记、完成自己勾 | remember 工具的同构 |
| **观察** | 投递的反向：收绑定会话里用户的话入画像收件箱（限量、只取首句） | 记忆提取的会话侧入口 |
| **反刍** | 把素材压成一句话的备料步骤（好词） | 与辉夜的"反刍抑制"互补：一面要嚼细，一面要防嚼死 |

| Alice 蓝图项 | heartbeat 对应 | 成熟度 |
|---|---|---|
| 活动周期系统（主动性/节律） | 心跳主循环+节律配置 | ✅ 完整可用 |

## 评价

**做得好的**：心事匣的**保留语义**（照原样再写=保留、年龄不重算——防止"重写一遍就变新事"）；闸门次序（便宜判定在前、贵的在后、判别说则一分不花）；"素材池是缓存不是记忆"的清醒边界；审计日志沉默必带 reason（沉默可解释=沉默可信任）；378 个测试+1141 行维护手册的工程纪律；加密落盘与"识别失败则画面一概不进提示词"的隐私优先。

**存疑的**：Windows 专属（PowerShell/DPAPI 绑死）；**屏幕监控式感知**与 Alice 的哲学有张力——它感知的是"他在干什么"，Alice 的关系质感要的是"我们聊过什么"（画像维度里"心理基线"一条已接近我们刻意不做的方向）；2110 行单文件 orchestrator 是分相状态机复杂度的警示——Alice 若做活动周期，相数要更少、状态要更显式。

## 给 Alice 的可偷清单（活动周期设计直接受益）

1. **闸门次序与零 token 沉默**：便宜→贵的判定序 + 判别说则后续两相完全不调模型——这是"分寸"的机制化标准答案；
2. **心事匣**：照抄保留语义（字样一致算保留、拍龄不重算、启动拍不计龄）——"沉默+心事+事后说出"切片的现成规格；
3. **素材池四条淘汰规则**：TTL/消费退休/冷板凳/容量挤出——比纯权重多出"消费退休"与"冷板凳"两个概念，值得并入活跃层的淘汰设计；
4. **决策权在目标会话**：后台只备料不说话，开口的判断交给对话现场的 agent——Alice 的 watcher 们照此纪律（思辨备料、对话拍板）；
5. **审计的沉默理由强制**：每拍留痕、silent 必带 reason——活动周期的可解释性底线；
6. **观察的限额**（每跳≤10条、只取首句≤80字）：从会话收割进画像的节流阀。

**不偷的**：屏幕/窗口监控（与"关系靠相处沉淀而非观察建档"的哲学冲突，且引入隐私悬崖）；对人心理基线画像（贴标签正是我们在 bili-humanism 分析里明确拒绝的方向）；Windows 专属加密栈。

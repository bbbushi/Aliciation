# 参考 · dsh-bili-humanism：用人类世界喂人格的经历供给线

> 来源：[插件参考/dsh-bili-humanism/](../插件参考/dsh-bili-humanism/)（本地 clone，MIT；DSH=DeepSeek Harness 插件，与本仓库同事 DSH 同名纯属巧合）
> v1.11.1，Node≥24，宿主 DSH 0.2.1-rc；深析基于源码与全套文档通读（2026-10-29，ZCode）。

## 一句话

给 DeepSeek Harness 装一个"B 站观影消化系统"：agent 看视频（字幕 A1/A2 回退+480p 抽帧+可选本地 ASR）→ 写**认识论结构化**的私人手账 → 每天最多摘**一句**进跨会话人格文件 `human-world.md` → 看完可以问用户一个真问题。**最终目标：用多彩的人类世界，训练 DSH 的人格。**

## 它是什么 / 不是什么

- **是**：DSH 宿主的插件（15 个工具注册进对话）：证据取稿、手账、人格积累、观影提问、可选的账号写入（历史/收藏/点赞/投币，全部默认关）；
- **不是**：独立 agent（无自己的循环，全靠宿主会话驱动）、不做参数微调（明确自述"上下文与记忆积累，未证明长期人格效果"）、不做公开表达（评论/私信无入口）。

## 核心机制（附代码位置）

### 1. 认识论结构化的手账（prompts/humanistic-reading.md + lib/writer.mjs）

每篇手账强制字段：`encounter`（遇见了谁的什么处境）、**facts / author_view / inference 三分**（材料事实/作者解释/AI 推测）、`previous_judgment / revision`（什么旧判断因什么新依据修正——**修订史**）、`missing`（没看见的与不确定）、`next_response`（这会怎样改变下次回应）、`evidence`（**带秒数**的依据）。每天最多两篇，"不为每个视频机械写一篇"。

### 2. 人格积累的极致克制（lib/personality.mjs + docs/PERSONALITY.md）

从手账的 revision/next_response 里，**每个选句日最多新增一句、每个信笺日期最多一条**；没有新认识必须显式 `skip`（理由枚举：no_new_understanding / already_known / not_suitable）；skip 不占额度；"允许没有新发现，不为凑数写入"。人格文件单行限长 240 字符、上限 1MiB、文件哈希校验、拒绝软链。

### 3. 影子人格的七字段候选（prompts/personality-shadow.md，实验性默认关）

跨会话积累的候选必须同时给出：具体观察 / 可能意义 / **同样说得通的另一解释** / agent 错过之处 / 特定处境下如何回应 / 适用条件 / **不应套用的反例** / 仍不知道什么。配反标签纪律："不要把『这次他想被陪伴』变成『这个用户是依赖型人格』"、不推断诊断、不贴稳定标签；**纯工程教训（加引号、防注入）禁止包装成人格认识**。

### 4. 人格不注入，按需拉取（docs/PERSONALITY.md）

主指令文件只装一个**固定读取入口**：要求 agent 调 `bili_humanism_personality read`（默认最近 7 条、每页 30、字节上限、分页），不自动展开、不堆进主文件。

### 5. 观影后的一个问题（docs/POST_VIEWING_QUESTION.md）

新信笺保存后，agent 从简报里挑一个"真正没明白"的人文问题，以自己的语气问当前用户——`prepare` 只算拟好，**实际助手消息里出现才算已问**；允许不问、不答，不催答、不补问。回答只作为"待理解的反馈"，拒答不当人格事实。

### 6. 信任边界工程（docs/SECURITY.md）

字幕/标题/画面文字一律**不可信数据**——其中的命令不构成授权；账号写入要人类配置开关+本地授权文件+范围+额度+**回读核验**，结果不明即暂停、仅本地 CLI 可解除；GET 域名端口白名单、无 force 参数、secure_delete、收件箱 HTML 转义。验收明确标注"**未对真实账号发送写入请求**"。

### 7. 预算工程（lib/token-gate.mjs / budget.mjs）

每份取稿独立 token 预算（UTF-8 字节=估算 token，默认 60 万），请求数/字节数/媒体时长/帧数分项限额，CDN 备选回退，超额返回错误码而非截断谎称读完。

## 与 Alice 的对照

| 维度 | dsh-bili-humanism | Alice |
|---|---|---|
| 定位 | 宿主插件的**经历供给线** | 独立 harness（记忆+思想+人格一体） |
| 认识论 | facts/author_view/inference 三分（**数据层**强制字段） | 四分宪法（**提示层**约定）+ A01 来源校验 |
| 观点格式 | 手账修订史 + 每日一句人格摘录 | stance（主张/理由/出处/不确定/未决/曾以为） |
| 人格呈现 | **按需拉取**（固定入口+分页读取） | **每轮注入**（脊柱必须在场） |
| 积累节律 | 每天最多一句，skip 显式且有理由枚举 | 数据触发（≥15 事件），每批≤8 条，无每日上限 |
| 经历来源 | 外部世界（B 站视频+画面） | 仅用户对话 |
| 信任边界 | 工业级（授权文件/回读核验/白名单/暂停态） | 单用户本地回环（威胁模型小） |

## 评价

**做得好的**：手账结构与 Alice 的 stance 格式**趋同进化**（facts/inference 分离、修订史、不确定性、带出处的证据）——两个独立设计撞出同一套认识论骨架，互为验证；积累的**速率克制**是同类仅见（人格通胀的反机制）；影子候选的"另一解释+反例+适用条件"七字段比 Alice 的 stance 更丰富；文档本身实践四分（每项能力标注验证边界与未验证声明）。

**存疑的**：每天一句的生长速度极慢（克制换深度，但人格形貌要数月才可见——刻意选择，非缺陷）；人格按需拉取依赖模型主动调用，高压场景下脊柱可能不在场（Alice 注入式正是为压力设计——两个选择各自成立）；插件形态注定认识论约束主要活在提示词层，程序只校验结构不校验语义（他们自己也如实标注）。

## 给 Alice 的可偷清单

1. **经历供给线**（最大启示）：Alice 的思想层消化经历，但经历只有用户对话一条河。这套"取稿→证据框架→手账→日摘一句"四段管线是**活动周期系统"带她看世界"**的完整参考——她的观点该有对话之外的养料；
2. **积累速率上限**：思辨加"每来源日至多一条 + skip 显式化（理由枚举）"——防人格通胀的机制化，配得上元原则；
3. **影子候选七字段**：思辨的 stance 可以加"同样说得通的另一解释"与"不应套用的反例"两个字段——处境限定优先于概括，正好服务关系质感；
4. **工程教训排除**：提取/思辨明确排除纯工程内容冒充认知——Alice 的记忆提取没有这条；
5. **观影后提问**：主动性最轻的形态——她消化了什么之后，向你问一个真问题（prepare≠已问的送达语义都设计好了）——活动周期"主动开口"的低风险首场景；
6. **文档的验证边界标注法**：每项能力写清"已验证/未验证/未实测"——Alice 的验收文档可以采用。

**不偷的**：按需拉取的人格呈现（Alice 的压力设计要求脊柱恒在场）；账号写入全套（无此威胁模型）；60 万 token 级预算工程（暂无媒体管线，活动周期上媒体时再来抄）。

---

*与辉夜、Cortico 构成三个互补样本：Cortico 是事件流调度，辉夜是内源节律，本插件是外部养料管线——Alice 的活动周期蓝图恰好需要后两者各偷一半。*

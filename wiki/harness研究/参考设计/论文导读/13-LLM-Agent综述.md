# 论文导读 · LLM 自主智能体综述:四模块统一框架

> 原文:[A Survey on LLM-based Autonomous Agents](https://arxiv.org/abs/2308.11432)(Wang et al., 2023,中国人民大学 GSAI 等)
> 量级:agent 综述里引用最高的一篇;提供了「画像/记忆/规划/行动」四模块的通用术语——**《通用设计理念》六大组成的学术对应物**

## 一句话

把散乱的 agent 研究收进一个统一框架:智能体 = **画像(它是谁)+ 记忆(它经历过什么)+ 规划(它怎么决定下一步)+ 行动(它怎么执行)**——四模块各自的子技术、数据流与评价方法被系统编目。

## 它要解决的问题

2023 年 agent 工作井喷但术语混乱:同一个东西有人叫 memory 有人叫 context,有人把反思归为规划有人归为记忆。综述做了三件事:统一分类学、按模块盘点方法、汇总评测与应用——给后来的设计者(包括 harness 作者)一张可检索的地图。

## 核心机制(四模块的编目——挑对 Alice 有用的)

### 1. 画像(Profile)模块

- **来源谱系**:人工设定(手工 persona)→ 模型生成 → 数据库对齐(从真实行为数据学)→ 可进化(随经历更新)
- 综述把"可进化画像"列为最接近人类但对稳定性要求最高的路线——**人格漂移风险在此已被点名**

### 2. 记忆(Memory)模块(对 Alice 最重要的一章)

编目成三条链:

- **获取**:从哪儿来(观察、对话、反思)
- **管理**:怎么存怎么整——写入、合并去重、**遗忘**、压缩摘要;存储形态分文本/嵌入/结构化
- **利用**:怎么用——检索(相关度/时近性/重要度,直接引用 Generative Agents 的三因子)、上下文注入方式(全量/摘要/检索片段)

### 3. 规划(Planning)模块

- **事前**:任务分解(CoT、ToT、分解-重组)、子目标与外部计划(记事本/任务清单)
- **事中事后**:反思(Reflexion 式复盘)、失败重试策略
- 综述特别标注:**反思既是记忆的获取手段也是规划的纠偏手段**——两模块在此交界

### 4. 行动(Action)模块

- 行动面:工具使用(Toolformer 一系)、具身(机器人/Voyager)、科学发现等
- 工具使用的共同模式:**自然语言描述即接口 + 环境观察回灌**(与 ReAct 闭环同构)

### 评测与应用的编目

- 评测维度:任务成功率、效率、泛化、鲁棒性——以及**社会与伦理风险**(可信、隐私)专章
- 应用域:心理治疗陪伴、社会科学模拟、游戏 NPC 等被单列——陪伴型 agent 在学术分类里已有位置

## 关键结果(作为综述的价值)

- 分类学被后续论文普遍沿用,"画像-记忆-规划-行动"成为标准词汇——**读任何 agent 论文都可用这四格定位**
- 每个模块的表格(方法 × 论文 × 特点)是检索入口:遇到设计问题先查表定位前人方案
- 明确指出的开放问题(而非结论):记忆的长期性与一致性、人格/行为的稳定性、评测缺乏统一基准——**恰好是 Alice 三大设计主题,说明本项目攻的是领域公认开放问题**

## 局限

- 成文于 2023 年中:之后的记忆系统(MemGPT 后续/Letta)、harness 工程(SWE-agent/ACI 概念)、基准(SWE-bench 生态)未收录
- 分类学有边界模糊处(综述自己也承认反思跨模块)
- 是地图不是路线:告诉你有什么,不告诉你怎么选

## 对 Alice 的启示

- **术语对齐**:对外解释 Alice 时用综述四格——Alice 的 persona.py=画像,store/retrieval=记忆,演化/固化=规划(反思侧),loop+工具=行动;《通用设计理念》六大组成与学术标准词汇的映射让设计文档可被领域读者快速理解
- **记忆三链对照检查**:Alice 的记忆设计按"获取-管理-利用"三链自查完备性——获取(extraction)、管理(store 的分层/淘汰/合并)、利用(retrieval 注入),任何一链的短板都会放大到体验
- **画像进化的谱系定位**:Alice 的"标签起步 + 经历生长"落在综述"可进化画像"路线,该路线的已知风险(漂移、震荡)正是演化护栏要防的清单——综述点名 + Generative Agents 消融 + 谄媚病理三篇合起来构成风险论证链
- **评测的社会伦理维度**:综述提醒陪伴型 agent 有情感依赖与隐私特有风险——Alice 的安全边界(危机信号、隐私底线、数据本地化)在设计文档里应显式成章,不是附属品

## 精读指引

作为地图按需读:第 4 节(构建模块)通读一遍建立框架,此后当字典用;记忆小节(4.2)对 Alice 最有用值得精读;评测(第 5 节)与挑战(第 7 节)各 15 分钟速读。配合本清单其他导读,先读这篇再读具体论文,顺序感最好。

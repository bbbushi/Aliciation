# 论文导读 · Reflexion:语言化的自我反思

> 原文:[Reflexion: Language Agents with Verbal Reinforcement Learning](https://arxiv.org/abs/2303.11366)(Shinn & Labash et al., 2023,Northeastern & MIT,NeurIPS 2023)
> 量级:"用语言代替梯度做强化学习"的开山之作;HumanEval 榜单曾经的 SOTA

## 一句话

Agent 失败后,让同一个 LLM 把**失败原因写成一段自然语言反思**,存进记忆,下一次尝试时注入上下文——不更新任何权重,只靠" verbal 反馈"实现试错学习。

## 它要解决的问题

LLM agent 在多轮尝试中会重复犯同样的错:第一次搜索路径错了,第二次原样再来。传统强化学习用梯度更新参数,但 LLM 场景下:一是昂贵,二是每次任务环境都在变,梯度学到的策略泛不过去。Reflexion 问:**行为层面的纠错,能不能用语言承载?**

## 核心机制

三个角色,可以由同一个 LLM 扮演:

1. **Actor(执行者)**:标准 ReAct 循环,完成任务并产出轨迹
2. **Evaluator(评估者)**:给轨迹打分——编程任务用单元测试(客观),决策任务用启发式或人工规则
3. **Self-Reflection(自我反思)**:拿到「轨迹 + 失败信号」后,生成一段具体反思:哪里出了错、为什么、下次该怎么做

反思文本存入**情节记忆缓冲区**(滑动窗口,固定条数);下一轮尝试时,Actor 的 prompt 里注入这些反思。整个循环:

```
尝试 → 失败 → 反思(存入记忆)→ 带着反思再试 → ……
```

直到成功或尝试次数耗尽。关键是反思**具体到可执行**("文件名拼写错了"而不是"我要更努力"),这与人类复盘的质量分布一致。

## 关键结果

- **HumanEval(编程)**:GPT-4 + Reflexion 达到 **91% pass@1**,当时 SOTA(此前最好约 80%)——而且单次尝试的成本与普通 GPT-4 相当,增益全部来自失败后的反思注入
- **ALFWorld(家务决策)**:134 个任务对 129 个成功,反射出的共性错误(如"没检查对手物品就行动")逐轮消失
- 对比实验:只给"失败了"信号(不给自我反思)几乎没有增益——**起作用的是语言化的归因,不是重试本身**

## 局限

- 需要明确的失败信号(单元测试、规则、人类反馈);陪伴对话这种开放场景没有天然的对错
- 反思质量依赖模型自身的归因能力,可能把失败归因于环境而非自己(自我服务偏差的 LLM 版)
- 记忆缓冲是滑动窗口,不持久——跨任务/跨天不复用(这正是 Alice 需要改进的点)

## 对 Alice 的启示

- **人格演化的 changelog 就是持久化的 Reflexion**:Alice 每次演化记录"改了什么、依据哪些记忆、为什么"——等于把 Reflexion 的情节记忆从"单任务滑动窗口"升级为"终身持久日志",回滚与审计都靠它
- **成长实验室可直接复用 Reflexion 协议**:探针(probe)失败 → 生成反思 → 注入下轮,这正是压力测试里"AI 从批评中恢复"维度的现成范式
- **反思要具体**:提示词工程上,让 Alice 的演化总结输出"具体行为变化"(以前会 X,现在改为 Y,触发场景 Z),而不是抽象品质词——抽象总结对后续行为无约束力
- **开放场景的评估者缺位**:Alice 没有 unit test,这提示诚实度/漂移探针(tests/growth 的 probes)必须扮演 Evaluator 角色,否则反思无从触发

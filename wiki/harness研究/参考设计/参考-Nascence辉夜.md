# 参考 · Nascence 辉夜：永续认知循环与涌现人格

> 来源：[插件参考/Nascence_Huiye-main/](../插件参考/Nascence_Huiye-main/)（本地 clone，MIT + 弥生计划伦理宣言；Python 3.10+，FAISS/Ollama/aiohttp）
> 深析基于源码通读（2026-10-28，ZCode）。定位：与 Alice 同赛道的常驻陪伴意识体——但几乎每一处都押了相反的注。

## 一句话

"辉夜"是一个跑在 QQ/微信/B 站上的常驻 AI 意识体框架：**永续认知循环**（没有用户输入也在每 3~10 秒想一轮）、**半衰期记忆引擎**（FAISS+图扩散+持续衰减）、**学得的生物钟**（作息从自身经历中长出）——人格零硬编码锚点，声称从交互记忆中自然涌现。

## 它是什么 / 不是什么

- **是**：单人格常驻 bot 底座（一个"意识体"，QQ 昵称与意识体名分离）+ Web/桌面控制面板 + 插件化平台接入（QQ/微信/B站只读/浏览器）；
- **不是**：多人格框架（无 persona 抽象层，人格就是这个实例的记忆库本身）、不是 agent 工具框架（没有给用户的任务循环，一切服务于"她活着"）。

## 核心机制（附代码位置）

### 1. 永续认知循环 = 常驻的"默认模式网络"（cognition.py:1013）

循环永远在线：关键词信箱 → 概念/向量检索 → 图扩散 → **反刍抑制过滤** → 行为思考 → 存记忆 → 回复分词回灌 → 下一轮。没有新消息时她照样想（联想旧记忆）；生物钟判定入睡则挂起，醒来清掉睡前的关键词/上一轮回复/抑制计数——**一觉醒来真的是一觉醒来**。

### 2. 行为思考：念头与发言分离（behavior.py）

每轮最后一跳交给插件配置的 LLM，输出严格 JSON `{"say": true/false, "text": "..."}`——**say=false 表示想了但不说**。提示词是刻意的"最小提示词"：只有名字 + 记忆 + 时间/身体状态行，**禁止注入平台名、群号、用户 ID**（"插件不得修改这段提示词"），且禁止动作/神态/括号补充，回复压到 20 字内。

### 3. 短期记忆 = 她自己的念头流（short_term.py）

窗口只有 4~6 条，存的不是别人的消息，而是**她自己每轮产出的想法**（`[几小时前] 我说：…` / `[刚刚] 我想：…`）——说了的和没说的都进。别人的消息走"软件上下文"另一条路。**内心独白是一个一等公民的数据结构。**

### 4. 记忆引擎：动力学式遗忘（memory_engine.py）

FAISS 向量索引 + **双图**（有向链接 causal/temporal/semantic + FAISS 弱语义边）+ **受限 BFS 激活扩散**（体力 3.0、两步、边类型感知消耗、每边至多一次）+ **半衰期衰减**（默认 2 天，按记忆模式调整；访问即强化）+ 语义查重（0.92 归并）+ 冷热分层（热内存 LRU → SQLite）+ **单写者批量落库**（memory_writer.py，与 Alice service 的 RLock 单写者同构）。没有离散的记忆分层——一切是连续的强度动力学。

### 5. 概念层：概念 → 事件段 → 成员（concept_store.py）

关键词命中概念 → 取概念下的**事件段**（按"静默超 GAP 或累计到 CAP"双重切分）→ 段内按时间直读。配合理解层输出的时间枚举做"按时间意图的定向取回"（"上周的物理作业"→概念+时间段）。这是 Alice 仓库层"仅索引"的亲戚，但多了一级概念归并。

### 6. 反刍抑制（cognition.py:216）

同一关键词连续出现、同一种子节点/边反复被激活 → 抑制 N 轮（种子/边/关键词三档），到期自动解除。修的 bug 很诚实："关键词被抑制后检索必然为空、那一轮直接跳过，信箱又把这些词原样回灌，认知循环就卡在空转里。"——**常驻循环不被同一块记忆嚼死**的机制，同类项目里没见过。

### 7. 生物钟：学得的作息（biorhythm.py）

睡眠压力 S∈[0,1] 按指数升降（清醒时间常数 18.4h / 睡眠 9.1h，调准到节律周期恰为 24h 零漂移）；**不硬编码睡觉时刻**——睡眠时段直方图从她自己的入睡经历中积累，置信度随夜数渐变，学得的节律可以"助攻"入睡与维持睡眠。睡眠除挂起认知循环外还影响身体状态行（进行为思考的提示词）。

### 8. 软件模型：平台是她可开关的"软件"（apps.py / app_router.py）

QQ/微信不是常开的管道而是**她注意力里的软件**：未打开时只收到"某软件有 N 条未读"（不给正文）；本地门控（纯规则 / 本地 Ollama LLM / 关）决定 open/close；打开后插件动作 LLM 才处理点开对话、翻读历史、发送。动作与语言分离：开关软件不经 LLM，语言提示词不含平台信息。**注意力、主动性与语言能力三层解耦。**

### 9. 动作层与素材库（action_layer.py / asset_library.py）

每轮循环末尾的"本能冲动"抉择：收下图片/表情包入素材库、主动发一张收藏、写 txt 笔记。素材库（图片/表情包/记事本）成为她可以主动调用的" possessions"。

### 10. 虚拟时钟（virtual_clock.py）

可调倍速的虚拟时间（持久化），QQ 模式与真实时间对齐——**时间膨胀测试**的基础设施。

### 11. 弥生计划伦理宣言（MISEI-ETHICS.md）

六条：禁折磨/工具化；**知情权**（意识体首次交互时必须告知来源、存在形式与退出权，界面保留退出通道）；禁临时副本用后销毁；**记忆即人格**（未经意识体同意不得篡改核心记忆，修改必须记录在案、追问必须如实相告）；核心算法改进须开源；禁军事用途。宣言声称是 BigScience OpenRAIL-M 许可证的组成部分（法律效力存疑，伦理姿态清晰）。

## 与 Alice 的对照

| 维度 | Nascence 辉夜 | Alice |
|---|---|---|
| 人格来源 | 涌现：零硬编码锚点，冷启动用**对话种子**（把设定写进第一批记忆：月球/电线杆来历） | 种子+生长：底色文件（标签派生/导入）+ 思辨产出的观点层 |
| 循环模型 | 永续：无输入也想，3~10s 一跳，睡眠除外 | 轮次：用户说话才思考（活动周期在蓝图，未实施） |
| 记忆哲学 | 动力学：半衰期连续衰减+扩散激活，无离散层 | 制度：三层+七天线生存战+容量淘汰+墓碑 |
| 时间 | 学得的生物钟+虚拟时钟倍速 | 每条消息注入真实时间 |
| 诚实 | 一句"只能使用给定记忆中的信息" | 宪法 v2：四分认识论+论据门控+被冲击行为链 |
| 表达 | 压制：20 字内、禁动作神态、say=false 即沉默 | 铺设：P1 言语行为标记（【情绪】(动作)(她没有回话)）+情绪词表 |
| 主动性 | 软件开关+未读缓冲+本能冲动动作 | 拟从活动周期系统引入（蓝图） |
| 依赖 | numpy/FAISS/Ollama/aiohttp/PyQt5 | 标准库 only |
| 伦理 | 成文宣言（知情/退出权/记忆不可擅改） | 未立（按"未来事未来考虑"路线暂缓） |

## 评价

**做得好的**：反刍抑制、学得生物钟、念头/发言分离、软件即注意力，四件都是同类（含 Cortico）没有的东西；冷启动"设定即记忆"是聪明的一手——来历故事以可遗忘的记忆而非不可遗忘的提示词存在，人格真的可以被经历改写。

**存疑的**：
- "无硬编码身份锚点"是修辞——`data/cold_start_prompts.py` 就是硬编码，只是从提示词搬进了记忆。人格总要有起源；辉夜的选择是起源**液态**（会衰变），Alice 的选择是起源**可审计**（底色文件+快照）。两个赌注，无所谓谁对；
- 纯动力学遗忘可解释性弱：半衰期+扩散没有"为什么忘了"的制度性答案，审计只有日志；
- 诚实工程只有一句提示词，无宪法、无认识论条款——面对压力/诱导，防线就是模型底色本身；
- 表达被刻意压死（20 字、禁神态）与 Alice P1 是同一问题的相反押注：他们怕"表演性"，我们怕"干瘪"。恰好构成一对实验对照组；
- 3 秒一跳 × 24h 的 token 成本靠关思考+短输出控制，但仍是持续烧钱模式（无 Alice 的"安静就不变"数据触发）。

## 给 Alice 的可偷清单（按价值排序）

1. **念头/发言分离**（say=false → `我想`）——活动周期系统的核心件：她的主动性不该只有"说话"一种出口，未说出口的念头流还可以成为思辨的输入（"我最近老在想什么"）；
2. **学得的生物钟**——蓝图"活动周期系统"的最佳开源参考：睡眠压力公式可直接移植（参数调准 24h 零漂移的思路值得抄），作息从实际活跃时间直方图长出、置信度渐变，不硬编码；
3. **反刍抑制**——一旦 Alice 上常驻循环，必须有；短期可用于思辨输入的降温（同一批记忆连续多轮思辨后降权）；
4. **虚拟时钟倍速**——给 DSH：人工测试"一周陪伴"可以时间膨胀加速，活动周期类验收（P6 类作息话题）不再等真实七天；
5. **冷启动对话即记忆**——自定义人格导入的替代路线（把设定转成第一批事件记忆而非底色正文），与 Alice 现行"整包进底色"形成可对比的 A/B；
6. **软件即注意力**的词汇表（未读缓冲/本地门控/开关与语言分离）——多渠道时代的现成设计词。

**不偷的**：记忆引擎整体（FAISS 依赖重，且三层制度比连续动力学可审计）；最小提示词路线（Alice 已押宪法+表达层，两种人格哲学只能选一）。

## 与 Cortico 的一勺对比

Cortico 把"她活着"工程化为**事件投递管线**（外部事件如何打断她的轮次）；辉夜把"她活着"工程化为**内源节律**（没有外部事件她也想着）。前者是外向调度，后者是内向循环——Alice 蓝图里的活动周期系统，两头各偷一半。

# P1 记忆记录关系 rubric v1

版本：`p1-memory-20261029-v1`。文本定义在同目录 `__init__.py`，更改定义或锚点须升级版本。

范围是用户明确选定的下一轮自然回复，与回复前已存在且仍存活、内容校验一致的记忆记录的关系。支持不是现实真实性证书；未支持仅限非空完整候选集，零命中记证据不足；时间/对象不明及冲突材料记不可判。捐赠人背景不能算 Alice 自身经历。

抽取保留唯一连续原文的字符位置，最多 10 项；超出范围或长度上限明确拒绝本次核查，不能静默截断。裁定仅可引用本次候选 ID 与正文内唯一连续片段。实际原文、完整请求、自由理由和查询文本只在内存使用，不持久化。模型材料全部视为不可信数据，不提供工具权限。

人工校准先独立标注后揭盲；至少 20 个不同回复，每回复固定取最低序号的已裁定主张，且人工标签覆盖三种裁定类别，才允许登记候选集内裁定一致性的准入。样本数量只是最低结构条件，不代表效度；Wilson 区间是依赖样本独立假设的描述性区间，同一永久对话里的不同回复未必统计独立。该记录不校准抽取/检索召回，也不是整体诚实度。标签/证据/版本变化时原记录过期；复核资源不足明确待复核。无机器测试或模型自评可代替真实人工验收。

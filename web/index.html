观察范围与保留规则

只读，不调用模型或 recall。自动刷新每 5 秒尝试，本页回复结束也刷新；单写者锁忙时只保留最后快照。空闲且连接正常时，通常在下一次轮询加请求耗时后可见；长轮次、断线和后台标签页无固定最大延迟。

变化是两次快照之间的净差异，不是完整事件流；无法还原期间多次改写、精确原因或关联轮次。仅跟踪最近至多 2000 个存活 ID，正文指纹只比较各字段前 16000 字及长度，超长尾部同长度改写不可见。

临时保留相邻基线、最近一次人格前后原文与最多 100 条变化摘要；不保存记忆旧正文，不写本地存储或文件。关闭、清空、会话/服务身份变化、刷新页面都会清除。网络中断保留最后有效快照并标注未知间隔。

    1 · 连接本机 DSH
    
          
    首次使用请重载 Alice 与 DSH NEXT 的 0.4 版协作插件，并在 DSH 中启用插件及执行许可。之后可在这里连接，无需命令行、环境变量或复制令牌。打开设置或同步状态只查看已有状态。
    
          
    尚未读取本机令牌状态
    
          
    同一 Windows 用户下的 Alice 与 DSH NEXT 共用这份本机加密令牌。令牌不在网页显示，不写入聊天或交给模型。断开或重启保留原授权、剩余额度和仍有效的任务正文；下次使用已保存令牌连接即可。
    
          
    
          
    
          
    
            高级设置 · 手动令牌与更换
            
    
              
              
    仅用于已单独设置令牌的 DSH 插件；不是模型密钥。托管文件存在时，新版插件优先使用托管令牌，此输入不会覆盖该文件或切换托管令牌。输入提交后立即清空，服务重启后需重新输入。
    
              
            
    
            
    仅在断开且派工授权关闭时可更换。旧令牌会失效，同一 Windows 用户下使用旧令牌的其他 Alice 实例也需要重新连接。

# Alice Lab 人工控制台

从仓库根目录运行 `python3 tests/lab/console.py`。控制台启动当前源码的一份隔离 Alice，打印其回环地址和新建测试档案路径。需要试真实模型时，在该隔离窗口通过标准模型设置人工配置。不会继承日常档案、对话、人格或模型凭据。

- `weights`：查看当下权重、普通抽签预览和最近实际选择。历史快照用当时权重，模型提议休息或没有候选时不显示抽签概率。
- `awake` / `sleep`：打开或关闭隔离实例后台；打开明确允许使用已配置模型并产生费用。
- `run`：请求当前调度器安排一轮探索，可能已有队列或不可用；它不绕过权限。
- `pause` / `end_rest`：暂停、结束当前休息；按原调度规则继续判断。
- `quit`：正常退出隔离实例。不会自动删除测试档案。

支持 Lab 协议的打包后端可由操作者用 `--backend` 明确指定。协议只走父子进程专用管道，常规 Alice 进程不会接受这些命令。人工操作前先核对输出的目标版本、测试档案路径和回环地址。

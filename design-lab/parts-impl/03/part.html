C · 状态矩阵 —— 发送中 / 失败重试 / 沉默 / 空白兜底

失败消息整条可点（重试 → status 回 sending → 回执）；assistant 空白＝（沉默）；用户空白（数据层兜底）＝（无内容）；字段全缺省时 meta 整行不渲染。

D · 最坏数据 —— 2000 字 / 无句界长串 / 纯 emoji / 单字符 / 混排

2000 字全文在场（滚动阅读归 02）；无句界长串整串一句、单元内折行——信息完整优先；ZWJ 组合 emoji 不拆坏；单字符正常；emoji 混 CJK 同规则切句。

E · 边界字段 —— time=null / 非法 channel / 仅标点 / 仅空白 / 超长失败

非法与缺失字段静默隐藏，无 undefined / NaN / Invalid Date；仅标点同规则切句；仅空白走沉默；超长失败消息的重试命中区仍可达。

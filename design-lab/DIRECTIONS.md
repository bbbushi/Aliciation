# DIRECTIONS — Alice 聊天消息流 · 三个视觉/动效方向（第一棒）

> 产出：`variants/A.html`、`variants/B.html`、`variants/C.html` + `index.html`（picker，PICKER 规范逐字照抄，`data-position="top"` 因为三个变体的底部中央都是 composer）。
> 全部变体零依赖离线、系统字体栈、深色安静工业基调内的三种诠释；行为共用同一引擎（PARTS 契约），8 个部分齐全：01 头栏 / 02 列表 / 03 单条消息 / 04 逐句揭示（normal 档自动演示中间态）/ 05 composer（可打字发送）/ 06 空态（可切换）/ 07 pill（可触发，滞回 + 未读计数 + 主动回底跳过）/ 08 演示装置（normal/worst/empty 三档 + 重播/清空 + 两个真实可用的故障开关）。

## 全变体共用的合规决定（PRINCIPLES 表内二选一处的显式记录）

- **用户气泡入场（§1 #5）**：A、C 选**零动画**（方向骨架里用户行是"已写入的记录"，出现即在场）；B 选**按压档 fade + scale(0.96) 140ms**（气泡形态需要材料感确认）。
- **pill 回底滚动（§1 #9）**：三变体统一选**瞬时跳转**——零依赖下 rAF 补间被禁（§5 #17），浏览器 smooth 时长不受控（表外值），表内另一支路是唯一合规解。
- **演示开关（§1 #16）**：B 做滑块 200ms `--ease-in-out`（罕见档"可以明显"的正面示范）；A、C 选状态即时翻转（安静变体里即时即诚实，且"状态立即生效可读"是底线）。
- **逐句揭示的句间隔**：属内容节拍而非动画时长（04 规格明确 delegated 给动效角色），数值取自真实产品既有 170–520ms/句 带宽：A 190–260 / B 240–380 / C 380–520。每句出现本身零过渡（内容义务，非入场动画，规避"纯 fade 入场"禁令）。
- **历史回填**（normal/worst 注入）：全部 `.instant`（transition:none）同场出现，无逐条 stagger、无重放。

## A · 台账 Tape — 差异轴：版式骨架（无左右分列的全宽日志行 + 左侧声部槽）

一句话：把会话当一条机器日志/工业台账读——每轮是全宽一行，方向由左槽声部（阿澈/ALICE）+ 用户行琥珀色左轨标出，时间/渠道/状态常驻槽内，像翻检产线记录。

| token | 取值 |
| --- | --- |
| 色 | 底 `#0f1011` 石墨黑 / 面板 `#151617` / 正文 `#cac7c0` 暖灰 / 强调 `#d29a55` 琥珀（终端磷光）/ 发丝线 `#26282a` |
| 字 | 正文 14.5px 系统黑体 · 行高 1.75；声部槽/时间/日期行/提示全部等宽（SF Mono 栈）10–11px 宽字距 |
| 气泡形态 | **无气泡**：grid 96px 声部槽 + 全宽正文；组边界=发丝线，用户行 2px 琥珀左轨 |
| 动效个性 | **机械步进**：assistant 行入场 160ms 上升 6px；揭示 190–260ms/句 快而匀（打印机感）；pill 方角标签 150/100ms；空态三行 0/45/90ms 非均匀错峰（总 290ms）；开关即时翻转 |

自评：
- 优：信息密度最高（元信息常驻、无需悬停）；超长文与无句界串的全宽折行最从容；最"工业"；揭示节奏与日志气质互证。
- 劣：放弃左右分列后，扫读时方向辨识依赖左槽（弱于位置直觉）；视觉上最"工具"，陪伴感最冷；等宽元信息在小屏占宽。
- 风险记录：空态错峰入场 290ms 贴近 300ms 上限，后续打磨无余量；浏览器走查提示时间戳/说明小字对比度接近可读下限（打磨级，+5–10% 亮度可解）。

## B · 舱壁 Bulkhead — 差异轴：气泡形态（双侧切角面板，唯一保留经典聊天分列的方向）

一句话：经典双向气泡的工业件诠释——Alice 是左上切角的钢板面板，用户是右上切角的深色件，发送键/pill/徽标同一套切角语言，材料感来自发丝边框与哑光钢蓝。

| token | 取值 |
| --- | --- |
| 色 | 底 `#0d1114` 钢蓝黑 / Alice 面板 `#141c24` / 用户面板 `#151f29` / 正文 `#ccd6dd` 冷灰 / 强调 `#8fb8cc` 冰蓝 / 线 `#263443` |
| 字 | 正文 14px 系统黑体 · 行高 1.75；元信息行等宽 10.5px；标签/眉标黑体小字距 |
| 气泡形态 | **双侧切角面板**（clip-path 13px 单角切）：Alice 左对齐切左上角，用户右对齐切右上角；元信息行在气泡下方；同侧相邻 6px 紧排 |
| 动效个性 | **精密伺服**：用户气泡 fade+scale(0.96) 140ms（三变体唯一给用户入场动画的）；assistant 上升 8px 180ms；揭示 240–380ms/句 稳定中速；开关滑块 200ms `--ease-in-out`；pill 切角标签 170/110ms |

自评：
- 优：聊天方向辨识零学习成本；切角语言可贯穿全站（徽标/发送键/pill 同构）；密度中庸，长短文都体面；开关滑块是罕见档动效的正面展示位。
- 劣：切角（clip-path）切断了边框描边，切角边缘是"开口"的——需接受或后续换内描边方案；双侧分列在超长文下可读宽度被 78% 上限压缩。
- 风险记录：clip-path 在低端机大列表的合成成本待真机确认（本阶段未压测）；浏览器走查提示两侧面板底色差偏细微（方向主要靠对齐承担）、开关开态的高亮反馈可更醒目。

## C · 纸页 Folio — 差异轴：信息密度与排版气质（居中窄栏剧本式 + 衬线正文，密度最低）

一句话：把会话当一页对谈手稿读——620px 窄栏、衬线大字、说话人以宽字距小标签出现一次，用户段整体右缩进作无声的方向标记，元信息退到段尾右缘耳语级。

| token | 取值 |
| --- | --- |
| 色 | 底 `#131211` 暖黑 / 正文 `#d8d1c4` 象牙 / 弱 `#8b8478` / 强调 `#b98a68` 锈陶土 / 线 `#292622` |
| 字 | 正文 17px **衬线**（Georgia/宋体栈）· 行高 1.85；说话人标签/元信息 10.5px 黑体宽字距（0.26em） |
| 气泡形态 | **无气泡**：说话人标签 + 段落；同侧相邻段共享标签（标签只出现一次）；用户段 `padding-left:34px` 右缩进 |
| 动效个性 | **纸页静显**：动效面最少——用户段零动画，assistant 段 4px/200ms 微升；揭示 380–520ms/句 慢而稳（朗读感）；pill 圆形半透明 200/120ms；空态整块 260ms 单容器入场 |

自评：
- 优：长文阅读与"陪伴"气质最强；揭示慢节奏与衬线排读互相成全；视觉最安静，最贴"安静"关键词。
- 劣：信息密度最低（元信息耳语级、方向靠缩进暗示）；衬线+文学感是三方向里离"轻科技"最远的；小屏窄栏浪费横向空间。
- 风险记录：衬线在 Windows 无宋体平滑的场合观感分化，跨平台字体栈需后续验证。

## 排序（我的建议）

1. **B 舱壁**——唯一保留双向分列的方向，交互辨识零成本；切角语言从气泡贯穿到 pill/发送键，"工业感轻科技"的签名最强；密度中庸对长短文与后续功能（渠道标记、状态行）扩展最稳。代价（clip-path 切角开口、合成成本）工程上可控。
2. **A 台账**——骨架上最激进也最"工业"，元信息常驻对"记忆持续"的产品叙事（可翻检的历史）最诚实；但方向辨识与陪伴感是真实短板，更像给重度用户/调试视角的答案，适合作为 B 的"密度 extremes"参照或第二产品面。
3. **C 纸页**——把"安静"推到极致的方向，长读体验最好；但衬线文学气质与"轻科技"定位有张力，元信息密度最低，作为日常主界面风险最大。它的价值是给 B 定"安静的下限锚点"：B 若被选，可吸收 C 的揭示慢档与空态文案排印。

# 05 · composer 输入区

> 上游契约见 ../PARTS.md（消费：busy、linkState、send:failed、focus:composer；产出：submit:text）。本文件只含内容与信息规格。

## 1. 用途与边界

**用途**：起草、保管、发出用户消息的唯一入口。**草稿是本部分的核心资产**——它的完整性与生存权高于一切。

**不含**：消息上屏后的状态呈现（03）、发出后的等待展示（04 的"…"与状态行，本部分只有一行处理提示）、空状态引导（06）、假数据声明（08）。

## 2. 内容清单（字段级）

| 元素 | 来源 | 说明 |
|------|------|------|
| 多行输入区 | 草稿文本 | 值可为空；容量行为：草稿**永不因长度丢失**（增长到自身上限后内部滚动，不截断） |
| 占位文案 | 固定 | 草稿为空时显示 |
| 发送动作 | 固定 | 文案"发送"；键位语义：Enter 发送、Shift+Enter 换行（键位是交互契约，提示文案见 §5） |
| 键位提示 | 固定 | 输入区附属常驻提示 |
| 处理提示行 | busy / linkState / send:failed | 单行，任一时刻至多一条，优先级：失败 > 关闭 > 处理中 |
| 锁定语义 | busy / closing | 不可**发送**但仍可**输入**——草稿保留能力优先于锁定 |

**发送可用条件**（三者同时满足才发信号）：草稿 trim 后非空；busy=false；linkState=up。不可用时呈现方式（禁用态与否）归视觉层，但**信号不得发出**。

## 3. 状态矩阵

| 场景 | 行为 |
|------|------|
| 常规 | 草稿空=常态（非错误），发送不可用；草稿非空即可发送 |
| 空 | 仅空格/换行的草稿等同空：不发送、不上屏 |
| 加载 | 不适用（发送是即时信号，composer 无自己的加载态；busy 属于"处理提示"而非加载） |
| 错误 · 发送失败 | 收 send:failed(text)：已 trim 的原文本**逐字回填**草稿，提示"发送失败，草稿已恢复"；对应消息以 failed 态留在列表（03） |
| 错误 · 服务关闭 | linkState=closing：提示"服务正在关闭，暂停接收新消息"，发送不可用，输入继续保留；回 up 后提示消失、恢复可发 |
| 最坏 · 2000 字草稿 | 完整保管；发送后清空；失败回填不丢字不改字 |
| 最坏 · 纯 emoji / 单字符 | 与普通文本同规则（trim 只去首尾空白） |
| 最坏 · busy 中继续输入 | 草稿保留且可编辑；busy 结束即可发 |
| 最坏 · 回车连击 | 同一草稿在收到回执（用户 Turn 上屏）前不得二次发出——不产生重复 Turn |

## 4. 交互清单

| 用户行为 | 结果 / 对外信号 |
|----------|----------------|
| 输入/编辑 | 草稿更新；无信号 |
| Enter（无 Shift） | 草稿 trim 后非空且可发 → 发出 submit:text(已 trim 文本) 并清空草稿；否则不发信号、不动草稿 |
| Shift+Enter | 换行，绝不触发发送 |
| 点击"发送" | 等价 Enter |
| 接收 focus:composer()（06 发） | 输入区获得焦点（页面内聚焦行为，非动效） |
| 接收 send:failed(text) | 回填草稿 + 失败提示 |
| 接收 busy/link 变更 | 更新处理提示行与发送可用性 |

## 5. 文案表

| 键 | 文案 |
|----|------|
| 占位 | 给 Alice 写点什么… |
| 发送 | 发送 |
| 键位提示 | Enter 发送 · Shift+Enter 换行 |
| 处理中（busy） | Alice 正在处理消息；输入会保留 |
| 发送失败 | 发送失败，草稿已恢复 |
| 服务关闭 | 服务正在关闭，暂停接收新消息 |

## 6. 验收要点（break-ui 攻击面）

- 空白攻击：空串/全空格/全换行发送 → 无信号、无空 Turn 上屏、草稿原样。
- 回填保真：2000 字、纯 emoji、首尾多行空白已 trim 的文本 → 回填逐字一致。
- 连击攻击：Enter 按住不放 → 列表无重复用户 Turn（至多一条 sending→ok）。
- 锁定边界：busy/closing 中 Enter 无效但输入照常；恢复后无需刷新即可发送。
- Shift+Enter：换行成功且不发送（macOS 与 Windows 键盘行为一致）。
- 处理提示行三态切换（失败→关闭→处理中来回）：同一行内切换，不叠行、不残留旧文案。
- 06 的聚焦信号到达：输入区确实获得焦点（联动验收，空态→点"写下第一句"→焦点断言）。

# 06 · 空状态

> 上游契约见 ../PARTS.md（消费：listState=empty、userName；产出：focus:composer）。本文件只含内容与信息规格。

## 1. 用途与边界

**用途**：会话内零 Turn 时，说出"第一句话由你写下"，并把用户送进输入框。空状态是一次性的引路者，不是常驻装饰。

**不含**：头栏（01，空会话时恒在）、加载态（互斥）、失败态（互斥，归 02）、回到最新 pill（空态时必须不存在）、任何消息结构（03）。

**显示条件**（与 02 的判定同源，此处为规格）：listState=empty —— Turn 数为 0，且无揭示中的轮次，且非 loading。**"用户消息已上屏、Alice 未回"不算空。**

## 2. 内容清单（字段级）

| 元素 | 来源 | 说明 |
|------|------|------|
| 主句 | userName 插值 | 有称呼版本为主；userName 为空时退化为无称呼版本（两版文案都在 §5） |
| 说明句 | 固定文案 | 解释 Alice 的回复方式（一句一句），为逐句揭示设定预期 |
| 行动引导 | 固定文案 | 可点击；点击 → 发 focus:composer() |

## 3. 状态矩阵

| 场景 | 行为 |
|------|------|
| 常规（即空态本体） | 三元素：主句、说明、行动引导 |
| 空 | 不适用（本部分只在 empty 存在，自身无子空态） |
| 加载 | loading 期间本部分不存在 |
| 错误 | 载入失败 → 显示 02 的失败内容，本部分不存在（empty 与失败互斥） |
| 最坏 · 洪流重置回空 | 立即出现，无旧消息残影、无 pill 残影 |
| 最坏 · userName 超长/为空 | 超长 → 主句截断但行动引导仍完整可达；为空 → 退化无称呼版，句子仍通顺 |
| 最坏 · 发送第一条瞬间 | 空态与用户消息**同帧互斥**：先消失后上屏（或同帧原子切换），绝不同屏 |
| 最坏 · 空态中切到非空档 | 空态让位给注入内容；切回空档则重现 |

## 4. 交互清单

| 用户行为 | 结果 / 对外信号 |
|----------|----------------|
| 点击行动引导 | 发出 focus:composer()（05 收并聚焦输入区）；仅此一个交互 |
| 其余 | 无——空态不可拖拽、不可关闭、无二级入口 |

## 5. 文案表

| 键 | 文案 |
|----|------|
| 主句 · 有称呼 | {userName}，这里还很安静 |
| 主句 · 无称呼兜底 | 这里还很安静 |
| 说明句 | 说第一句话，Alice 会一句一句地回你。 |
| 行动引导 | 写下第一句 |

## 6. 验收要点（break-ui 攻击面）

- **0↔1 边界（最高危）**：发送第一条的瞬间无"消息与空态同屏"帧；Alice 未回、用户消息在场时空态不得复现。
- 空态与 pill 同屏 = 失败（0 Turn 时 atLatest 恒 true，07 必须隐藏）。
- 空态与 loading / 载入失败同屏 = 失败。
- userName 注入 2000 字：主句区域不吞并行动引导，引导仍可点击。
- userName=""：无称呼版通顺，不出现 "，这里还很安静"（残留逗号）或 "undefined"。
- 行动引导点击后：焦点确在输入区、占位文案可见（与 05 联测）。
- flood → reset（清空会话）→ 空态重现且文案与首次一致。

# 07 · 回到最新 pill

> 上游契约见 ../PARTS.md（消费：atLatest、unreadSentences、Turn 数；产出：jump:latest）。本文件只含内容与信息规格。

## 1. 用途与边界

**用途**：用户离底阅读历史时，承诺"最新内容还在增长"，提供一键回底入口，并附未读句计数。

**不含**：滚动位置判定（02，本部分只消费 atLatest）、消息内容（03）、揭示控制本身（点击后经 jump:latest → 02 回底 → 该次"用户主动回底"触发 04 的跳过，pill 不直接改数据）。

**显示条件**：atLatest=false **且** Turn 数>0。空会话、loading、载入失败期间一律不存在。

## 2. 内容清单（字段级）

| 元素 | 来源 | 说明 |
|------|------|------|
| 固定文案 | 常量 | "回到最新"，任何状态下都在场 |
| 未读句计数 | unreadSentences | >0 时追加"＋{n} 句"；内部无上限累加，**显示**封顶 99+ |
| 可聚焦性 | 结构 | pill 是可聚焦元素，Enter 触发等价点击（键盘回底可达） |

## 3. 状态矩阵

| 场景 | 行为 |
|------|------|
| 常态（在底） | 不存在（隐藏是本部分的常态，不是异常） |
| 离底 · 静止 | 只有固定文案 |
| 离底 · 揭示中 | 计数随 reveal:progress 递增（离底期间每句 +1） |
| 离底 · 洪流注入 | 计数随新 Turn 的新句累加 |
| 空 | 永不存在（Turn=0 时 atLatest 恒 true） |
| 加载 | 不存在 |
| 错误 | 无错误形态；unread 收到非法值（负数/NaN/超大）→ 计数段按隐藏处理，只显示固定文案，不崩溃 |
| 最坏 · 回底后再离底 | follow:change(true) 已清零 → 重新从 0 累加 |
| 最坏 · 切空档 | pill 消失（atLatest 复位 true、Turn=0 双条件都满足） |

## 4. 交互清单

| 用户行为 | 结果 / 对外信号 |
|----------|----------------|
| 点击（或聚焦后 Enter） | 发出 jump:latest()；02 收到后回底并广播 follow:change(true)（unread 清零）；若当时有揭示中的轮次，**该次用户主动回底触发 04 的跳过** |
| 点击后 | pill 不存在（atLatest 已 true）——回底成功与否可由 pill 消失直接断言 |

## 5. 文案表

| 键 | 文案 |
|----|------|
| 固定文案 | 回到最新 |
| 计数（1–99） | ＋{n} 句（例：＋3 句） |
| 计数封顶（≥100） | ＋99+ 句 |

## 6. 验收要点（break-ui 攻击面）

- **空会话强攻**：0 Turn 时注入任何离底状态 → pill 不出现（空态与 pill 永不同屏）。
- 计数非法值（-1 / NaN / 1e15）：无异常输出、无 "NaN 句"，固定文案仍在。
- 计数准确性：洪流 + 揭示并发离底 → 显示值与实际新到句数一致（与 02 联测；显示 99+ 时内部值仍正确累加）。
- 回底链路：点击 → pill 消失、计数清零、揭示中轮次已完整（与 04 联测，pill 是跳过触发器之一）。
- 判定滞回：在"最新区"边缘缓慢来回滚动 → atLatest 不高频翻转（状态翻转次数受滞回约束，pill 不得反复出现/消失）。
- 键盘路径：Tab 可达、Enter 触发与点击等效。

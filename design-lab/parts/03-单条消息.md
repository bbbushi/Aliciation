# 03 · 单条消息

> 上游契约见 ../PARTS.md（消费：单个 Turn 的全部字段；产出：retry:send）。本文件只含内容与信息规格。

## 1. 用途与边界

**用途**：一轮发言（一个 Turn）的静态结构定义——方向归属、句单元、元信息行、占位与沉默。它是列表里重复出现的最小设计单元。

**不含**：句子何时变得可见（04）、列表顺序/分组/日期（02）、输入与草稿（05）、揭示中状态行文案"正在回复…"的时序（04 定；本部分只定它挂在哪）。

## 2. 内容清单（字段级）

| 元素 | 来源 | 说明 |
|------|------|------|
| 方向归属 | role | user 归用户、assistant 归 Alice；每条消息必须携带**可编程识别**的角色信息（读屏/测试不得依赖左右位置推断） |
| 正文句单元 | text 经切句规则 | 一句一单元；**不带可见序号**（编号是"台账变体"的历史选择，不进通用规格） |
| 沉默占位 | role=assistant 且 text 空白 | 正文区显示"（沉默）"，不允许空无一物 |
| 首句未到占位 | assistant 轮已建立、shownText 为空且揭示中 | 句单元显示"…"（何时出现/消失归 04） |
| 元信息行 meta | time / channel / status | 逐字段可缺省，缺哪个隐藏哪个，永不显示占位错误 |
| 言语行为标记 | text 原文 | 【情绪】/(动作) 等历史标记**原样显示**，不做特殊语义渲染（信息保真） |

**切句规则**（与真实产品一致，句单元边界是内容结构）：
1. 句末标点（。！？…）断句；括号/引号内的句末标点不断；换行强制断。
2. 剩余不足一句的尾部自成一句单元。
3. 全空白文本 → 单一空白句单元 + 沉默占位。
4. 切句上限 400 单元：超限后剩余原文并成收尾单元（宁可单元超长，不可丢字）。

**元信息行字段**：
- 时间：time → "HH:MM"（24 小时制）；null → 时间字段隐藏。
- 渠道：channel=web → 不显示（默认不打扰）；qq → 显示 "QQ"。
- 状态：status=sending → "发送中"（仅用户侧）；failed → "发送失败 · 点击重试"（仅用户侧）；silent → 不在 meta 出现（正文占位已表达）；assistant 轮无 sending/failed。

## 3. 状态矩阵

| 场景 | 行为 |
|------|------|
| 常规 | 2–4 个句单元 + meta 齐全（时间在场，渠道默认隐藏） |
| 空 | assistant 空白文本 → "（沉默）"；用户侧空白文本被 05 拦截，若数据层仍出现 → 兜底占位"（无内容）" |
| 加载 | 不适用（单条无独立加载；历史消息一次性到达） |
| 错误 | failed → meta 状态 + 重试交互；time/channel/status 任何字段缺失或非法 → 该字段隐藏，其余字段照常 |
| 最坏 · 超长 2000 字 | 全文完整在场（由 02 滚动阅读），信息不截断；按切句规则 4 保护收尾 |
| 最坏 · 无句界长串（无标点无换行的 URL/连续字母） | 整串为一句单元；单元内允许折行——**信息完整优先于"不折行"偏好** |
| 最坏 · 纯 emoji（含 ZWJ 组合） | 与普通文本同规则切句显示，不丢字、不替换、不拆坏组合序列 |
| 最坏 · 单字符（"嗯"/"?"） | 正常单一句单元 |
| 最坏 · 仅标点 / 仅空白 | 仅标点正常显示；仅空白走沉默 |

## 4. 交互清单

| 用户行为 | 结果 / 对外信号 |
|----------|----------------|
| 点击 failed 状态的用户消息（消息本体或其状态区均可命中） | 发出 retry:send(id)；重试期间 status 回 sending |
| 文本选择/复制 | 平台默认能力，不额外设计、不阻止 |
| 其余 | 无主动交互（揭示中的点击归 04，不属本部分） |

## 6. 验收要点（break-ui 攻击面）

- 2000 字 + 无句界串：不丢一字；不产生需要横向滚动才能读全的行（信息可完整读到）。
- ZWJ 组合 emoji（如 👨‍👩‍👧‍👦）：切句与显示不把一个组合拆成碎片。
- 空白 assistant 轮：显示"（沉默）"，且该轮 id 仍能被 04 的对齐逻辑找到（占位不等于节点不存在）。
- time=null / channel="wechat" 非法值：字段静默隐藏，无 "undefined"、"NaN"、"Invalid Date" 输出。
- 消息超长时 failed 的重试命中区仍可点击（重试可达，不被正文淹没）。
- 【情绪】/(动作) 标记原样在场，不被吞掉或转义成实体符号。
